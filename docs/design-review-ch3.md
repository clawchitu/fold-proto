## 1. 机制：清楚、新、3-1 零文字教得会

**清楚。** 「上页斜起，灯在它背后，石头的影子落在下页，影子能走，越合越往外滑，合到底石头压下来」——一句话、一个物理直觉、没有新 tile。影子位置 `round(d·cos θ)` 的三个后果都对直觉：影子只在斜起时有；越合越远；远的石头影子走得快（3-3 的课）。

**比一、二章新。** 第一章是离散的「合上 = 镜像」，第二章是单一吸附点 90°。第三章是整个游戏第一次把**连续角度**当输入——这正是 plan §12.5 要给评委看的「连续角度作为输入」；同一块石头在三章里有三重身份（合上挡路 / 立起不动 / 斜起投影），是「一张纸、三种状态」在规则层面的对应物。两个被否决的方向（90° 纸片投影、背光透路）否得对，不翻案。

**3-1 不用字能教。** 三个保险：① 被动扫过——从摊平一路合到底，d = 4 的影子在 82°→28° 之间依次扫过第 4、3、2、1 列（折角 98 / 112 / 129 / 152），玩家第一次合书必然看见它过缺口；② 幽灵手拖到 50° 松手、不回弹——这是全章要教的唯一新事实「铰链是旋钮」；③ 本文 §3 的影锁：影子盖住缺口那一刻 Selection 触觉 + 描边亮 400 ms，**快合也触发**，所以哪怕 0.3 s 一把合上，手上也有一下「咔哒」告诉你中间有东西。合上后看到的是 §closed 的描图纸：石头压在（0,2）、缺口还是缺口——「合上没有影子」是第一课，帧 8-2c 画对了。

一处表述要改：`design-ch3.md` §1 说影子在「页抬到 > 81°」离开，那只对 d = 4 成立；规则是 `d·cos θ < 0.5` 时消失（d = 3 为 80°、d = 2 为 75°、d = 1 为 60°）。已改。

## 2. 压的规则：加，但只加一半

**决定：合上时（折角 ≥ 155）纸人站在下页、而上页石头的镜像位正是这一格 → 被压，回到起点。** 下页的石头不动，站在上页、对面是下页石头的格子只是走不了，不会被压。

为什么加：
- 不加的话，3-2「压」是个谎。走过影子站到（1,1）再合上，石头正落在你脚下——现在的规则里你安然无恙，还能接着走到终点。章名叫「压」，玩家第一件会试的事就是站在那里合上。
- 乘影合到底已经是 `crushed`（影子滑到底的位置就是镜像位）。站在影子上被压、站在同一格的纸上不被压，是同一个格子两种结局，迟早有人发现。
- 读屏早就在说这件事：`crushedHere`「合上会被对面的石头压住」只播给下页、对面有石头的格子。规则现在和它一致。

为什么只加一半（不对称）：
- 全对称（上页纸人、下页石头也压）会在第一、二章多出 9 个从未测过的「死格」，其中 1-5「墨」的自然打法——走到（6,2）缺口边上再合——会直接被（1,2）的石头压死。第一章不该有这种陷阱。
- 叙事上「落下来的是上页的石头」已经被合上帧的虚线框 + 四角压痕说定了；下页的石头是「摆着的」，它不动。
- 对称版除了 1-5 还会改 1-2、1-3、2-1、2-2、2-3、2-4 的失败面，收益只有一句物理严谨。不值。

影响：`check.js` 17 关全过，par 一关不变；第一、二章没有任何可到达的受影响格（唯一的下页压格是 3-2 的（1,1））。Swift `FoldCore` 加同一条（`crushed(s, from, a)`），XCUITest 加 3-2「站（1,1）合上 → 回起点」一例。被压的表现：和乘影合到底相同（260 ms 压扁、Impact .rigid 与「啪」同一下、读屏 `crushed`、回到起点、书保持合上、可撤销）。

## 3. 关卡曲线与 par：过，加一个「影锁」

| 关 | 变化 | 窗口 | 判断 |
|---|---|---|---|
| 3-1 影 | 1 | 23° | 教学关，对 |
| 3-2 压 | 1 | 26° | 第二课是「不要合到底」，加上 §2 之后陷阱成真，对 |
| 3-3 远近 | 1 | **5°**（29°–33°） | 精度跳得猛，但它是 3-6 同一窗口的单独训练，位置对；靠影锁撑住 |
| 3-4 乘影 | 2 | 16° | 广告镜头，对 |
| 3-5 回程 | 2 | 8°（26°–33°） | 「打开也能乘」是全章最好的翻转，对 |
| 3-6 灯下 | 3 | 5° | 收束：乘 → 锁 → 下来 → 合，对 |

par 1-1-1-2-2-3、合到底 ≤ 1 次，plan §12.3 全满足。考虑过把 3-3 改成第 2 列缺口（窗口 9°，在 52°–60° 中段），放弃：3-3 的价值恰恰是提前单独练 3-6 那 5°，分开练再合起来考，比把窗口做宽更稳。

**影锁（新规则，spec §5 / §6 已加）**：上页每块石头的影子都盖住一个缺口时为「锁定」——Selection 触觉、缺口描边亮 400 ms、缺口的空心音变实（两道以上同时锁定加双音和弦）；**松手落在锁定窗口内，页停在窗口中点，不往外漂**。窗口之外 91°–154°（折角）照旧不吸附。这是 plan §2 机制 9「角度锁」说的那个「咔哒」，`design-ch3.md` 原来只给了声音模式；现在给所有人。5° 的窗口有了它就是「找得到、停得住」，没有它就是手抖。

两个几何事实给建造记着：影子在折角 98 才出现（d = 4），而 90° 的吸附捕获区在 iOS 上**到 90 为止**（spec §5「91°–154° 不吸附」）；网页原型的 70–110 → 90 不改、也不作数。3-6 solver 走的 `pop100` 在 iOS 上可以停住，在原型里停不住——原型里玩家走的是 61°–67°（折角 113–119）那条，`check.js` 两条都认。

## 4. 帧：六处偏差怎么处理

① **上页远边横穿 S–G 那排格子（8-2b）：保留，不挪。** 这不是偏差，是物理：石头在上页最远一格（d = 4），50° 时它悬在 4·cos 50° = 2.57 格处，影子就在它正下方的第 3 格——远边一定穿过影子那一排。把远边挪到 0.48 / 0.68 H 等于换了角度或让影子离开石头底下，两样都不要。要做的是 ②。

② **下页的格子画在透光上页之上：接受，但按 §closed 的描图纸画。** `design-review-3.md` §closed 已经定了「格子、朱线、纸人在最上层，纸背的高光和压暗在格子下面」；斜起只是同一规则在 26°–89° 的延伸。所以：被上页盖住的格子、影子、纸人、朱线仍在最上层，**上面蒙 15% 的背光纸色薄纱**（同 §closed，透出「隔着纸看」的意思，又不把对比拉回 1.9:1），1 pt `edge.lower` 描边照 `design-ch3.md` §4 的决定。只有石头剪影是在上页上的，它在纸层里，不在最上层。没盖住的格子不蒙纱。

③ **地图「9 / 15」「二 4/4」「五 翻页」（8-4）全错，改为：一「达」5/5、二「通」6/6、三 0/6、右上角 11 / 17；四「倾」即将推出；没有「五」。** 关数按 `levels.js`：5 + 6 + 6 = 17。全游戏四章（spec §3；plan §11 的表、4-8「两人」是最后一合），「翻页」是推到 1.1 的机制，不是章。ch2-9-map 同样画了「五」，一起改。

④ **章首帧的「二 #F3EDE2 → 三 #F1E9D8」标注：删。** 同一帧的小书可以留。

⑤ 图例已纠正，无事。

⑥ **乘影没有动画帧：不挡建造。** 建造按 `design-ch3.md` §1 / §4 和 spec §6 做（2 pt 逆光亮边、CHHaptic continuous 跟影子速度、每滑一格一个下滑音）。M4 润色前让 Claude Design 补一条 3 帧的 3-4 条带（67° 站上第 2 列 → 58° 滑动中 → 51° 到第 1 列），商店截图要用。

帧里另有四样**只是标注、不进 App** 的东西，建造别照抄：「斜起 50°」角度气泡（spec §0 第 5 条：没有读数）；摊平位置的虚线轮廓（§0 第 2 条：不画辅助线，而且虚线 = 上页是 §closed 的约定，不能再借用）；幽灵手的虚线轨迹（review-2 §2.4 的幽灵手只有手，没有线）；8-3 的对比度标签。

## 5. 会让玩家困惑 / 会破既定规则的点

1. **灯在哪里。** 「灯在纸的后面」是纸人的视角：光从观者这边、从书的上方来，透过 0.60 的上页，被页面**下面**的石头挡住，影子落在正下方的下页上；上页的暖晕是被照亮的纸，石头是隔着纸看见的黑块。**不要在棚下放光源**——放了影子就不会落在下页上，而且会把下页照亮到看不出影子。帧 8-2b 画的是对的，这里只是把理由写死。
2. **相机。** 斜起全程用「手里的相机」12°，拖动中不动，雨棚从折痕伸出盖住下页上部（review-3 §3 / §5），帧符合。不要因为第三章要「看影子」而加俯角——那正是 review-3 撤掉的东西。影锁的软停不切相机。
3. **合上帧（8-2c）少了纸背。** 合上后应是 §closed 的描图纸：`paperBack` + 纤维、15% 薄纱、下页实线 / 上页虚线、石头虚线框 + 压痕、灯 350 ms 退掉。帧里格子画对了，纸背没画——按 §closed 做，不按帧。
4. **朱线过缺口。** 纸人踩影子走过的缺口，朱线照画（朱线 = 走过的路，不是纸上的针脚）；乘影滑行时朱线跟着滑行一段一段画出来。影子走了、线还在——它是记忆。
5. **影子出现得晚。** 从 89° 进入「斜起」到 82° 才有第一道影子（d = 4），中间 7° 什么都没有；`paper.lit` 在 89° 播是对的，但视觉上纸亮起来（背光 0 → 0.60）要在 89°–82° 之间完成，让玩家先看到「纸亮了」再看到影子，不然会以为斜起没用。
6. **15° 档不吸附 90。** 按钮 / 读屏每按 15°，从 180 往下到 90 再到 75：75°（折角 105）在斜起窗口内，必须停得住；别让 90 的吸附把 75 吃掉。`check.js` 的 `stepped15` 断言依赖这一点。
7. **ja / ko 的 3-2 关名**：「重し」「누름돌」都是「镇纸」，和 §0 第 4 条「镇纸是未入选候选」撞词；建议 ja「圧」、ko「누름」。送母语者审时一起定，不挡建造。

## 6. 建造改动清单（FoldCore / letterfold 0.2）

规则
1. `FoldCore`：加 `crushed(state, cell, angle)`：折角 ≥ 155 且 cell 在下页且 mirror(cell) 是石头 → 真；角度变化时先于 ride 判断；结果同乘影合到底（压扁 260 ms、Impact .rigid、`crushed` 朗读、回起点、书保持合上、入撤销栈）。对照 `logic.js crushed`、`check.js turn`。
2. 影锁：锁定判定 = 上页每块石头的影子都在某个缺口上；进入锁定 → Selection + 缺口描边亮 400 ms + 空心音变实（≥ 2 道：双音和弦）；松手且在锁定窗口内 → 页 160 ms（`hinge.release`）停到窗口中点；窗口外 91°–154° 不吸附不变。快速扫过也触发触觉和描边。
3. 影子出现 / 消失按 `d·cos θ ≥ 0.5`；`paper.lit` 在进入 89° 时播一次；背光在 89°→82° 之间从 0 升到 0.60。
4. 15° 档位和 90° 吸附：斜起窗口内的 75°、60°、45°、30° 都必须停得住。

画面
5. 斜起时下页被盖住的格子 / 影子 / 纸人 / 朱线在上页之上，蒙 15% 背光纸色薄纱；没盖住的不蒙；1 pt `edge.lower`；纸人在影子上 1.5 pt `#FBF6EA` 逆光描边，特写 2 pt。石头剪影在纸层里。
6. 远边位置按几何（50° 时 −0.58 H · 1.23×），不躲格子。
7. 合上按 §closed（纸背 + 纤维 + 实线 / 虚线），灯 350 ms 退掉，影子全消。
8. 不进 App：角度气泡、摊平虚线轮廓、幽灵手轨迹线、对比度标签、章首的颜色标注。
9. 乘影：按 `design-ch3.md` §4 / spec §6 做；M4 前补 3 帧条带。
10. 光源只在书上方 / 观者侧；上页暖晕 `lamp #FFD08A` 纯装饰；高对比去掉灯晕；降低透明度上页实底。

地图 / 文案
11. 两岸地图：5/5、6/6、0/6、11 / 17，四「倾」即将推出，删「五」（ch.2 的地图一并改）。
12. ja / ko 3-2 关名待母语者审（§5 第 7 条）。

测试
13. XCUITest：3-2 站（1,1）合上 → 回起点；3-3 松手在 31° → 停在 31°±0（影锁）；3-4 从 67° 合到 51° 纸人从（2,2）到（1,2）；17 关 `levels.json` 的 `expect` 与 Swift solver 一致（含 `crushed`）。
