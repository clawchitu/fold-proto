# 《折信》难度复盘（2026-10-19）：为什么我们的度量两次都错了

> **校准点**：卷二第一章「胶」章末 5-7 `stuckPage`，v2 score **14**（final 档，目标 5–10 min），主人实测 **20–30 秒**。差 **≈ 20 倍**。此前卷一 4-5 / 4-6 在 v1 下满分 8（hard），主人：「还是有点简单」。两次度量说难、人说易。本文不再给第三个公式，先解释**为什么公式会错**，再给能被测出来的东西：一个关卡生成器、七张新图、一套试玩协议。
>
> **这次改动**（已进 `levels.js` / `tools/` / 灰盒）：5-1…5-3 不动；5-4…5-7 重做；新增三关可选的「暗信」；`tools/gen.js` 生成器；`tools/check.js` 的档位规则从"分数区间"改成"分数下限 + 解长下限 + 诱饵上限"，折数预算按档位分级（§1.4）。35 关 `node tools/check.js` 全过。

## 1. 诊断：为什么 20–30 秒

`node tools/gen.js stats` 对全部关卡量了八件事（表在 §附录；旧 5-4…5-7 的数值在这一节里引用）。结论按重要性排：

### 1.1 整个状态空间一眼看完

| | 卷一 25 关 | 旧第五章 7 关 |
|---|---|---|
| 棋盘 | 3–5 行 × 8 列 | 3–5 行 × 8 列 |
| 空格（`-`）占比 | 平均 **72%** | 平均 **74%** |
| 元素（石 / 钥 / 门 / 墨 / 纸片 / 胶） | 平均 3.2 个 | 平均 3.3 个（5-7：7 个） |
| 可达状态（格 × 角度 × 是否盖印） | 50–240 | 70–240 |

棋盘小、空格多，有意义的格子只有十来个。游戏状态只有三个量：你在哪一格、铰链在哪个角度、书合过没有。一个熟悉规则的人在读图的那两秒钟里就把全部状态走完了——**没有需要在脑子里推演的东西**。

### 1.2 解很短，而且被规则封顶

| | 卷一 | 旧第五章 | 新 5-4…5-7 | 暗信 |
|---|---|---|---|---|
| 最优解长度（姿态变化 + 步数） | 平均 8.6（3–16） | 平均 **7.3**（6–10） | **17 / 17 / 18 / 20** | **20 / 19 / 22** |

两条规则把深度钉死了：

1. **par ≤ 3（`plan.md` §12.3 疲劳规则）**。姿态变化是这个游戏里唯一"做事"的动作，走路是免费的。三次姿态变化 = 最多三个决定。
2. **盖印只发生一次，而且与你站在哪无关**。第一次合上时钥匙开门、墨印、胶粘全部同时发生，`stamp()` 只看地图不看人。于是每关都是两幕：合上之前（只能在自己那一页走、斜起踩影子）和合上之后（地图已经定了）。合上之前你唯一的选择是**站在哪一格**。玩家只要看懂"合上之后地图长什么样"（第五章 5-1 教过之后人人都会），第一幕就只剩"找一个不会被压的格子"。

5-7 的 20 秒就是这么来的：看一眼胶和石头的配对 → 知道合上后哪里有石头、哪里有影子 → 找不被压的那格 → 合。三个决定，每个都能直接读出来。

### 1.3 每关只有一个念头，布局直接指着它

- 第五章每一滴胶都**正对着**它要粘的那块石头，而且是同一行唯一一块；胶没有第二种可能的用途。
- **诱饵元素（`noise`）**：拿掉之后最优解一步不变的元素。旧 5-4…5-7 分别有 **1 / 1 / 2 / 3** 个；5-7 的七个元素里，"切断退路的胶 (1,2)"、"落在路上的石头 (6,2)"、"门 (3,3)" 都是诱饵——它们只惩罚走错的人，对知道规则的人不存在。而 **`blockers`（存在是为了堵住捷径的元素）** 旧第五章一共 1 个。一个谜题的难度来自"看起来能走的路为什么不通"，而我们的元素全在"走对的路上作为道具"。
- **决策点的岔路（`wrong`）**：最优解每次动铰链之前，有几种"做了会有事发生、但不对"的铰链动作。旧 5-4…5-7：**4 / 2 / 2 / 5**；其中第一步的岔路 2 / 2 / 1 / 3。新关 10–15，第一步 5–7。

### 1.4 死局一步就到，而且看得见

旧第五章的死局全部由**第一次合上**进入（`before` = 1），而且游戏当场放动画（石头飞过中缝）。对第一次见到胶的人这是教学；对第二次见到的人这是"别先合上"四个字。死局深度 1 = 没有死局。真正花时间的死局是**走了四五步才发现回不去**。

### 1.5 关名和一句话把念头说出来

「影先」「一合 · 只合一次。在哪里合？」「先乘影」「影子只借一次」——关名就是解法的顺序。评审 `design-review-v2c1.md` §2 已经改掉一句，但其余四关的名字仍在泄题。新关的名字和一句话改为**物件和意象**（「旧处」「渡」「两盏灯」），顺序和角度放进「?」梯子的第一级。

### 1.6 度量量的是"新手会不会吃一惊"，主人是作者

v2 的 insight 项——`misdirect`（显而易见的一步会错）、`before`（要在合上之前做事）、`deadEnds`、`made`（影子是自己造的）——每一项都是"原来不能这样"的一次惊讶，各记 2 分。但：

- 它们**量的是同一个事实**。5-4 的 `before` + `misdirect` + `deadEnds` 全部 = "别先合上"，一个念头拿 6 分。
- 惊讶只发生一次。5-1 教完胶，5-4 到 5-7 对同一个人就没有惊讶了。度量把**规则的新鲜度**当成了**搜索的难度**。
- 主人写了规则。对他来说每一条规则都不新鲜，剩下的只有读图和推演，而 §1.1–1.2 说明没有可推演的东西。

**结论**：score 不能再用来宣称一关"难"。它只能做下限（低于某值一定简单），档位由试玩的时间定（§5）。`check.js` 已照此改：teach–mid 保留上限（教学关不许变难），hard / final 只查下限，另加 §3 的三条 v3 门禁。

### 1.4 顺带：折数预算改为按档位分级

疲劳规则是为了"不让玩家为一关反复开合手机"，但 `plan.md` §12 之后已经把拇指拖页定为所有设备的主输入，铰链是可选的。所以把预算从"每关 ≤ 3"改为：teach / easy / mid ≤ 3；hard / final ≤ 4；可选「暗信」≤ 6。完全合上：主线 ≤ 2，暗信 ≤ 3。另加一条**章预算**：一章主线最优解姿态变化总和 ≤ 24（第五章现在 2+2+2+3+3+4+4 = 20）。暗信不计入章预算，因为它是玩家主动选的。

## 2. 难的谜题游戏怎么做难：可以搬过来的八个模式

这些游戏的共同点：规则比我们少，但每条规则和别的规则都有**第二种读法**。

| 游戏 | 它难在哪 | 搬到折 / 角度 / 影 / 胶 / 墨 / 压 上 |
|---|---|---|
| **Stephen's Sausage Roll** | 每一格都有用；没有装饰格。推香肠的动作不可逆（掉下去、烤焦），而且**同一根香肠要翻两次**——同一个物件要用两次。 | **P1 零诱饵**：每个元素要么在最优解上，要么拿掉之后出现更短的解（`blockers`）。`noise ≤ 2` 进 CI。**P2 石头的两份工**：同一块石头先投影给你走，再堵住一叠或在旧位置压你（`reuse`：新关每块关键石头 ≥ 2 个角色）。 |
| **Baba Is You** | 规则本身是状态；你踩过的东西换了身份。 | **P3 空格的两种身份**：左页一个空格，对面是石头 = 斜起时的**影子**，对面是纸 = 合上时的**渡口**（从这一叠走过去你就换了页）。一滴胶把对面从石头换成纸，影子就变成了渡口。新关全部靠这个。 |
| **Snakebird** | 重力 + 顺序：身体是桥，掉下去是承诺。 | **P4 乘影即承诺**：踩上影子再改角度，你只能跟影子走；合到底就掉。暗二：踩着影子一直合，影子把你放到纸上的那一瞬间书合拢、门开、石头被粘走——三件事一拍。 |
| **Patrick's Parabox** | 你在容器里，容器也是你走的格。 | **P5 叠合里的页**：合上时你在一叠纸里，每走一格 `land()` 决定你落在哪一页（能留在本页就留）。打开时你在哪一页是**一路走来的历史**决定的，不是看出来的。暗二的叠合路要换四次页。**P5′ 石背**：左页石头的那一叠不能走进去，但你可以在打开时站到它正上方的右页格，再合上——站在里面就能走出去。暗一、暗三、5-4（被胶堵住的捷径）。 |
| **A Monster's Expedition** | 每个局部正确的动作全局都错；岛和岛之间靠倒下的树。 | **P6 第一合是无害的局部最优**：合上看起来只是过河，但它把一块石头放到你三步之后要走的地方 / 把你要踩的影子的石头粘走。新关 `before` 全为 1，但不再是"别合"，而是**合之前先站对、合之后先别打开**。 |
| **Cosmic Express** | 一条线要依次服务两个目标，不能回头。 | **P7 一合两用**：那一次合上必须同时开门 + 搬石头 + 不压到你，三个约束交在一格上（暗二只有一格安全）。**P8 角度来回**：两块离中缝一样远的石头，影子落在同一列；要先开到 60° 再合回 40°，角度不是单调的（5-7 两盏灯）。 |

还有一条是我们自己的：**走路是免费的，所以深度只能来自"在哪里改角度"**。新关最优解 14–16 步走路，是因为每一次改角度之前都要先走到唯一正确的那一格（`narrow` 新关 3/3、2/3、4/4、4/4、5/6、4/5、5/6）。

## 3. 生成器：`tools/gen.js`

```
node tools/gen.js stats                 # 量全部关卡（§附录的表）
node tools/gen.js show <id | 行,行,…>    # 一张图的全部指标 + 解
node tools/gen.js search --rows 6 --par 6 --closes 3 --tiles .-xgkD --need glue+key --polish
node tools/gen.js polish <id | 图>       # 删掉不承载任何东西的格子和元素
```

- **规则来源**：只调用 `logic.js`（`ride` / `neighbours` / `stamp` / `shadows`），铰链以 5° 步进在 `check.js` 的 10 个采样角之间转，和游戏一致。
- **一次探索，全部指标**：对一张图建完整状态图（格 × 角度 × 盖印），算：`par`（最少姿态变化）、`steps`、`len = par + steps`；`wrong`（每个决策点上"做了会有事但不对"的铰链动作，按"合上站在哪一叠 / 斜起 / 立起"归并）；`narrow`（只有一种对的铰链动作的决策点数）；`dead` / `deadEnds`（死局占比、死局盆地数）；`before`、`made`、`ride`、`pageSwitches`；`fatal`（站在纸上合会被压的决策点）。
- **慢指标只给幸存者**：`noise` / `blockers` / `loadBearing`（逐个元素拿掉看解变不变）、`irrelevant`（逐格改成空看解变不变）、`reuse`（一块石头在解里扮演几个角色：影 / 墙 / 压 / 被粘）。
- **适应度**：`12·par + 2·steps(≤14) + 4·wrong(≤10) + 3·firstWrong + 6·deadEnds(≤2) + 6·[死局占比 15–70%] + 8·before + 6·made + 3·ride + 3·fatal + 3·pageSwitch + 4·narrow − 元素超预算 − 纸格过多`；硬约束：可解、15° 一档可解、par / 合数不超上限、指定机制不可或缺（`--need glue+pop`）。
- **搜索**：随机图 → 单点变异（改一格 / 交换两格 / 挪起点终点，纸片自动成对）→ 模拟退火 → 多次重启 → 归档；最后对前 N 张做 `polish`（贪心删格，适应度不降才删），再按 `F = f − 4·noise − 0.8·irrelevant + 4·reuse` 重排。60 000 次评估约 3.5 分钟。
- **发现**：par 上限 3 也能搜出 len 17–19、两个死局盆地、`before` + `made` 的图——深度不只来自折数，来自 §2 的 P3 / P5（渡口和换页）；但 par 3 的图全是同一个骨架（合 → 渡口过页 → 一串乘影）。par 5–6 才出现"合两次、中间站石背""乘着影子合上""三次合、墨印两次"这些不同的骨架。
- **它看不见的**：可读性（人能不能一眼看懂图）、重复感（七张图是不是同一个念头）、故事。所以生成之后一定手选——这次 7 张图从 ≈ 70 张候选里挑，去掉了 4 张同骨架的。

## 5. 试玩协议

**不再由分数定档；由时间定档。** 每关的目标是**有经验玩家**（通过卷一 + 5-1…5-3）**首次、不看提示**的时间：

| 关 | 目标 | 低于下限 → | 高于上限 → |
|---|---|---|---|
| 5-1 / 5-2 / 5-3 | 0.5–1.5 min | 不动（坡道） | 查文案 |
| 5-4 / 5-5 | **2–4 min** | 砍掉重搜（`--minpar 3 --par 3`） | 给「?」第一级 |
| 5-6 / 5-7 | **4–8 min** | 砍掉重搜（`--par 4`） | 给「?」第一级；> 15 min 换图 |
| 暗一 / 二 / 三 | **8–20 min**，允许放弃 | 不动（暗信就该难） | 放弃率 3/3 → 换一张 |

**人**：主人 + 2 位朋友（一位通过卷一、一位没玩过——后者先玩 5-1…5-3 作为校准）。每人单独玩，不旁观别人。

**记**（每关一行，灰盒加一条 `console` 日志即可）：开始到过关的时间；**第一次动铰链的动作**（和 `firstWrong` 对照：第一步就对 = 这关读得出来）；撤销 / 重来次数；进入死局的次数和在死局里待的时间；是否按了「?」及第几级；放弃否。另外请每人在过关后用一句话说"这关的窍门"——和表里的「要想到的」对照，**说不出来 = 靶心没打中**（可能是蒙过去的）。

**判定**：
- 一关三人中位时间落在目标区间 → 档位成立，把时间写进 `levels.js` 的注释。
- 两关连续偏差 > 2× → 不改公式，改图；三关以上同向偏差 → 整体改目标区间。
- 主人单人 < 1 min 的 hard / final 关直接视为失败，不等朋友。
- 这一轮之后，`check.js` 的 `LEN_MIN` / `NOISE_MAX` 用实测数据回填：找出"时间 ≥ 目标"的关里 len 的最小值，作为下一章的下限。
