# 卷三脑暴：铰链走过的路，纸都记得（2026-10-26）

主人要卷三的方向。本文只是方向稿：不建关、不写代码、不改 `roadmap.md`（第七章正在设计，`objects.md` B.2 里卷三那四行——三折 / 纸鹤 / 镜 / 纸人的影子——是本文要挑战的默认答案）。依据：`roadmap.md` §1 / §4、`plan.md` §2 / §11 / §12、`objects.md` B.3、`difficulty-v3.md` §1–§2、`design-skins.md` §2–§3。角度一律物理角。

## 0. 一页结论

**先说难度，因为它决定选哪个机制。** `difficulty-v3.md` 的教训是：凡是棋盘的**确定性变换**（斜起看影子、合上看印、翻过去看第三页），玩家十秒内免费看完，一眼纸（`glance.js`）就能印出来，关就只剩"找那一格"。把 12 个候选 + `objects.md` 的 6 个新物件按"一眼纸能不能印"分，只有三类：

| 类 | 机制 | 一眼纸 | 难度来自 |
|---|---|---|---|
| **视图型** —— 又一种确定性变换 | 三折、镜、窗、灯位、角度门 | **能印**（多一张视图） | 读图；v3 已证明读图不是难度 |
| **事件型** —— 铰链每经过一个节点就发生一件事，而且不可逆 | 墨晕（卷二）、**滚石**、**纸鹤**、风铃、封蜡 | **印不完**：状态取决于经过了几次、**在哪两次之间走了哪段路** | 顺序（P3）、不可逆（P2）、资源（P6） |
| **耦合型** —— 结果取决于纸人自己在哪 | 石背、纸人的影子、压板（人是重量）、墨人 | **印不下**：位置 × 角度的积空间 | 推规则后果（P5） |

卷一教的是铰链作为**位置**（0 / 90 / 130 / 180 是一个旋钮）；卷二教的是合上作为**事件**（印、粘、洇、翻）；**卷三该教的是铰链的路径作为一个序列**——经过 90° 和合到 0° 是两种不同的拍子，先后不同结果不同。这是真正的台阶，而不是第五种变换。

**主人的标准是「最好有难度且有趣味」**，两个都要。上表只量难度；趣味另有一条尺：每个方向下面都单列一行"趣味从哪来"——是玩具感（动一下就有反应）、是惊喜、是故事兑现，还是啊哈。难度靠规则后果，趣味靠**后果好看**；一个机制如果后果只能用叠合图看懂，它再难也不好玩。

**先正面说一个撞车**：现在的卷三《三折》和卷二第六章「翻页」是同一件事——都是"书多了第三页"。翻页已经让玩家见过第三页、见过三页之间的链式盖印（`design-ch6.md` §1.2）；三折再来一次，玩家学到的新事实只有"第三页叠在上面而不是翻在旁边"，卷二到卷三像没换卷。三折能保留的只有它的**名字和终章画面**，不能再当一卷的机制。

**我的选择：方向 B《倾》**——松石 + 纸鹤 + 来回 + 三折终章，纸换成**硬卡纸**。三折保留，但从"卷名机制"降为卷三的**终章**（成本 2、品牌点、只用一章）。镜、纸人的影子出卷三；滚石从卷四调上来，纸人的影子调去卷四配冰。理由在 §2。

## 1. 四个方向

### A 《三折》Trifold —— 默认答案（roadmap §1 / objects B.2）

- **故事**：卷二末两人翻到同一页；卷三的信太长，一折装不下——"信要折几次才够小、够近"。两道折痕，第三页落到叠合的两页上。末章那一合：三层叠成一格。
- **纸**：**油纸**。更透，叠三层仍看得见最底层；合上时描图纸变成三层递淡的叠影。
- **机制家族**：第三页（Duo 上是拇指拖的虚拟页）折到两页之上，列 c 经两次镜像落回 c，三层叠一格、最上层才是地面。真正的新东西不是第三页本身，而是**折序**：Z 折（第三页在下）和卷折（第三页在中间）的层序不同，谁在最上面由你先折哪一道决定——这是卷一"合上"第一次变成有两种答案的动作。
- **四章**：九 **三折** Trifold ——第三页落到 c 列，层序 = 折序 ｜ 十 **鹤** Crane ——纸鹤 `h` 每合一次飞到镜像格，两折后是"两次镜像" ｜ 十一 **镜** Mirror ——镜 `m` 把影子折 90° 沿列投下去 ｜ 十二 **己影** Own Shadow ——你的影子落在上页，一个人两个身体。
- **折 / 铰链 / Duo**：Duo 只有一条铰链，第三页永远是虚拟的——roadmap 说"手里的书和屏里的书第一次不一样，本身就是题"。我不信这句：plan §12 已经把拇指定成主输入，所以它不是题，只是卷三**失去了签名时刻**（卷一乘影、卷二合上粘走石头，都是真铰链能拍的）。
- **一眼测试**：视图型。折序 2 种 × 合几次，一眼纸印两套就完；三层叠合图比两层大但仍是确定图。剩下不在纸上的还是那 1 bit"我被带进了哪一层"——就是石背，读者已经会了。**靠三折本身过不了 hard 0/2**，要靠纸鹤（事件型）和己影（耦合型）救。
- **趣味从哪来**：故事兑现——Letterfold 的本义终于出现，合拢那一下三层叠成一格是全书最该好看的一帧；加上纸鹤每合一次飞一次的玩具感。但三折本身的"啊哈"（c 回到 c）是翻页啊哈的变奏，不是新的。
- **风险**：① **和卷二「翻页」撞车**：翻页已经给了第三页和三页链式盖印，三折只多了"叠在上面"这一个事实，卷二到卷三像没换卷——这是 A 最大的问题，不是可读性；② 4 列 × 三层的可读性，油纸三层递淡 + 高对比下三层只能靠花纹分；③ 读屏一句话要说清"这格叠着三层、最上层是什么"；④ 镜是视图型，和三章四章、卷二八章一起是第四次"影子章"。

### B 《倾》Lean —— 立起来，东西往低处去 ★

- **故事**：同一页上站过了，书打开还是两岸。那就把书**立起来**：立起来的时候，什么都往低处滚——低处是折痕，折痕是你。卷三的问题从"我怎么过去"变成"**我能把什么送过去**"：石头替我滚过去，鹤替我飞过去，最后信折三折才够小、够寄。末章那一合：三折合拢，三层叠成一格（三折作为终章保留）。「倾」也是倾诉的倾。
- **纸**：**硬卡纸**（card）。卷二的信笺薄，卷三的纸厚、硬、立得住：浮雕格变成**压痕格**，石头有了重量感（滚动时有厚纸的闷响），页立成帐篷时能看见厚度。透光 0.08（最不透的一卷——给卷四的冰纹留对比）。
- **机制家族：过立事件**。上页**每经过一次 90°**，上页的松石 `r` 向折痕滚一格（滚进缺口填成纸，前方有石 / 门 / 纸人则不动，滚到中缝旁那列停）；纸鹤 `h` **每完全合上一次**飞到镜像格（载着你）。两条规则，两种拍子：**斜起再回来 = 两次过立不合上**，石头滚了两格、鹤没动、墨没印；合一次 = 过立一次 + 合上一次。铰链的一条路径第一次被拆成可数的节拍。为什么是台阶：卷一到卷二所有机制的结果都是**当前角度或合上这一拍**的函数；这一卷的结果是**角度路径**的函数——这正是一眼纸（七个采样角并排）印不出来的东西。
- **四章**：九 **滚** Roll ——松石 `r`：过立一次滚一格，滚进缺口成桥；滚动的石头影子跟着跳（6–7 关） ｜ 十 **鹤** Crane ——纸鹤 `h`：合一次飞一次，落在墨上染墨、落在胶上被粘住；滚石堵住它的镜像格它就飞不动 ｜ 十一 **来回** To and Fro ——无新 tile：来回（两次过立）第一次在 par 里算钱；滚 × 影 × 鹤的顺序题（先乘影再让石头滚，还是先滚再乘），`CLOSES_MAX` 不放宽但姿态 par 放到 5 ｜ 十二 **三折** Trifold ——第三页落下来，松石和鹤经两次镜像；终章用本卷两样 + 胶 + 影。暗信：风铃 `b`（奇偶）；侧信：墨流（湿墨立起时往折痕流一格，不进主线）。
- **折 / 铰链 / Duo**：**立手机就是倒东西**（roadmap #7 原话）。乘影之后最物理的签名时刻：一只手把 Duo 立成帐篷，上页的石头滚进河里。拇指拖页同样成立（经过 90° 就触发），15° 步进恰好经过 90°，读屏一句话「松石；上页立起时会往折痕滚一格」。求解器：松石位置进网格变体（胶已经这样编码），纯函数。
- **一眼测试**：事件型 + 不可逆。① 一眼纸要印"过立 k 次之后"的 k 张图 × 鹤飞了几次 × 七个角——而真正的题是"**在第几拍和第几拍之间走哪段**"，图上没有（和墨晕同一论证，v3 §4.2）；② **石头永远不滚回来**：把石头滚进错的缺口，三步之后才发现你要乘的是它的影子（`deadDepth ≥ 3` 天然成立）；③ 资源：par 里一次"斜起再回来"花 2 拍滚 2 格但不印墨、不飞鹤；合一次花 1 拍什么都发生——同一个预算两种花法；④ 耦合：乘着松石的影子过 90° 时影子消失、石头滚走，再斜起影子在另一列——"渡船在你脚下换了位置"。
- **趣味从哪来**：**玩具感**——这一卷的纸是会动的：立起来就有石头滚、鹤扑一下翅膀，不解题光来回扳铰链也有反应（卷一卷二里不合上什么都不发生）。惊喜在第一次发现"斜起再回来"也算数：你以为什么都没做，石头已经在河里了。故事兑现是每一关都在"送东西过去"，终章三折把信折小了寄走。啊哈：乘着松石的影子过 90°，渡船在脚下换了位置。
- **风险**：① **90° 恰好是上页看成一条线的角度**（plan §8 风险 3）——滚动在 90° 触发但要在 75°→105° 之间可见地滑过去，动画和规则分离；② 和纸片桥同一个窗口（60–120°）：桥立着时石头可以滚上桥（桥是纸），规则不冲突但画面要试；③ 4 列只滚 3 格，滚的空间小——靠和影 / 胶 / 鹤组合，不靠距离；④ 卷四《冰》失去滚石（"冰上滚得远"），换成纸人的影子护冰（见 §2）；⑤ 松石 `r` 和石头 `x` 的轮廓要一眼分开（圆 vs 方；高对比：斜线 vs 圆点阵）。

### C 《影戏》Shadow Play —— 你的影子也是你

- **故事**：灯在她那岸（卷二末章）。卷三把纸举到灯前：**你自己的影子**落到了对岸——一个人，两个身体，一个输入。问题："影子到了，算不算我到了"。末章：你和你的影子、她，三个剪影叠在一格。
- **纸**：**影窗**（皮影戏的"亮子"：绷紧的素绢 / 纸，灯固定在后）。全卷背光，一切都是剪影——皮影角色终于回到自己的媒介；灯晕原点固定在页边，角度 = 纸到灯的距离。
- **机制家族**：纸人的影子（#9）——斜起时你在上页投影，影子随角度滑，能捡上页的钥匙、站上页的格；镜 `m` 折影子 90°；墨人（#10）站在湿墨上合书、你被印到镜像位。核心是**积空间**：影子位置 = f(你的位置, 角度)，走一步影子也走一步。
- **四章**：九 **己影** Own Shadow ——影子落上页、随角滑 ｜ 十 **镜** Mirror ——影子折 90°，一度之差整列挪 ｜ 十一 **墨人** Ink Figure ——唯一的瞬移，只去镜像位 ｜ 十二 **影戏** ——两盏灯（卷二）+ 镜 + 己影。
- **折 / 铰链 / Duo**：角度是灯距，旋钮手感回归；但没有合上的新拍子，Duo 签名时刻是"举到灯前"，卷一三章用过。
- **一眼测试**：耦合型——一眼纸印不下"每一格 × 七个角"的影子表，读者只能推。但**没有不可逆**（影子可逆、镜可逆、墨人一次性但一关一次）：P2 缺席，得借胶来做承诺。hard 0/2 可能达到，final 要靠胶 + 墨人叠。
- **趣味从哪来**：惊喜——第一次斜起看见对岸有一个"你"在跟着走，是全卷最好的一帧；之后是双身体的玩具感（走一步影子滑一格、转一度影子挪一列）和皮影戏的画面兑现。啊哈：影子捡到了你够不着的钥匙。危险在它的乐趣全在"看"，一旦看熟就只剩算。
- **风险**：① **影子疲劳**：卷一三、四章，卷二八章，卷三再四章全是影子，商店截图像没更新；② 两个身体的读屏（「你在 2,3；你的影子在 6,3」每步两句）；③ `objects.md` 压板写"影子没有重量"，roadmap #9 写"你的影子能踩压板"——两处矛盾，选 C 要先裁；④ 镜是视图型，撑不起一章。

### D 《窗》Window —— 纸有了洞（剪纸）

- **故事**：信纸被剪开了——"透过这个洞，我看见你那页的灯"。纸：**剪纸**（镂空；夜，纸变暗，只有光照到的格能走）。
- **机制**：窗 `w`：合上时两页的洞对齐可以穿层；斜起时光透过洞在下页投一个光斑，光斑随角滑，**暗路只在被照到时能走**（影子的反面）。第三章「剪」：合上压过划线处，撕出新的洞——唯一不可逆。
- **四章**：九 窗 Window（穿层）｜ 十 光斑 Spot（暗路）｜ 十一 剪 Cut（撕出洞）｜ 十二 夜 Night（终章）。
- **一眼测试**：视图型（光斑是影子的补集，VIEW 2 直接印），只有「剪」是 P2。**单独过不了 v3**；roadmap 把窗配冰（光化冰 = 事件型）是对的，不要拆出来。
- **趣味从哪来**：画面——剪纸镂空透光是四个方向里最漂亮的截图；穿层那一下有 Parabox 式的惊喜。但光斑是影子的反面，玩起来的手感和三章一样，新鲜感在第二关就用完。
- **风险**：剪纸的红和朱红印章撞（全游戏唯一饱和红）；撕 = 复活砍掉的"折痕记忆"的一半；Duo 没有新动作。

## 2. 选择：B《倾》，三折降为终章

**为什么是 B。** 三条，按重要性：

1. **它是唯一一个主机制自己就过 v3 的方向。** A 和 D 的主机制是视图，要靠配菜过门——那等于卷三的卷名机制是摆设。B 的"过立 k 次之后 + 在哪两拍之间走"和"石头不滚回来"是 v3 §2 P1 / P2 / P3 / P6 全中，而且是规则本身给的，不用关卡设计硬凑（v3 §6 的教训：两页信、par ≤ 5，怎么凑都一眼破）。
2. **它给了 Duo 第二个广告镜头。** 乘影是"慢慢合手机"，倾是"把手机立起来"——两个都是只有在手里才好看的动作。三折做不到这一点，第三页在哪台设备上都是拇指。
3. **台阶是真的台阶。** 位置 → 事件 → 序列。玩家在卷三学到的新能力是"数铰链经过了什么"，这个能力卷四的冰（照到就化、不可逆）直接接着用。
4. **难和好玩是同一个来源。** B 的难度来自"石头滚了就回不来"，而它的趣味来自"扳一下就有东西滚"——同一条规则。A 和 D 的难度要靠别的机制补，趣味又靠画面补，两头都是外挂。主人要的「有难度且有趣味」，只有 B 不用在两者之间让步。
5. **它不撞卷二。** 卷二的四章全是"合上 / 翻过去发生什么"；卷三第一次让"不合上"也发生事。三折作终章只用一次，和翻页的区别（叠在上 vs 翻在旁）一章之内讲得清，不用撑四章。

**三折怎么办。** 保留，当卷三终章（十二章）：品牌点在，成本 2，用一章就够——像卷一的「两人」只做终章。油纸的透光留给三折那一章作为纸的"状态变化"（spec §0「一张纸，三种状态」卷内仍成立：硬卡纸 → 终章折痕处透光），不换卷纸。如果十二章灰盒后三层可读性过不了 5 秒测试，终章改成滚 × 鹤 × 胶 × 影的组合关，三折推到卷四开卷。

**砍 / 挪：**

| 机制 | 处置 | 理由 |

## 3. 野点子（不进卷，留着）

1. **十字折 Cross Fold**——把 Duo 转 90° 握，铰链就横了：折痕从列变成行，镜像从 c→7−c 变成 r→h−1−r。plan §3 已说横竖屏两种折痕都支持，这是把它变成**一关里有两条折痕，用哪条取决于你怎么拿手机**。硬件决定折痕方向，没有任何一个 2D 游戏能做这个。问题：普通 iPhone 上退化成一个按钮；求解器要双轴镜像。留给某一卷的暗信，或卷五。
2. **盲信 Blind Letter**——一封纸是黑的信：烧过的页，棋盘不显示，只有声音模式（音高 = 行、音色 = 页、声像 = 位置）。把无障碍层变成明眼玩家的内容——「一本闭着眼也能读的书」从口号变成一关。ADA 的 Inclusivity 故事需要一个这样的镜头。风险：聋人玩家要有触觉 / 字幕的等价版；只做侧信，一卷一封。
3. **寄信 Post**——两台手机：你合上的那一页（盖印之后的棋盘），就是对方打开时的开局。不是关卡编辑器（砍过），是**你的终局是她的开局**：同一关两个人各解一半，中间隔着一次真正的"寄"。异步、一天一封。它把"两个人、一本书"的故事变成了两个真人。成本高（同步、存档、反作弊都不要——只传一张文本地图），但商店文案只需一句：「把你折好的信，寄给一个人。」
