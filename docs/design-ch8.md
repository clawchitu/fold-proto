## 1. 机制：灯换了岸

**一句话：灯挪到左岸了——现在是平放的左页上的石头，把影子投到你举起来的那一页上。**（两盏灯都亮时，两套影子同时在。）

### 1.1 规则（`logic.js`）

| 规则 | 代码 | 一句"纸会怎样" |
|---|---|---|
| 灯在哪岸是关卡属性 | `level.lamp`：`'R'`（默认，卷一三章起）/ `'L'` / `'LR'`；`create()` 存 `s.lamp`，`lampOf(s)` | 页边的灯笼挂在哪一页的外角，影子就从那一页起 |
| 左岸灯：左页石头的影子落到**抬起的那页**上 | `shadowColumnL(c, a)`：离铰链 d 格的左页石头，照到右页离铰链 `round(d·−cos a)` 格——`shadowColumn` 的镜像；`shadows()` 在 `lamp` 含 `'L'` 时也扫左页 | 影子贴着铰链起，**越合越往外滑（往第 8 列）**，合上那一刻正好是石头的镜像格——也就是那颗石头堵死的那一叠 |
| 两盏灯 | `lamp = 'LR'`：两套都算；同一格两道影子先到先得（先右灯后左灯） | 右页的石头照在左页，左页的石头照在右页，各走各的 |
| 抬起页上也能乘影 | `ride()` 按 `src` 在哪页选公式；`check.js` / `gen.js` / `play.js` / `slips.js` / `main.js` 的 onShadow 不再 `!isRight` | 站在右页缺口上的影子里，合书它带你往外走；合过 26° 或开过 89° 它没了，你掉下去 |
| 影子跟着石头换页 | 无新代码：胶把石头从右页粘到左页，它的影子就从左页搬到右页（只在 `L`/`LR` 下可见） | 第一合之后，**抬起页上长出一道新影子**（`made` 的右页版） |
| 翻页 | `at()` 已按 `face` 读第三页，`shadows()` 不用改 | 翻过去之后，左页石头的影子落在**第三页**上 |
| **角度门 `A`**（tile） | `shadows()` 在 lit 窗口（91°–154° 折角 = 物理 26°–89°）把每个 `A` 格放进地图（值 `'A'`）；`ride()`：站在 `A` 上，lit 就留下，不 lit 就掉；`cellBlock` 不 lit 时报 `door`；合上时 `A` 不是地面（叠只在另一面是纸时开） | 一片纸做的活页门：**页斜起它才立着**，能走；摊平或合上它就趴下，是缺口。站在上面把页放平或合到底，你掉下去 |
| 墨 / 胶 / 钥匙对门 | `bleed` 只洇 `-`/`g`；印只印 `-`；胶只粘 `x` | 门不吸墨、不印字、粘不走 |

**不做的**：灯的位置在关内改变（灯位是关卡属性，不是动作——"抬哪一页"也不做，Duo 的「任何一半都能抬」留给原生交互层，规则上右页抬起不变）；角度门有各自的角度窗口（objects.md 原案）——窗口统一等于灯的窗口，一句话讲得清：「灯亮着，门就开着」；第三盏灯、灯灭。

### 1.2 和每一条已有规则的相互作用

| 和什么 | 作用 | 哪关用 |
|---|---|---|
| **影**（三） | 方向反了：影子往**外**滑（往第 8 列），不往铰链滑；合上的终点是石头的镜像格 = 堵死的叠。卷一练出的"往铰链找影子"的直觉在本章是错的 | 8-1 起 |
| **乘影**（三 / 四） | 抬起页上的渡船：合书它带你**离开**铰链；开书带你**回**铰链。到底就掉（镜像格是石头的叠） | 8-1、8-2 |
| **石背**（P5-1） | 左岸灯下，石头的影子和石头的背是**同一列的两头**：影子合到底落在石背格上——先乘影到石背，再合，你就在 `#` 叠里 | 8-5、8-7 |
| **叠合换页**（P5-5） | 不变 | 全章 |
| **胶**（五） | 石头换页 = 影子换页：粘过来之后它照在另一页。两盏灯下，一次合同时**拿走**一道左页影子、**造出**一道右页影子 | 8-6、8-7 |
| **湿墨**（七） | 洇满缺口 = 影子落到纸上 = 不载人。抬起页上的渡船同样会沉；门不吸墨（门两侧的缺口会洇，门不会） | 8-5、8-7 |
| **翻**（六） | 翻 = 压（洇、印、粘）；翻过去后左页石头照在第三页上。翻之前合几次，第三页上洇几圈——`glance.js` 只印「合 → 翻」 | 8-7 |
| **角度门 × 合** | 站在门上不能合（会掉）：门是**只能路过**的格，合书的站位永远不在门上；合上时门那一叠只在另一面是纸时开 | 8-4 起 |
| **角度门 × 乘影** | 影子滑到门上就停在门上（门托住你，影子走它的）；乘影 → 过门 → 到纸，三件事要在**同一次斜起**里做完，中间不能摊平 | 8-4、8-5 |

### 1.3 为什么是 v3 的料

- **P1**：胶合之后抬起页上的新影子、翻之后第三页上的影子，一眼纸都印（VIEW 4b / 6b）——所以不靠它们藏；藏的是**在哪两次压之间**乘哪道（7 章的教训）。
- **P2**：乘到石背再合 = 进 `#` 叠，出得来进不去；门上不能合——两条都是"做了才知道站错了"。
- **P3**：胶先粘（第一合）影子才换页；墨洇到渡船底下就沉（第二合）——乘影必须夹在两合之间。
- **P6**：合的次数仍是资源（墨）；加上"灯亮着才能过门"，一次斜起要同时做乘影和过门。

## 2. 看起来：灯在桌子那头

纸仍是**信笺**（`design-v2c1.md` §2；三页规则同 `design-ch6.md` §2）。本章不加纸参数，换的是**光**：

- **灯笼换边**：三章的页角挂灯（`design-skins.md` §A.3 #18 `margin-lantern.svg`，光晕原点 `data-glow`）搬到**左页外侧页边**（`lamp: 'L'`）；两盏灯（`'LR'`）左右各一盏，右边那盏用三章的原资产。光晕原点跟着走：斜起时抬起页上的影子从铰链边起、往外滑，光晕从左页外角起正好解释方向。
- **影子**：同三章的方格影（高对比交叉线），只是画在抬起的右页上——右页本身有透视倾斜，影子**随页倾斜**（和三章"石狮竖直画、不随页倾斜"相反：影子是页上的东西）。两盏灯时两套影子同色（它们从不落在同一页）。
- **角度门 `A`**（新 tile，轮廓基元 = 门的基元：闭合框 + 挡，`objects.md` A.1）：一片**纸折的活页**，摊平时是贴在缺口上的虚线框（读成"这里有东西但不是地面"：格内一个开口向上的 U 形折线，1.4 pt，墨色 40%）；斜起到 26° 起**立起来**成一张小纸片把缺口盖住（260 ms，ease-out，和影子出现同一拍），面色和纸一样、四边 2 pt 墨线闭合框；合上 / 放平时趴下（同一动画倒放）。高对比：立起时实心框 + 格内「开」字样的两条短横；趴下时只剩 U 形。读屏：`gate`「活页门，斜起时开着」。
- **站在门上掉下去**：同"影子没了掉下去"的动画（纸人折叠落下 → 淡回起点），多一拍：门先趴下（120 ms）再掉。
- **声音**：门立起 = 纸片翻起的一声"啪"（短白噪 40 ms + 中频敲击），趴下同声低八度；影子落在抬起页上同三章。震动 [10]。
- **章印**：八「灯」`seal.muted`。页边布景：**两盏灯**（两页外上角各一盏；`'L'` 关只有左边的，右边只留挂钩——"灯搬走了"）。终点仍是信封；8-7 终点在第三页、信封**封口已拆**（卷二最后一封信，她拆了）。
- **三页**（8-7）：同第六章。
