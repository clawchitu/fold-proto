对象：`~/.tomo/workspace/tmp/fold/design/skins-{ch1,ch2,ch3,ch4,ch5,dark,hc}.jpg`（410 × 1200 手机帧；原尺寸逐张看过，棋盘区再裁到 1000 px 看过一遍，六张棋盘另做了 **1/4 尺寸全灰度**缩略条 `/tmp/skins/grey-sheet.png` 补帧 agent 没出的那一项）对照 `design-skins.md`（含 §6 十条偏差）和 `objects.md` A.1。角度一律物理角。对比度 WCAG 2.x，`node` 复核。**不碰 `levels.js` / `logic.js` / `main.js` / `style.css`。**

## 0. 结论：**go-with-changes**，不重画帧

§1 修底在七帧全部生效，这是本轮最重要的一件事，过了：路格 / 缺口 / 石头在 1/4 灰度缩略图里三者仍分得开，1-2 的两块石头是板上最深的东西（v14 里它们是两粒白卵石）。规则物件换皮后基元都还在。

主人的问题——**手机尺寸下皮到底加了魅力还是加了噪音**——答案分两半：

- **格内的皮（石头 / 终点 / 门 + 钥匙）是魅力。** 三种石头（石墩 方 · 缆桩 梯形 · 镇石 扁）在 55–72 pt 格里是三个不同的剪影；四种终点（朱旗 · 灯笼 · 收信人 · 信封）是四封信的故事落在终点格上；三扇门（篱门 方框 · 月洞门 圆框 · 闸 方框 + 板）一眼就是三个地方。这三样出现在每一关或题眼上，换它们等于换了棋盘的脸。**保留。**
- **页边布景是噪音的那一半。** 七样布景全部 ≤ 24 pt、≤ 2.4:1，在 1/4 灰度缩略图里**一样都看不见**，在原尺寸手机帧里要找才找得到。其中三样有活干（三章挂灯 = 光从哪来；四章芦苇 + 渡船 = 「岸」；二章桥栏 = 「立」的桥），四样没有（一章柳、五章邮戳、五章 / 暗信信封角）。**留三砍四**，格内布景（§2.3）和它的门禁（§7）整体**不进卷一 / 卷二的 App 建造**。

一句话：皮的魅力在**格子里、大的、每关都有的**东西上；页边只留能解释这一章的记号。建造按 §3 的清单，不等新帧——所有改动都是删除或参数，下一次看图是 App 自己的截图（§4）。
