## 1. 机制：翻

**一句话：合上的书可以翻个面再打开——左页没变，对面换成了第三页。**

### 1.1 状态模型

| 量 | 取值 | 说明 |
|---|---|---|
| 页 | 左页 L、右页 R、第三页 T | T 是**右页这一张纸的背面**。一关的地图一行 12 列：`LLLL RRRR TTTT`；T 的第 0 列贴着中缝（和 R 一样写），所以 T 的第 j 列合上时落在 L 的第 3−j 列——`mirror()` 不变 |
| 面 `face` | 0 / 1 | 现在和 L 相对的是 R（0）还是 T（1）。开局 0。屏幕上永远只有两页：第 4–7 列显示的是**对着 L 的那一页** |
| 网格 | 一张 12 列的网格，可变 | 钥匙开门、墨印、胶粘都直接写在这张网格上。求解器把它编码成"压过的次数链"：`g = press(g, face)`，内容相同就合并 |
| 纸人 | 可见坐标（0–7, r） | 第 4–7 列的纸人站在"当前对着 L 的那页"上。翻面时纸人**必须在 L**（下一条），所以它从不跟着纸翻 |

### 1.2 翻会发生什么（`logic.js`）

| 规则 | 代码 | 一句"纸会怎样" |
|---|---|---|
| 只有合上的书能翻 | `flipBlock`: `a < FOLD_MIN → 'open'` | 书打开着，翻的是整本书，没有意义 |
| 翻的时候你得站在**左页** | `flipBlock`: `isRight(char.c) → 'leaf'` | 你站着的那张纸翻不动（Duo 上：合上的手机翻面时，手握着的是不动的那半） |
| 没有第三页就没有翻 | `flipBlock`: `pages < 3 → 'single'` | 卷一、第五章的信只有两页 |
| 翻 = 换面 + 压 | `flip`: `face ^= 1`，然后 `stamp()` | 翻过去那一刻 T 压在 L 上：L–T 之间的**钥匙开门、墨印、胶粘**全部发生，和合上那一拍同一规则。翻回来（face 1 → 0）R 再压 L 一次：如果 T 那一拍把石头粘到了 L 上、而 R 对面有胶，石头会再被粘走——同一张网格，链式 |
| 翻过来会被压 | `flip` 返回 `crush`，用 `crushCause(…, FOLD_MIN)` 在盖印**之前**判 | 你站在 L 的 (c, r)，T 的镜像格是石头 → 石头落在你身上，回起点。和合上压人是同一条规则，同一句读屏 |
| 影子跟着面走 | 不改代码：`shadows()` 读第 4–7 列 | face 1 斜起时投影的是 T 的石头；R 的影子没了。**同一张左页，两套影子** |
| 压痕跟着面走 | 不改代码：`crushed()` 读镜像格 | face 1 合上，T 的石头落下来；R 的石头不在了 |
| 叠合跟着面走 | 不改代码：`foldOpen` / `land` 读镜像格 | 合着走时你在哪一页是走出来的（postmortem P5）；翻面之后同一叠的另一半换了，所以"能不能进这一叠"和"进去落在哪一页"都变了 |
| 终点可以在 T 上 | `isWin` 经 `at()` | face 1 时：合着走进那一叠，或翻过去打开走到她——「翻到最后一页，两人在同一页」 |
| 每翻一次 = 一次姿态变化 | `check.js` par 计 1 | 翻手机是整只手的动作；疲劳预算照算。合的次数不加（翻发生在一次合里） |

**不做的**：站在 R 上翻会"跟着纸翻到 T"（免费的瞬移，而且读屏说不清）；打开时翻（那是卷一砍掉的"翻面/外屏"）；第四页。

### 1.3 为什么有深度：翻和前面每一条规则都互相作用

| 和什么 | 作用 | 用在哪 |
|---|---|---|
| 叠合行走（一、P5） | 翻要站在 L：你在叠里的哪一页是走来的历史，所以**从哪一叠进、走到哪一叠再翻**是题 | 6-2 起每关 |
| 压（三） | 翻过来 T 的石头落在 L 上；R 的压痕消失。**翻之前站哪一格**和"合之前站哪一格"是同一个问题的第二问 | 6-3…6-7（`trap` 全为 1） |
| 影（三） | face 0 和 face 1 是两套影子；要先用 R 的影子走到位，再翻 | 6-3、6-4、6-5 |
| 乘影（三 / 四） | 乘影占两次姿态，翻占一次，合占一次：par 4 刚好——顺序一错就不够 | 6-6、6-7 |
| 胶（五） | 翻那一拍 L–T 之间的胶也粘；胶在角上等着，先合上就把路粘断（`before`） | 6-6 |
| 渡口（P3） | 同一格左页空格：对面是 R 石头 = 影子，对面是 T 纸 = 渡口。翻一下，影子变渡口 | 6-3、6-7 |

## 2. 看起来：信笺的背面

卷二的纸仍是**信笺**（`design-v2c1.md` §2）。第三页 = 这张信笺的背面：同一张纸、同一道淡格线，但 ① 色温暖一档（`filter: sepia(.18)`，`style.css`）；② **格线换成竖的**——正面横格、背面竖格，是信纸的常识，也是一眼分出"翻过没有"的办法，不靠色；③ 翻的瞬间右页淡出再淡入 0.5 s（减少动态：直接换）。中缝、朱线、纸人、描图纸、影子的交叉线全部同前。

**翻的动画**（建造）：合上的书绕中缝的垂线转 180°（像翻一张卡），350 ms，ease-in-out；转到一半时两页都是纸背；落下来时 `stamp` 的闪和 ch.5 的 `glue.pull` 同一拍。减少动态：换面 + 闪。**章印**：六「翻」`seal.muted`。终点在 T 上的关（6-7），`G` 画 ch.5 定下的信封（objects.md A.2）。

## 4. 自审：每关的"啊哈"，和为什么不能 30 秒蒙出来（对照 postmortem）

- **6-1 翻**：啊哈 = 合上的书还有一面。≤ 30 s 是目标；R 全空、信不在屏上，唯一能做的事就是找那个新按钮。
- **6-2 背面**：啊哈 = 站着的页翻不动。目标 ~1 min：第一反应"合上就翻"被挡（读屏 / toast 说原因），然后要在叠里找 R 是缺口的那一格——P5 的第一次复用。
- **6-3 两面**：啊哈 = 先用这一面的影子，再翻。不能蒙：第一步岔路 7 种（哪里合、哪里斜）；合在别处翻过去 T 的石头 (11,0) 堵死顶行；影子窗口 3 个采样角。
- **6-4 夹层**：啊哈 = 两块石头同一角度铺出顶行，而顶行是走过去的。不能蒙：2 个死局盆地（24% 的状态），合早了 / 翻在别的叠都进去；第一步 6 种岔路。
- **6-5 页边**：啊哈 = 底下那条诱人的长路是死胡同，台阶是 55° 那道影子。不能蒙：死局 35%、2 个盆地；影子只在 55°–60° 接上（窗口 3）。
- **6-6 压花**：啊哈 = 胶在角上等着，**先合就输**（`before` + `misdirect`）；乘影要朝打开的方向。不能蒙：死局 50% 的状态、2 个盆地，窗口 0（必须乘影），par 4 一步不能多。
- **6-7 末页**：啊哈 = 两块相邻的石头各干一件事（影子 / 翻过来的墙），合的那一格由头顶的石头定。不能蒙：第一步 8 种岔路、全程 19 种；乘影 + 唯一安全格 + 翻后的叠合路三件事串着。**弱点**：没有死局（§7），最像被主人 1 分钟解掉的一关。

对照 postmortem 的四条：① 棋盘不空（mid 以上 idle 68–78%，12 列口径）；② 死局不在第一步（6-4 / 6-5 / 6-6 的盆地都在第 2–3 个决定之后进入，而且进入的那一下看得见——翻过来石头落下、胶把石头粘过来）；③ 每关 ≥ 2 个前章机制（叠合 + 影 / 压 / 乘影 / 胶）；④ 关名是物件（翻、背面、两面、夹层、页边、压花、末页），顺序和角度在「?」第一级。

## 6. 无障碍

**VoiceOver**：
- 控件：「翻」按钮（`pre.flip`），只在合上时可用；键 **T**；大按钮栏里同名。按不了时读原因：`no.flip.open`「先合上，才能翻」、`no.flip.leaf`「你站在要翻的那一页上」、`no.flip.single`「这封信只有两页」。
- 翻那一拍（`bus 'flip'`）：`turned`「翻过来了：左页对着第三页」/ `turnedBack`「翻回来了：左页又对着右页」+ 压印事件（`doorOpened` / `inkPrinted` / `glued`）+ `connected` / `lost`（翻之后立刻跑一次 `checkReach()`——死局进入点在这里，不是在合上）+ 被压 `crushedFlip`「翻过来的那页上有石头，正压在你这格。回到起点」。
- 「我在哪」报 `thirdPage`「第三页」；格子标签经 `F.at()` 自动读对着 L 的那页，不用新字；进章 `paper.ch6`。
- 待建造：翻的 ARIA 网格说明（`gridHelp`）补一句"T 翻页"。

**高对比**：第三页不靠暖色——右页加 3 pt **虚线内框**（`body.hc[data-face="1"]`）+ 竖格线；石头 / 门 / 胶的花纹同前。**运动**：42 关只用 15° 一档全解（`check.js` 断言）；本章的角都在档上：60°（6-3、6-6 乘到）、40°（6-4、6-6 起步）、55°（6-5、6-7 起步）、50°（6-7 乘到）；翻不要求速度，是一个按钮。**减少动态**：翻 = 换面 + 闪。**声音**：翻 = 纸的 crease 音 + 短震动 [20, 40, 20]；压印同前。
