## 0. 结论：**GO-with-changes**，不开重画轮

物件画对了：圆的松石和方的定石在 45 pt 真尺寸、灰度、高对比三遍里都分得开；四连拍的方向、拍数、填缺口都对规则；硬卡纸的压痕格进得了「一张纸，三种状态」的族谱。要改的都在**规格层**，原生按 §3 直接建，不回 Claude Design：

4. **V4 笺图太小**（§2.5）：两张 2 × 4 小图格子约 22 pt，低于 28 pt 下限；按 §3.7 横排两拍重排，格 ≥ 28 pt，第一拍的页要画成斜的。

## 2. 七条裁决

### 2.1 松石 vs 定石在 45 pt：**过**

V2 真尺寸条（45 pt）和灰度条：球有球的高光 / 暗边 / 接触影，定石是一块平的深方块——不靠颜色，靠**形 + 浮雕**，灰度下仍是「一圆一方、一凸一平」。高对比条：圆点阵圆 vs 斜线方，3 pt 轮廓都在，缩到 45 pt 点阵还是点阵。两条都过。只改一处：V2 的高光接近纯白，比纸还亮——高光最亮不许亮过纸（§3.3），否则缩略图里球心被纸吃掉、只剩一个暗月牙。

### 2.2 硬卡纸皮：**进族谱**，带 5 个数

spec §0 第 1 条「每章只改 4 个参数 + 1 套皮」：卡纸改的是纸色、透光（0.08，全书最不透）、墨饱和、背光，皮是「浮雕格 → 压痕格 + 看得见厚度的页边」——格子的边是格子的画法，不算线（spec §0 第 2 条），没有新线、没有新色相、没有朱红的新用处。V1 的压痕格（面色深一档 + 上暗下亮的内凹边 + 1 pt 全周边线）就是 skins §1.2 修过底的路格倒过来做浮雕，1/4 缩略图里路 / 缺口 / 两种石头四样分得开。**判：GO**。数值见 §3.1–3.2；页边厚度只在**外边和侧边**画，折痕边不画（厚度是页的，折痕是书的）。

### 2.3 松石的球：**留立体，收着画**

这是全书第一个有体积的物件。它必须是球——「圆 = 没粘住」是规则，不是装饰；皮影纸人、平的石头旁边站一颗球，正是「这颗和别的不一样」。收三处：① 高光 ≤ 纸的亮度，② 两段渐变不做镜面反射点，③ 接触影一枚椭圆、不拖长影。不加纹理、不转花纹——滚动靠位置 + 挤压 + 接触影读出来，球面一转纹就成了第三种石头花纹（§3.3、§3.5）。

### 2.4 章首（V5）对 `ChapterOpener`：**按族重排**

`LevelScreen.swift` `ChapterOpener`：卷二卡的顶上一行「— 卷二 —」（15 pt 宋体、字距 4、两侧 22 × 1 的线），下面数字「五」30 pt 粗宋、章名「胶」**150 pt 黑宋**（英文 52 pt 粗）、规则句 19 pt `ink.700`（1.0 s 后淡入）、小书 150 × 150（上距 22），纸色从上一章的纸擦到本章的纸（`WipeShape` 0.6 s），2.6 s 自动关或点一下关。V5 的差异和裁决：

### 2.5 V3 (c) 的拥挤与 V4 的小图：**球不缩；笺图重排**

**(c)**：90° 时页按 `squash` 压到 ≥ 0.3（spec / vol3 §4 ①），格 80 pt 的行距压到 24 pt，而球 Ø 51 pt——这不是画挤了，是**球不该跟着页压**。球是立在页上的东西（和纸人、三章石狮一类，竖直不随页倾斜），剪影在任何视角都是整圆；定石是贴在页上的方块，跟着页压扁。于是 90° 那一帧：平的方块压成细条、圆球还是圆球——松石和定石在最窄的一帧反而最好认。球溢出它的行是设计，不是 bug；用画家顺序（屏幕 y 小的先画）让靠折痕的球盖住远的。接触影跟着页压（§3.5）。

**V4**：两张小图各 2 × 4 格，格约 22 pt，球约 14 pt、纸人约 16 pt——低于 skins §5「最小可见特征 1.2 单位」在 cell 28 pt 以下的底线；而且第一拍「斜起」的页画成平的，和「经过 90°」的文字对不上。笺的文字（`slip.roll`）和 `i18n` 一字不差 ✓，「收起 ›」、章节栏 ✓。重排按 §3.7：两拍**横排**在文字上方，各 2 × 4 格、格 30 pt，第一拍页画成斜起的梯形（和 `LampBook` 同一种画法）。

### 2.6 V3 (d) 纸人头顶的红圈：**去掉**

放大看（`V3-roll` x 880–1140, y 170–300）：纸人头顶是一枚空心红环，和 V1 朱线起点的环同形同色——是帧脚本把「起点环」画在了纸人所在格、又把纸人画在了环下面。两条族规都不允许：① spec §0 第 3 条，朱线**跟在纸人身后**，一步没走就没有线，起点环随第一针出现；② 纸人（`ink.figure`）上不落任何朱红——朱红只在线、旗、印、钥匙环上（skins §2.4）。层序：朱线在格上、松石上、纸人下（§3.4）。(b)(c) 围着纸人和球的虚线弧同理去掉（见 §0 第 2 条）。

### 2.7 地图卡（V6）：**族里的卡，改两处**

`Screens.swift` `ChapterCard`：数字 28 pt 粗宋 + 章名 17 pt 半粗、下半格「n / 总」+ 状态 + ◇（进行中）或印（已达）、纸色按章、未启封 = 右边一根绳 + 蝴蝶结、`soon` = 虚线框卡。V6 的「九 滚 · 0/7 · 进行中 ◇」和这个一模一样 ✓；卷名「倾」做页标题、卡左右交错、朱线从顶下来到进行中的卡打个结再变灰线 ✓（卷二页同款）。改两处：① 十、十一、十二没画，是 `soon` → 虚线框「未写」，不是绑绳「未启封」；② 卷三的卡纸色是卡纸（`ChapterCard` 的 `paper` 数组现在 `min(8, id − 1)` 把第九章起都落到信纸，要加卷三一项）。返回键按卷二页的写法「‹ 卷二《…》」，不是 V6 的「‹ 书」。第九章的印字待定（§4）。

### 3.4 层序（上页，按屏幕 y 从小到大即从外边到折痕）

格（路 / 缺口）→ 影子 → 定石 → 朱线（含起点环）→ **松石**（按 y 升序，靠折痕的后画、盖住远的）→ 纸人 / 她。松石和纸人同一格 y 比较时纸人在上。读屏：`kind.r`「松石」；格子句「第 n 行第 m 列，松石；上页立起时会往折痕滚一格」。

### 3.5 滚动动画（75°–105° 窗口；规则只在跨 90° 那一拍）

记 `u` 为窗口进度（0 = 刚进窗口，1 = 出窗口）：**从上面进**（合的方向，105° → 75°）`u = (105 − a) / 15` 截到 [0, 1]；**从下面进**（开的方向，75° → 105°）`u = (a − 75) / 15`。球沿「往折痕」的轴（屏幕向下、按页的透视）偏移 `s(u) = u²(3 − 2u)` **格**（smoothstep：u = 0.5 即 90° 时正好 0.5 格——两格中心的中点）。

| 阶段 | 角度 | 画面 | 触觉 / 声 |
|---|---|---|---|
| 进窗口 | u 0 → 0.5 | 球从原格中心滑向中点；接触影随页压扁；手指拖动时**按角度驱动**（0 ms，1:1 跟手） | 每 15° 的 Selection tick 照旧 |
| 跨 90° | u = 0.5 | 引擎 `roll()` 提交（球的逻辑格变成 c − 1，或消失并把 c − 1 改成 `.`）；画面连续，不跳 | — |
| 出窗口 | u 0.5 → 1 | 球滑到新格中心（s = 1）；到位时**挤压** 60 ms：x 1.06 / y 0.94 → 1 / 1（ease-out） | Impact **.soft 0.6**；厚纸闷响（暂借 `sound.slide`，低 3 个半音） |
| 落进缺口 | u ≥ 0.85 | 球缩到 0.86 Ø 并下沉（被格裁掉下半），u = 1 时消失；新路格面色淡入 180 ms；§3.3 的环 600 ms 淡出 | Impact **.rigid 0.7**；闷响 + 一声短的「嗒」；读屏 `rolledIn` |
| 没跨 90° 就回头 | u 没到 0.5 | 球沿同一条曲线**退回原格**（「摇一下不滚」，vol3 §4 ①），不挤压、不响 | 无 |
| 被纸人挡住 | 任何 | 球不滚；u 在 0.35–0.65 之间做 ±0.12 格的摇，90° 处最大，出窗口回 0 | Impact .light 0.4；toast `rollHeld`「你挡住了松石」 |
| 一列松石 | 同一窗口 | 全部一起按同一个 u 动（引擎已经按靠折痕的先算好了终点）；前一颗掉进缺口、后一颗滚到它腾出的格，画面上就是一列同时往下挪一格 | 一次触觉，不叠加 |
| 松手 / 吸附 | `hinge.release` 160 ms、`close.snap` 220 ms | 球改为跟随吸附的角度补间，等于仍按角度驱动；若吸附把角度一下跳过窗口，球用 **180 ms ease-out** 补完 s → 1 | 同上 |
| 连续两次过立（一次拖动里 80° → 100° → 80°） | 两次提交 | 第一次出窗口前第二次已开始：球从当前画面位置起算新的 s，不回跳 | 两次触觉 |
| 合上那一拍 | a → 0 | 窗口动画按 `close.snap` 的 220 ms 走完，然后才是 `page.press` / 压 / 印 / 粘——**先滚后粘**（ch9 §1 表末行） | — |
| 减少动态效果 | — | 不做角度驱动位移：跨 90° 时球 200 ms 交叉淡化到新格；填缺口 = 球淡出、路格淡入；无挤压 | 触觉照旧 |

**滚完之后**（出窗口或吸附停稳）：读屏播 `rolled`「松石滚到了第 n 列」/ `rolledIn`「松石掉进缺口，那里是纸了」（多颗只报最靠折痕的一颗，`main.js:302` 同）；影子按滚后的图重算（引擎已这么做）。
