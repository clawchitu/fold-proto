# 《折信》物件计划：皮与骨（2026-10-19）

主人（10/19）：「道具物件是不是可以丰富一下，还是说后面会丰富。」答：**两层都做，但分开做。**

今天棋盘上一共 9 样东西：纸人 ×2、石头 `x`、门 `D` / 钥匙 `k`、墨 `i`、纸片 `p`、影子（不是 tile，是石头的第二重身份）、灯（只有光晕，没有灯）、胶 `g`（卷二）。35 关里它们反复出现，看久了确实"就这几样"。但稀疏有一半是故意的：`design-spec.md` §0 第 4 条「只画 `levels.js` 里有的元素」和 `roadmap.md` §3「一章最多一条新规则」——**规则面小，题才深**（`design-difficulty.md` §1 的结论是难度来自机制互相作用，不是机制多）。所以"丰富"要分两层：

- **A. 皮**：不加规则，给已有的规则物件换**章皮**（同一块石头在四章里是石墩、石狮、缆桩、镇石），再加一层**不参与玩法的布景**（柳、桥栏、灯笼、渡船、信封）。规则：轮廓不变、布景不占玩法格、一眼仍读得出棋盘。便宜，卷一就能上。
- **B. 骨**：新的规则物件按 roadmap 的节奏来，**一章一样**，结构机制（翻页、三折、灯位）和物件机制交替，所以任何时刻玩家要记的规则 ≤ 5 条。

本文是计划，不出图。角度一律物理角（180° 摊平、90° 立起、0° 合上）。

---

## A. 皮：不加规则的丰富

### A.1 三条不可破的规则

1. **轮廓不变**。每个规则物件有一个**轮廓基元**，所有章皮都必须保留它，高对比花纹（spec §7）也不变。皮只能改基元之外的东西：纹理、顶饰、边缘、色相（在纸参数允许的范围内）。

   | 物件 | 轮廓基元（所有皮必须有） | 高对比（不变） | 皮可以改 |
   |---|---|---|---|
   | 石头 `x` | 实心深色块，占格 ≥ 60%，无开口 | 45° 斜线 + 3 pt 轮廓 | 外形（方 / 兽 / 桩）、顶部剪影、纹理 |
   | 门 `D` | 一个框 + 中间的锁孔 / 竖闩，读作"挡着" | 3 pt 门框 + 锁孔 | 框的形状（方 / 圆 / 篱）、材质 |
   | 开了的门 `o` | 同一个框，中间空了，虚线 | 虚线框 | 随门 |
   | 钥匙 `k` | 一个环 + 一根柄（或一根绳 + 一个坠子），小而孤立 | 实心钥匙轮廓 | 环的形状、柄头、材质 |
   | 墨 `i` | 不规则的湿黑块，有飞溅点 | 实心笔触块 | 溅点的数量和方向、饱和（跟章的墨饱和走） |
   | 纸片 `p` | 跨中缝成对的 V 折 | 横条纹 + 3 pt 框 | 纸面的纹（素 / 木纹 / 格线） |
   | 胶 `g` | 琥珀椭圆 + 滴形线稿 | 黑点阵 + 滴形线 | 不改（卷二刚上，先让人认熟） |
   | 终点 `G` | 一个**竖立的小东西**在格子里（旗 / 灯 / 人 / 信） | 双框 | 竖立物的身份（见 A.3） |
   | 纸人 | 拐杖 / 发髻 + 提灯 | 轮廓 | **不改**。两个人是全部演员，皮会动摇"同一个人" |
   | 影子 | 整格方形 + 交叉线 | 交叉线 + 虚线框 | **不改**。影子是三章以后的核心读法 |

   **判定**：一张截图 5 秒，10 个没见过这一章的人指出每个规则物件是什么；任何一个物件 < 9/10 这张皮不上。色盲三列模拟（spec §7）和 40% 灰度各看一遍。

2. **布景不占玩法格**。布景（柳、桥栏、灯笼、渡船、信封、印章）只能在两处：

   - **页边**（`--pad` 那一圈，格子外）：页的外边和上边。**不许靠中缝**（spec §0 第 2 条：中缝旁不能有任何像线的东西），不许盖住页角（页角是拖页的热区）。
   - **惰性格**：求解器证明在**所有可达状态里**都不是路、不被影子盖、叠合时对面也不是纸、不会被墨印到、不会被胶搬石头过去的格子（`check.js` 新增 `inert(level)`，枚举现有的 `analyse()` 状态即可）。布景放进惰性格还要满足：≤ **10%** 的格子（4×5 两页 40 格 → 最多 4 格）、不在中缝两列（第 3、4 列）、不与起点 / 终点相邻、同一行不超过一个。
   - 布景的对比度对纸 **≤ 2.5:1**（有意低于 3:1 的图形阈值——它是"纸上印的"，不是"纸上放的"），不用朱红、不用 `ink.figure` 黑、不用实心块 ≥ 40% 格（那是石头的基元）、不画环（那是钥匙）、不画框（那是门）。
   - 高对比、降低透明度、超大格子三种模式下**格内布景全部关掉**，页边布景保留但降到 1.5:1 以下。读屏不读布景；转子「物件」里没有它。

3. **一章一套皮，跟纸走**。spec §0 第 1 条"每章只改 4 个纸参数"扩成 **4 个参数 + 1 套皮**：皮由章决定，和纸一样是章的属性，关卡不能单独挑皮（否则皮变成提示）。实现上就是 `main.js` 第 93 行的 `SPR` 按章换一组 SVG（`body.dataset.chapter`，和第 107 行 `dataset.paper` 同一处设），CSS 不动布局；布景放一个新文件 `dressing.js`（关 id → `[{c, r, kind}]` 或页边 `[{edge, kind}]`），`check.js` 对它断言 A.1 第 2 条。**不碰 `levels.js` / `logic.js`。**

## B. 骨：新规则物件的节奏

### B.1 原则

- **一章只加一样**（roadmap §3）。结构机制（翻页、三折、灯位、纸人的影子、两人同走）不加 tile；物件机制加一个 tile。两种**交替**，所以每卷的新 tile 是 2 个，玩家任何时刻要认的 tile ≤ 9（现在 8：`. - x k D o i p g`，加上影子）。
- 进 `logic.js` 的三条门（roadmap §3）：纯函数、求解器能枚举（可变地图要能编码进状态键）；读屏一句话说清这格合上 / 斜起会怎样；高对比有花纹不靠色。下面每样都给了"状态键"一栏——这是成本的真正来源。
- 新 tile 的轮廓基元在立项时就定（A.1 表加一行），皮随卷的纸走。

### B.3 六个新物件（和折 / 角 / 影 / 胶的化学反应）

每个给：一句规则、为什么是铰链、和已有物件的相互作用、状态键、难度潜力 1–5、成本 1–5（低 = 便宜）、轮廓基元。

**1. 秤 / 压板 `_`**
- **规则**：压板是纸，能走；**只在书合上、而且它那一叠里有石头或纸人时**算"被压住"；被压住时，和它配对的门开着（或配对的缺口补上）。打开，压力消失，门又关上。
- **铰链**：合上就是重量。影子**没有**重量——光压不住板。这是第一个区分"影子"和"石头"的物件。
- **相互作用**：胶把石头搬到压板对面 → 合上就压住（胶的第二用法）；乘影到压板上再合 → 你自己是重量，但门只在合着时开，所以要**合着走**穿门（叠合行走第一次有时限）；纸片桥和压板不能同时成立（桥要 60°–120°，压要 0°）。
- **状态键**：无需新增——压不压是 `mode === 'fold'` + 叠合内容的纯函数。
- **难度 4 · 成本 1**。轮廓：一块略下沉的方板，四角四个小点（铆钉）；高对比：方框 + 四角点。

**2. 风铃 `b`**
- **规则**：挂在中缝某一行的铃；页**每经过**它的角度一次（比如 90°），铃响一声，和它配对的翻板在"纸 / 缺口"之间翻一次。
- **铰链**：不经过 90° 就到不了 0°——每一次合上都必然摇一次铃。姿态次数第一次成了奇偶谜题，和 par 直接相撞（这就是难点）。
- **相互作用**：和纸片桥同角（60°–120°）——过桥时铃已经响过；乘影要连续改角，可能来回经过铃好几次；墨晕"每合一次洇一格"和铃"每过一次翻一次"是同一种资源的两张脸，放不同卷。
- **状态键**：翻板的奇偶 1 bit × 铃数。
- **难度 3 · 成本 2**。轮廓：中缝上的一个小钟形 + 一根坠线；声音模式里是全游戏唯一的高音。无障碍：翻板状态有花纹（纸 / 缺口本来就分得开），铃响有触觉 Selection + 字幕。

**3. 水 / 冰 `~`**
- **规则**：摊平和合上时是冰，能走；上页斜起（灯亮，91°–154°）时**被光照到的冰**（即不在任何影子里的冰格）化成水，不能走、不能站——站着时化掉就落水回起点；页放平（≥ 155° 或 ≤ 90°）又冻上。合上时冰被压碎：那一叠里冰按缺口算。
- **铰链**：灯 = 角度（roadmap #11）；"影子里的冰不化"把三章的影子反过来用——**影子第一次是保护而不是路**。
- **相互作用**：石头的影子护冰（影随角滑，护的格也滑：乘"影护冰"走）；胶搬石头 = 搬影子 = 搬保护；墨印到冰上？不印（湿的）；窗（#8）的光斑点化一格冰——两者是同一卷。
- **状态键**：无需新增——化不化是角度 + 影子的纯函数（影子已在状态里）。
- **难度 4 · 成本 3**（画面要做"化"）。轮廓：浅色格 + 一道裂纹；化成水后是波纹；高对比：冰 = 格内一道斜裂线，水 = 三道横波。

**4. 镜 `m`**
- **规则**：镜是石头的一种（挡路、挡光、合上会压），但在下页被影子打到时，把影子**折 90°**，沿自己所在的列继续往下（或往上，看镜面 ╱ ╲）投到第一块石头 / 页边为止。
- **铰链**：角度只控制影子在行里的一维位置；镜把一维扫成二维——转一度，另一列整条影子跟着挪。只有连续的角度输入才能"找"到那一度。
- **相互作用**：乘影可以**竖着**走（沿反射的影子）；胶能把镜粘到对页（镜是石头类）——镜到了上页就只是一块挡光的石头，反射没了；三折（卷三）两次镜像 + 镜的一次反射，是卷三终章的题。
- **状态键**：无需新增（纯函数：影子 → 反射影子）。
- **难度 5 · 成本 2**。轮廓：实心块（石头基元）+ 一道对角亮线；高对比：斜线 + 一条对角实线。读屏：「镜；斜起时把第 n 列的影子折到这一列往下」。

**5. 纸鹤 `h`**
- **规则**：纸鹤是纸，能站。书**每完全合上一次**，它飞到对页的镜像格（站在它上面的纸人跟着走）；镜像格是石头 / 门就飞不动。
- **铰链**：合上 = 起飞。它是"会换页的地面"——不靠叠合、不靠纸片桥，第一次有了一个**每合一次就换一次岸**的渡船。奇偶（合一次在那边、合两次回来）和 par ≤ 3 的预算相撞。
- **相互作用**：落在墨上 → 翅膀染墨，下一次合上把墨印到它落的地方（纸鹤变成会飞的墨）；落在胶上 → 被粘住，不再飞（胶的第三用法：定住）；斜起时纸鹤是纸不是石头，没有影子；三折（卷三）里"镜像格"是两次镜像之后的格——纸鹤飞过两折。
- **状态键**：每只鹤在哪一页 1 bit（+ 染墨 1 bit）。
- **难度 4 · 成本 2**。轮廓：一个尖角朝上的折纸剪影（和 V 折纸片区分：纸片是跨中缝成对的横 V，纸鹤是单格竖立的尖）；高对比：折纸轮廓线 + 内部一条折线。叙事：纸鹤替人送信，是卷三「三折」的本义。

**6. 封蜡 `s`**
- **规则**：蜡是纸。第一次合上时，蜡和它对面的格子**永久粘成一格**：此后打开时这两格之间也能走（唯一一个不靠角度的跨中缝通道），但这一叠在合上时**只算蜡这一面**（对面的东西被封住：石头不压、墨不印、钥匙不开）。
- **铰链**：合上 = 封。它把"合上才相通"的核心规则在一格上永久化——也就永久丢掉了那一格的所有"合上"效果，是一次有代价的交换。
- **相互作用**：封住石头 = 关掉它的压和影（它在上页也不投影了，蜡遮住了光）——是"胶把石头搬走"的另一种解法；封住门 = 门永远开不了；封住纸片 = 桥不用立也通，但只有那一格；墨晕（七章）在蜡上不洇。
- **状态键**：封 / 未封 1 bit × 蜡数（和胶一样，第一次合上全部同时发生）。
- **难度 4 · 成本 2**。轮廓：圆形的滴蜡 + 中间一枚小印痕；高对比：圆 + 内部一个小方。叙事：信封好了——卷二的末章或侧信。

### B.4 一句话比较

| 物件 | 它改变的是 | 和它最像的已有物件 | 怎么一眼分开 |
|---|---|---|---|
| 压板 `_` | 合上时的"重量"有没有 | 纸 | 四角铆钉 |
| 风铃 `b` | 姿态变化的次数 | 纸片（都在中缝） | 钟形 vs V 折 |
| 水 / 冰 `~` | 角度决定哪里能站 | 缺口 | 裂纹 / 波纹 |
| 镜 `m` | 影子的方向 | 石头 | 对角亮线 |
| 纸鹤 `h` | 哪一页有地面 | 纸片 | 单格竖尖 vs 成对横 V |
| 封蜡 `s` | 合上效果的有无（永久） | 胶 | 圆 + 印 vs 椭圆 + 滴 |

每个进章前走 roadmap §3 的八步；灰盒先用现有的字符 / CSS 占位，皮在章稿里定。
