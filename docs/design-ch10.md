## 1. 机制：纸鹤

**一句话：一格折成鹤的纸，能站。书每压一次——合上、翻过去都算——它就飞到对页同一行的镜像格，站在它上面的人跟着飞。落点被占它就不飞；它每次都飞，不管你要不要。**

| 规则 | 代码 | 一句"纸会怎样" |
|---|---|---|
| 鹤是纸 | `isFloor` 含 `h`；不挡光、不挡路 | 能站，能走过去；对面有石头时它是纸不是石背——站在左页的鹤上合书，石头照样落在你身上 |
| **每压一次飞一次** | `stamp()` 末尾 `fly(s)`：所有鹤按压之后的图一起判 | 合上飞，翻也飞；它飞走的格变成纸 |
| 飞到镜像格 c → 7 − c | `mirror(c)` | 「你那页同样的位置」在你那页是反过来的 |
| **载人** | `carried(events, fig)`：站在 `cells[0]` 的人到 `to` | 合着的时候你还在同一叠，打开才发现在对页——全书第二种换页方式 |
| 落点是纸 / 缺口 → 落下 | `.`/`-` → `h`，原格 `.` | 落在缺口里的鹤是地板；它再飞走，那格是纸 |
| 落点是湿墨 → 染 | 原格变 `I`，不飞，`inked` | 鹤成了一滴墨，下次压它自己会洇 |
| 落点是胶 → 粘住 | 两格都成 `.`，载人最后一次，`glued` | 胶粘得住鹤 |
| 落点是别的 → 不飞 | 石头、松石、门、活页门、钥匙、干墨、她、起点、另一只鹤 | 落点被占 |
| **同一次压的顺序** | 滚（过 90° 那一拍，扫描里）→ 洇 → 钥匙 / 墨印 / 胶粘 → **鹤飞** | 松石先滚进落点，鹤就不飞（10-4）；湿墨先洇进落点，鹤就染了（10-5） |
| 翻也是压 | `flip()` 里 `stamp` + `carried` | 左页的鹤飞到第三页的镜像格，带着你（10-6）；右页的鹤翻到背面去了，不飞 |
| 鹤挡松石 | `roll()` 前面不是 `.`/`-` 就不动 | 鹤前面的松石滚不过来 |

**求解器**：`check.js` `grids()` 的 `press(g, face)` 旁边记一张 `flights`（哪格的鹤飞到了哪），`carry(g, face, fig)` 给出压之后人在哪；`move()` 合上那一拍、`flipOf()` 翻那一拍都过 `carry`。图本身不依赖人站哪，所以图链的去重不变。`needsCrane` = 把 `h` 全改成 `.` 后无解。`gen.js` 新计量 `carries`（解里把人带到对页的压的次数）、`--carries N`、`--need crane`。`hunt.js` 谓词 `soak` / `ground` / `over`（§3.1）。

## 2. 看起来

硬卡纸不变（`paper.ch10`「硬卡纸。角上折了只鹤。」）。鹤是一格纸上的折线轮廓（`main.js` `SVG.h`：空心轮廓 + 一条折线，高对比下同样成立），合上时扑一下翅膀——原型里先用 `flash` + `placeChar(true)`，落点那格闪一下；读屏 `kind.h` / `noun.h`「纸鹤」，载人报 `carried`「鹤带你飞到了第 n 列」，飞不动报 `craneStuck`，染墨 `craneSoaked`，粘住 `craneGlued`。

## 7. 决定 / 开放问题 / 下一班

- **决定**：胶和鹤只有"鹤落在胶上被粘住"一种关系（§1 纠正）；湿墨染鹤时鹤留在原地变 `I`（而不是消失）——这样它自己成了墨源，10-5 整关建在这上面；鹤落在缺口里是地板、飞走之后那格是纸（一只鹤来回飞两次，两格都成纸）；两只鹤面对面谁也不飞。
