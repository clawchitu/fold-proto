## 1. 机制：松石

**一句话：没粘住的石头。书立起来——铰链经过 90°，不用合上——它就往折痕滚一格；滚进缺口，缺口就成了纸。它不会滚回来。**

| 规则 | 代码 | 一句"纸会怎样" |
|---|---|---|
| 松石 `r` 挡路、投影、压人都和石头一样 | `isBlock` / `isOpaque` 含 `r`；`cellBlock` 报 `stone` | 圆的石头，方的石头，都是石头 |
| **每经过一次 90° 滚一格** | `standing(a) = a ≥ 90`、`passes(a0, a1)`；`roll(s, fig)` 在扫描里跨过 90° 那一拍调用（`check.js` / `gen.js` `move()`、`play.js` / `slips.js` / `main.js` 的 5° 扫描） | 斜起算一次，放平算一次，合上算一次，合上之后摊平又算一次；合上之后只开到斜起（没过 90°）不算 |
| 往折痕滚 | 只扫第 4–7 列，c → c−1；第 4 列是最低处 | 低处是折痕 |
| 前面是纸就滚，缺口就填 | `.` → 石头过去、原格成纸；`-` → 两格都成纸、石头没了 | 掉进缺口的石头是桥 |
| 前面是别的就不动 | 石头、门、活页门、墨、胶、钥匙、她、起点、**纸人** | **你站在它前面，它就不滚**（9-4） |
| 靠折痕的先滚 | 列循环从第 5 列起 | 一列松石一起滚；前面一颗掉进缺口，后一颗滚到它腾出的格 |
| 左页不滚；翻页后第三页滚 | 读写走 `at` / `put`（按 `face`） | 谁被抬起谁滚（`design-vol3.md` §4 ②） |
| 胶粘松石 | `stamp()`：胶对着 `x` 或 `r` 都粘，到胶上是 `x` | 粘住了就不滚了 |
| 同一次铰链动作里的顺序 | 滚 → 影子按新图 → 合上压（洇 → 钥匙 / 墨 / 胶） | **合书压的是滚之后的格**（9-5）；**先滚后粘**（9-6、9-7） |

**求解器**：`check.js` `grids()` 的图链加了 `roll(g, face, fig)`，和 `press` 一样按内容去重；`move(B, s, a)` 在 5° 扫描里跨 90° 时换图，扫描完再压。状态仍是 `(c, r, a, face, g)`。`needsRoll` = 把 `r` 全改成 `x` 后无解。`gen.js` 新计量 `rolls`（解里滚过石头的铰链动作数）、`fills`（其中掉进缺口的次数）；`phases` 对照的是同一次扫描滚过之后的图，所以只滚不压不算 phase；`made` 认滚过的松石的影子。

## 2. 看起来：硬卡纸

纸换硬卡纸（`design-vol3.md` §1.1）：压痕格、松石是圆的（`style.css` `data-kind="loose"`：径向渐变 + 圆角 50%；高对比：圆点阵 + 3 pt 轮廓，和石头的斜线分开）、滚动有厚纸的闷响（先借 `sound.slide`）。90° 可见性：`applyAngle` 的 `squash ≥ 0.3` 已保证页在 90° 不缩成线；滚动动画在 75°→105° 的窗口里播，规则在跨 90° 那一拍触发（`design-vol3.md` §4 ①）。读屏：`kind.r`「松石」；滚了报 `rolled`「松石滚到了第 n 列」/ `rolledIn`「松石掉进缺口，那里是纸了」。
