## 1. 先修底：路格 / 纸 / 石头的对比

### 1.1 问题

`~/.tomo/workspace/tmp/fold/v14-levels.jpg`：1-2、3-5、4-6 的路格几乎和纸同色，只靠一条 1 pt 投影分开；5-7 / 暗信因为信笺有印好的格线反而读得出。原因是两处实现都把路格面色定成「纸 + 7.5% `#8A7A62`」：

- App：`~/code/letterfold/App/Sources/Theme.swift:74` `tileFace = color.mix(with: #8A7A62, by: 0.075)`，实测 **1.08:1**；再叠一圈左上白描边（`Paper.swift:185`），边缘比纸还亮。
- 原型：`style.css:111` `.tile { background: var(--card) }`，`--card #FFFDF9` 比纸 `#F7F4EE` **更亮**（1.03:1）。

spec §4「路格比纸深一档」写了，但「一档」没给数。石头也一样淡：`#D3CCBF→#B9B1A3` 渐变在新纸上只有 1.45–1.94:1，1-2 的两块石头读成两粒白卵石。

### 1.2 目标（玩法图形 ≥ 3:1，WCAG 1.4.11）

路格是「纸上压出来的格」，面色不能深到 3:1（那是灰卡不是纸）。所以**面色负责一眼分层，边线负责达标**——和合上时的描图纸规则（review-3 §closed：1 pt 实线边 `#7D7163`，4.04:1）是同一个语言，spec §0 第 2 条已说明「格子的边是格子的画法，不算线」。

| 元素 | 规则 | 数值 |
|---|---|---|
| 路格面色 `tile.face` | 纸 mix **25%** `#8A7A62`（原 7.5%） | 新纸 `#DCD6CB` 1.32:1 · 米纸 `#D9D0C2` 1.31 · 背光 `#D7CDBB` 1.30 · 旧纸 `#D6CBB6` 1.29 · 终章 `#D3C7AE` 1.28 · 信笺 `#DBD5CA` 1.32 |
| 路格边线 `tile.edge` | **1 pt 全周实线**，一个 token 五种纸通用 | `#857868`：新纸 3.92 · 米纸 3.69 · 背光 3.56 · 旧纸 3.46 · 终章 3.28 · 信笺 3.88（全部 ≥ 3:1） |
| 浮雕 | 保留：顶边 1 pt 白 28%、底边 1 pt 投影 `#5A4A36` 28% + 2.5 pt 柔影 10% | 不变（Paper.swift:184–187） |
| 左上白描边 | **去掉**（它把边缘抬亮，抵消了面色） | Paper.swift:185 |
| 信笺路格 | 面色同上；边线用 `tile.edge` 而不是 `rule.letter` 42%（印格线是装饰 1.4:1，不能兼任格边） | Paper.swift:179 |
| 朱线在路格上 | `thread` 在新纸面色上 3.46:1、`thread.aged` 在旧纸面色 3.70:1、终章 3.55:1 | 仍 ≥ 3:1，不用改 |
| 石头本体 | 实心暖灰渐变，**平均色 ≥ 3:1**；1 pt 轮廓 `#5A4A36` 70% | 顶 `#9A8D7B` → 底 `#7D7163`（底色新纸 4.33 · 终章 3.63）；背光章仍是黑剪影（ch3 §4） |
| 缺口 | 不画格，只有纸纹点 | 纸纹点 `#DDD6C9` 1.32:1 → 改为 纸 mix 25% `#8A7A62`（和面色同一个值），每种纸都看得见 |
| 高对比 | 不变：白底 + 3 pt 黑框 | spec §7 |

**验收**：六张 v14 截图位置重拍，40% 灰度下路格 / 缺口 / 石头三者仍分得开；1-2 的石头在缩略图（地图卡片 1/4 尺寸）里是深的那个。改动只有三行（Theme.swift:74 的 0.075 → 0.25 + 一圈 `strokeBorder(tile.edge, 1)`；`style.css:111` `--card` → 按 `data-paper` 取 `--tile-face` + `inset 0 0 0 1px var(--tile-edge)`），原型和 App 同时改，**皮画在这个底上**。

## 3. 轮廓规则（a11y：换皮也认得出）

每个规则物件有一个**基元**（objects.md A.1），皮只能在基元之外加东西。下面是每套皮必须通过的检查，帧出来后先过这一遍再过 5 秒测试。

| 物件 | 基元（每套皮必须有） | 皮不许做 | 高对比（所有皮共用，不随皮变） |
|---|---|---|---|
| 石头 | 实心深色块 ≥ 60% 格、无开口、无内部亮线、平均色 ≥ 3:1 | 镂空（会像门）、顶部装饰 > 20% 高（石狮的耳鬣 ≤ 8 单位 / 40）、竖长比 > 1.6（会像纸人） | 45° 斜线 1.8 / 5 + 3 pt 轮廓；轮廓用各皮的外形 |
| 门 | 一个闭合框 + 中间一个竖的「挡」（锁孔 / 闩 / 闸板），框占格 ≥ 70% | 框里画别的（篱门的竹节只在框上）；框色浅于 `ink.700` | 3 pt 框 + 锁孔 / 闩实心；开门 = 同框虚线 7 / 4 |
| 开门 | 同一个框，中间空，虚线 | 换外形（开门的框 = 关门的框，玩家在找「刚才那扇门」） | 同上 |
| 钥匙 | 一个环 + 一根柄 / 绳，小（≤ 60% 宽 × 30% 高），孤立在路格上 | 环闭合不全、环以外再画环、柄粗于 3 单位 | 实心钥匙轮廓（各皮外形） |
| 墨 | 不规则湿黑块 + ≥ 1 个溅点，无直边 | 直边（像石头）、单色灰 | 实心笔触；印走后 2.5 pt 虚线框 |
| 纸片 | 跨中缝成对的 V 折 | 改 V 的角度；纹路深于 `skin.line` 40% | 横条纹 2 / 6 + 3 pt 框 |
| 终点 | 一个**竖立的小东西**站在路格中心偏上 | 竖立物宽 > 70% 格；用朱红以外的饱和色 | 双框 2 pt（内框内缩 8）+ 竖立物剪影 |
| 纸人 / 影子 / 胶 | 不换皮 | — | 不变 |

**三条附加规则**：
1. **页边布景不能和任何规则物件共享基元**：没有环（钥匙）、没有闭合框（门）、没有实心深块（石头）、没有竖立单物（终点）、没有 V 折（纸片）。柳是线、桥栏是开口的栏、灯笼是开口的（不闭合的框 + 杆）、船是半只、信封角是被页角切掉的。
2. **同一章里皮的外形不能重复**：石狮的耳不能像灯笼的提手；缆桩的绳痕不能像钥匙的环；镇石和信封都是矩形——镇石横、信封竖，且信封有封口折线。
3. **5 秒测试**（objects.md A.1 判定）：每章帧出来后 10 人指认，任一物件 < 9/10 这套皮退回。另加三列色盲模拟 + 40% 灰度 + 1/4 缩略图三遍。

## 7. 门禁：`check.js inert()` 与 `dressing.js`（只描述，不实现）

**`inert(level)`**（放 `tools/check.js`，用现有 `solve` / `analyse` 的状态枚举，不加新求解器）：

1. 枚举所有可达状态 `(c, r, a, st)`——角度集合用 `ANGLES ∪ STEPPED`（键盘 / 大按钮的 15° 档也算），状态间的角度变化走 `turn()` 的 5° 扫描。
2. 对每个状态收集「活跃格」：纸人所在格；`F.shadows(world, a)` 在扫描经过的每个 5° 角上投到的格；`grids(level)` 每个变体 `G[st]` 里不是 `-` 的格（墨印过去、胶搬过石头之后的地图）；合上（`a ≥ FOLD_MIN`）时所有非 `-` 格的镜像格 `7 − c`。
3. `inert = 所有格 − 活跃格`，再减去：第 3、4 列；起点 / 终点的四邻；任一变体里不是 `-` 的格。返回 `[{c, r}]`。
4. 顺手把 `inert.length / cells` 打进 `report()` 的表——它和 `IDLE_MAX` 是同一个问题的两面（惰性格多 = 棋盘稀）。

**`dressing.js`**（新文件，关 id → `{ margin: [{edge, kind}], cells: [{c, r, kind}] }`）。`check.js` 对每关断言：

- `cells` 每一项 ∈ `inert(level)`；`cells.length ≤ floor(0.10 × w × h)`；同一行 ≤ 1；`kind` 在该章 §2.3 允许表里（章由 `chapterOf` 判）；
- `margin` 的 `edge ∈ {outer, side-a, side-b}`，不许 `crease`；每页 ≤ 2 项；`kind` 在 §2.2 该章表里；
- 关 id 不在 `LEVELS` 里 → 失败（`gen.js` 重生关卡后布景不能悄悄留在旧坐标上；`len` 变了 `check.js` 本来就会红，布景跟着重验）；
- 没有 `dressing.js` 条目的关 = 没有布景，合法（第一、三章、暗信就是这样）。

跑法仍是 `node tools/check.js`，多一节「dressing」输出：每关惰性格数 / 用了几格 / 页边几项。**门禁绿之前，§2.3 的格内布景一个都不画。**
