## 0. 一页结论

卷一教的是铰链作为**位置**（0 / 90 / 130 / 180 是一个旋钮），卷二教的是合上作为**事件**（印、粘、洇、翻），卷三教的是铰链的**路径作为序列**：经过 90° 和合到 0° 是两种不同的拍子，先后不同结果不同。全卷只有两个新 tile（松石 `r`、纸鹤 `h`）和一个新姿态（终章的第二道折痕）；第十一章没有新 tile，只有"来回"第一次在 par 里算钱。难度来源三条，每章都用：**不可逆**（石头永远不滚回来）、**顺序**（同一次合里滚 → 洇 → 粘 → 飞的先后）、**资源**（过立几次、合几次）。趣味来源一条：**纸是会动的**——不解题光来回扳铰链也有反应。

| 章 | 名 | 新东西 | 一句规则 | 回来的旧机制 | 关数 / 章 par |
|---|---|---|---|---|---|
| 九 | 滚 Roll | `r` 松石 | 抬起的页每经过一次 90°，页上的松石向折痕滚一格；滚进缺口填成纸 | 影、乘影、叠合换页、石背、胶 | 7 / 22 |

## 1. 四章

### 1.1 九「滚」——松石 `r`

- **规则**（`logic.js` `roll()`，已入库）：`r` 是没粘住的石头，挡路、投影、压人都和 `x` 一样。抬起的那页**每经过一次 90°**（铰链从 < 90° 到 ≥ 90°，或反过来；斜起再放平算两次，合一次算一次、合上之后再摊平又算一次），页上每颗松石向折痕滚一格：前面是纸就滚过去（原来的格变成纸）；前面是缺口就掉进去把它填成纸（石头没了）；前面是别的——石头、门、活页门、墨、胶、钥匙、她的格、起点、**站在它前面的纸人**——就不动。靠折痕最近的先滚，所以一列松石一起滚；贴着折痕那格没有更低处。平放的左页上的松石永远不滚。胶粘走松石，它到了胶上就是普通石头（粘住了）。
- **皮**：硬卡纸。浮雕格变压痕格；松石是圆的（`x` 是方的；高对比下圆点阵 vs 斜线，轮廓 3 pt）；滚动有厚纸的闷响；页立成帐篷时能看见厚度。透光 0.08，全书最不透的一卷。
- **故事**：同一页上站过了，书打开还是两岸。那就把书立起来——立起来的时候什么都往低处去，低处是折痕，折痕是你。问题从「我怎么过去」变成「**我能把什么送过去**」。
- **啊哈链**（七关，详见 `design-ch9.md`）：石头滚进缺口是桥 → 没合上也算 → 影子跟着石头跳 → 你的身体挡得住石头 → 合书压的是滚之后的格 → 同一次合里先滚后粘 → 摊平也是一次过立。

### 1.2 十「鹤」——纸鹤 `h`

- **规则**（未入库）：`h` 是一格纸，能走。每次**完全合上**（折角 ≥ `FOLD_MIN`，含翻那一拍）它飞到自己的镜像格（c → 7 − c），站在它上面的纸人跟着飞——这是全书第二种换页方式（第一种是叠合走法）。落点规则：落点是缺口 → 鹤落下去成了那格的纸（鹤还在，下次还飞）；落点是纸 → 鹤落上去（原格变纸）；落点是**湿墨** → 鹤染了墨，不再飞（变成 `I`，之后随墨洇）；落点是**胶** → 被粘住，不再飞（变成 `.`，胶用掉）；落点是石头 / 松石 / 门 / 她 / 起点 → 飞不动，留在原地。**同一次合的顺序**：滚（过 90° 那一拍）→ 洇 → 钥匙 / 墨印 / 胶粘 → 鹤飞。所以一颗松石在同一次合里先滚进鹤的落点，鹤就飞不动；胶先粘走鹤落点上的石头，鹤就能飞。
- **皮**：从信纸角上折出来的鹤，合上时扑一下翅膀。高对比：鹤是空心轮廓 + 一条折线。
- **故事**：石头太重了，我折了只鹤。每合一次它就飞到你那页同样的位置——「同样的位置」是镜像：你以为它飞过来了，它落在了对面那一列。
- **回来的旧机制**：湿墨（鹤染墨 = 一次性）、翻（翻也是合，鹤在翻那一拍飞到第三页）、胶（粘住鹤 vs 粘走落点上的石头）。
- **反转**：① 玩家预期「合上 = 东西过去」（胶、鹤），实际鹤**载人**而不是搬石头：站在鹤上合书你在对页，站在鹤旁边合书你被压（鹤是纸，不是石背）；② 松石和鹤同一次合：滚在飞之前——鹤的落点在你合之前是空的，合的那一拍先被石头占了（7-4 的「同一次压里的先后」）；③ 翻那一拍鹤也飞，飞到第三页的镜像格——第三页没人等它。

### 1.3 十一「来回」——无新 tile

- **规则**：没有新 tile。改的是门禁：`PAR_MAX.hard` 4 → 5、`final` 5 → 6（本章），`CLOSES_MAX.main` 不放宽（2）。来回（一次斜起再放平）在 check.js 里记成两次 posture change 但零次合——它是**买两次过立的最便宜的办法**。章内把滚 × 影 × 鹤 × 胶 × 灯位做顺序题：先乘影再让石头滚，还是先滚再乘；灯在左岸时左页石头的影子落在抬起页上**不随滚动变**，右灯的影子跟着松石跳；翻页后换第三页的松石滚，右页的停。
- **皮**：硬卡纸不变；章首加一帧「立起又放平」的空镜（纸自己动）。
- **故事**：来回。立起来又放下，什么都没发生的时候，其实什么都发生了。
- **回来的旧机制**：灯位 `lamp: 'L' | 'LR'`、活页门 `A`（门立着时松石滚不进门那格）、翻。
- **反转**：① 玩家从九、十章学会「过立要合」，这章第一次让**不合**成为正解：合一次会印 / 粘 / 飞，而你只想让石头滚两格；② 左灯影子不动、右灯影子跳：两盏灯下同一次来回，一套影子换了列、一套没换；③ 翻页后：你记着右页那颗松石还差一格，翻过去之后抬起来的是第三页——滚的是第三页的石头，右页那颗一动不动（gating ②）。

### 1.4 十二「三折」——第二道折痕（终章）

- **规则**（计划，灰盒后定）：三页关换一种装订：第三页接在**右页外沿**（不是背面），第二道折痕在第 7|8 列之间。新动作「折第二道」：第三页折到右页上（第三页列 c 落在右页列 15 − c）；再合第一道，右页 + 第三页一起落到左页上（第三页列 c 落到左页列 c − 8：**两次镜像回到自己那列**）。层序 = 折序：先折第二道再合第一道，第三页夹在中间（卷折）；先合第一道再折第二道，第三页在最上（Z 折）——最上层才是地面，所以同一格叠三层时你站在谁上面由折序决定。松石在第三页上向**第二道折痕**滚（它自己的"低处"，在第三页的左沿）；鹤在第三页上向右页的镜像格飞（第一次镜像）。终章只用本卷两样 + 胶 + 影。
- **皮**：硬卡纸在折痕处透光（spec §0「一张纸，三种状态」卷内成立：卡纸 → 终章折痕透光），三层递淡的叠影只在合拢那一帧出现。
- **故事**：信太长了，折两次才够小、够寄。折两次，我回到原来那列——只是叠在你上面。全书第三卷的结尾是三层叠成一格。
- **风险与退路**：4 列 × 三层的可读性要过 5 秒测试（`design-review-ch3` 的尺子）；过不了就把终章改成滚 × 鹤 × 胶 × 影的组合关、三折推到卷四开卷（`brainstorm-vol3.md` §2）。
- **反转**：① 「合上 = 镜像」（卷一）在这里是**两次**镜像 = 不镜像：她在第三页 c 列，你以为合上要去 7 − c 那一叠，其实是 c；② 折序决定地面：同一次「全合上」两种答案（卷一第一次让合上有两种结果）；③ 第三页的松石往**另一边**滚（它的折痕在它左沿）：九章练出的「往第 4 列滚」在第三页反了。

## 4. 三个门槛问题（`brainstorm-vol3.md` §2 末）

**① 90° 触发 vs 可见动画。** 规则和动画分开：`logic.js` 在铰链**跨过** 90° 那一拍触发（`standing(a) = a ≥ 90`，`passes(a0, a1)`），和采样角 `ANGLES` 里的 90 对齐——求解器从 0 到 90 滚一次、90 到 100 不滚、100 到 0 再滚一次。渲染层：`applyAngle` 的 `squash ≥ 0.3` 已经保证页在 90° 不会缩成一条线（最窄 30% 宽）；松石的滚动动画在 75°→105° 的窗口里播（进窗口时石头先倾、到 90° 滑过去、出窗口时落定），15° 步进 75 → 90 正好把它滑过去；滑块在 90° 以内往回拉，石头**摇一下不滚**（规则没触发，动画回弹）。读屏一句话「松石；上页立起时会往折痕滚一格」，滚了之后报「松石滚到了第 n 列」/「松石掉进缺口，那里是纸了」。

**② 翻页后谁滚。** **谁被抬起谁滚**：`roll()` 只扫可见的第 4–7 列，`at` / `put` 按 `s.face` 读写，所以翻过去之后抬起的是第三页、滚的是第三页的松石，右页的（贴在叶子背面）一动不动。左页永远平放，左页的松石永远不滚——胶粘到左页上的松石已经是 `x`，不留"左页松石"这种东西（关卡不画）。十一章的反转 ③ 就是这条。

**③ 一眼纸的「过立 k 次」视图。** `glance.js`（已入库）对含 `r` 的关印 **VIEW 2·k**：页经过 90° k 次之后的图，k 从 1 到石头落定（≤ 4），k 为奇数（页抬着）时附七个角的影子；**VIEW 3·k**：过立 k 次之后合上的压（压人、印、叠合图）——合上本身算一次过立，所以 k 从 0 起；**VIEW 4**：合上之后再摊平又是一次过立，印摊平后的图。纸上印不出来的两样：**你站在哪两拍之间**（挡住了哪颗石头——视图假设你不在任何石头前面，纸上写明）和**你在第几拍合的书**。hard / final 的门就是这两样：解必须依赖"在第几拍和第几拍之间走哪段"，而不是依赖某一张 VIEW。第九章 7 关的 v3 数字见 `design-ch9.md` §3。

## 5. 每章的反转怎么做

尺子（`design-ch7.md` §8）：反转 = 前面的关把玩家训练成会**预测错**的一条规则后果——同一次压里的先后、要到后一拍才看得见的后果、熟悉的物件因为新物件变了样。每关的反转一句写在 `design-ch9.md` §3 的表里；门禁上用 `tools/hunt.js` 的结构谓词保证（谓词不满足的图不进档）。

| 章 | 玩家被训练成的预期 | 实际 | 谓词（hunt.js） |
|---|---|---|---|
| 九 | 卷一二：不合上什么都不发生；影子在石头画的那列；合上压的是画出来的镜像格；胶粘对着它的那颗 | 过立就滚；影子在滚之后那列；压的是滚之后的格；胶那一拍对着的格已经空了 / 换了颗石头 | `rolls ≥ 1 && !solvable(r→x)`；9-6：`glue 对着的格在 roll 之后变了` |
| 十 | 合上 = 石头过去（胶）；鹤的落点看图就知道 | 鹤载人不载石；落点在同一次合里先被松石滚进去 / 被胶腾出来 | `鹤飞的那一拍，落点由同一次合的 roll / glue 改过` |
| 十一 | 九、十：过立要合（合才有事）；影子跟着石头；翻过去接着滚 | 来回不合是正解（合会印 / 粘 / 飞，坏事）；左灯影子不动；翻后换页滚 | `solution.closes < 需要的过立次数 / 2`；`needsLamp`；`flip 之后第三页的 r 滚过` |
| 十二 | 合上 = 镜像；合上只有一种结果；松石往第 4 列滚 | 两次镜像 = 不镜像；折序决定地面；第三页的松石往第 8 列滚 | 灰盒后写 |
