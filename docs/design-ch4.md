## 1. 机制：没有新东西，全部一起来

**一句话：第四章不加格子、不加姿态。它加的是相互作用——你在一章里学会的东西，在下一章是陷阱。**

前三章各给了纸一种能力：合上是镜像（一），立起是桥（二），斜起是影子（三）。第四章把它们放到同一格上，出现四种前三章从未同时出现过的后果。每一关围着其中一两种建：

| # | 作用 | 后果 | 关 |
|---|---|---|---|
| A | 影 × 门 | 影子不越过锁着的门（`openNeighbours` / `ride` 的 `isBlock`）；开了的门是纸，影子能把你送过去 | 4-5、4-6 |
| B | 影 × 墨 | **影子是路，不是岸**：站在影子上合书会掉下去；墨印到缺口上，缺口才成了能合书的岸 | 4-3、4-4 |
| C | 压 × 顺序 | 合上要盖印（墨、钥匙），但合上时站在上页石头的镜像位会被压（`crushed`）。问题变成：**合上之前站在哪** | 4-3、4-4、4-6，3-6 预告 |
| D | 立 × 影 | 纸片在 60°–120° 立着，影子在 26°–89° 出现：**60°–89° 两样都在**。只在这一段，桥头的缺口有影子 | 4-2 |

另有一条从第三章顺下来的：远近两道影子速度不同，所以可以在某个角度从一道换到另一道（4-1）。

**砍掉的（plan §2 第四章原定）**：
- **倾（帐篷滚石）**：石头会动，就有了第四重身份，而且地图会变——读屏要重报整页，求解器要带可变地图，Duo 上立成帐篷的手机不好看影子。它的乐趣（"东西滚进河里填成桥"）留给 `roadmap.md` 的卷二候选。
- **窗（镂空穿层 / 透光抵消影子）**：合上的书本来就是两层叠成一层，"穿层"没有意义；"光抵消影子"是一条要用字解释的规则，而且需要新 tile。砍。
- **两人同走（两个可操作角色）**：成本高、输入要切换、读屏要报两个人。终章的「两人」用下面的办法做到了，不用它。

**「两人」怎么做（4-6）**：终点那格 `G` 不画旗，画**收信人**（发髻、提灯，`design-review-1.md` §3 / spec §8），站在上页（右岸）的岸边。规则一字不改：终点在上页、而它那一叠的四邻在打开时都到不了（§2 的建法），所以**只有合上时**你才能站进那一格——两岸相触，两个人在同一格里（`isWin` 的 `mode === 'fold'` 分支；`needsFold` 为真）。这就是 plan §2「合上时在折痕相遇才算过关」。然后书打开，河还在：第四封信从这里写下去（§3）。

**每关的「啊哈」与陷阱**：
- 4-1：第三章教了"影子带你出去"和"影子带你回来"，这里要在 30° 那一格换乘。陷阱：（3,0）头顶有石头，进关先合上 = 被压；在远影子上合到底 = 摔。
- 4-2：玩家会先立到 90°——桥在，桥头是缺口；再斜到 50°——影子盖住缺口了，桥却倒了。答案在中间：75°。这是全游戏第一次要求"立起的角度"而不是"立起"。门先开，否则桥那头走不通。
- 4-3：第三章的影子一直是桥，这里它第一次**不够**：站在影子上合书掉下去。墨印出来的那格才是岸——墨从第一章回来了。还有压：三格路里中间那格头顶有石头。
- 4-4：合上是必须的（墨），可是路上每一格合上都会被压，只有尽头那一格不会——先走到头，再合。然后是 3-5 式的回程乘影。`combo = 5`，全游戏最多。
- 4-5：两道影子，一道穿门到终点，一道通向孤岛。门锁着时影子带你撞门掉下去——玩家会先试这一步，然后明白"先合上开门"。
- 4-6：3-5 的回程 + 1-4 的钥匙 + 3-2 的压，最后那一合同时做三件事：开门、两岸相触、你站进她那一格。书打开之后两人又各在一岸——第四封信（§3）。

**铰链（plan §12）**：par 3 / 3 / 2 / 3 / 3 / 3，完全合上 ≤ 2（4-3 两次）。Duo 签名时刻：4-6 最后一合（plan §12.2 第四处，原写 4-8）。幽灵手：第四章**不演示**——这一章没有新事实可教，「?」只给文字提示（`hint`）。影锁照常：4-2 的 75° 是"影子盖住缺口 + 纸片立着"，锁定反馈同 ch.3；4-1 的 30° 换乘点两道影子同时在第 1 列，双音和弦。

## 5. 无障碍

**对比度**（WCAG 2.x）：正文 ink.900 在 #EFE6D2 13.78:1、在 #EBE0C7 13.05:1；`thread.aged` 4.78 / 4.53:1；影子面色 `shade` #6E604E 在旧纸 ≈ 4.9:1（在背光纸 5.05:1，旧纸略深，仍 ≥ 3:1）；「成」cinnabar 在旧纸 4.06:1（图形，过 3:1）；纸人站在影子上照 ch.3 带 1.5 pt #FBF6EA 逆光描边。高对比：石头斜线、影子交叉线、纸片横纹、墨实心、门框、终点双框——4-6 的终点双框里是收信人剪影；印章在高对比下是 3 pt 线框 + 「成」字，不填色。

**VoiceOver**：
- 进章读 `paper.ch4`；斜起时读 `paper.lit` 不变。
- 4-6 的终点格读 `kind.figure`「对岸的人，合上时相遇」；合上相遇后 `win` 照常，再读第四封信。
- 陷阱全部已有读屏：下页、对面有石头的格子读 `crushedHere`「合上会被对面的石头压住」（4-3、4-4、4-5、4-6 的压格）；上页石头读 `stoneShadow`；影子落进缺口 `shadowGap`；乘影 `slid`；门 `no.door`。4-5 影子撞门掉下去读 `fell`。
- 转子「物件」里收信人是一个物件。

**运动**：25 关只用 15° 一档全部可解（`check.js` 断言）。本章用到的斜起角都在档上：75°、60°、45°、30°。乘影不要求速度。影锁让 4-2 的 75° 和 4-1 的 30° 停得住。

**减少动态**：「成」印不落下，直接出现；两岸相触的 `page.press` 不做；章首擦入改 200 ms 交叉淡化。

**声音模式**：收信人的格子有一个独立动机（提灯 = 音盒三音，和终点动机不同），合上相遇时两个动机合成一个和弦。
