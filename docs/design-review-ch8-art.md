# 评审：第八章「灯位」物件图（Claude Design 帧，2026-10-26）

评审对象：`~/.tomo/workspace/tmp/fold/ch8-art/` 七帧（`G1-gate-states`、`G1-gate-states-HC`、`L1-lamps`、`L1-lamps-HC`、`B87-board`、`S-lamp-slip`、`S-gate-slip`，拼图 `sheet.jpg`）。依据：`design-ch8.md` §1 / §2 / §5，`logic.js`（`lit`、`shadowColumnL`、`shadows()`、`ride()`），`design-spec.md` §4 / §7，`design-skins.md` §3 / §5，`objects.md` A.1。评审人：Fable（主设计）。角度一律物理角（180° 摊平、90° 立起、0° 合上）；格子（列, 行）从 0 数；左页 0–3 | 右页 4–7 | 第三页 8–11。

## 0. 结论：**GO-with-changes**，不开重画轮

物件本身画对了：活页门三态（趴 / 立 / 站上）、灯笼的开口形、空挂钩、高对比花纹都在族谱里，45 pt 真尺寸读得出。要改的三件事都是**规格层**的，原生按本文 §3 直接建，不回 Claude Design：

1. **页面分配反了**（§1.1）：帧把上页当左页。规则是上页 = 右页 = 抬起页（spec §4）。`'L'` 关的灯笼挂**下页**外角、影子落**上页**。
2. **去掉角标**：正常模式的 1.5 pt 角 tick 和高对比的 3 pt 白衬 L 形角标都不要（§2.1）。影子不用标它的灯——两盏灯的影子从不落在同一页。
3. **趴下的门的 U 线换色**：40% 墨 2.4:1 不过 3:1，改 `tile.edge` `#857868` 1.5 pt（信笺 3.88:1）（§2.2）。

B87 / L1 / 两张笺上的影子、石头、门的**位置只是示意**，建造一律从引擎算（§2.3）。

## 1. 对规则

### 1.1 哪一页被照亮——帧反了，规格纠正，不重画

`design-spec.md` §4：手机竖屏横折痕，**上页 = 右页（第 7→4 列，从上往下），下页 = 左页（第 3→0 列，从折痕往下）**；抬起的是右页。`logic.js`：`lamp = 'L'` 时 `shadows()` 扫左页（下页）的石头，`shadowColumnL` 把影子放到 `N − 1 + e` 即右页（上页）第 4 列起、越合越往第 7 列（屏幕上越往上）。

帧里的标注「left lamp: top page, top-right」把上页当成了左页，于是 `L1-lamps 'L'`、`S-lamp-slip`、`S-gate-slip`、`B87-board` 全部左右页互换：石头画在上页、影子落在下页、灯挂在上页右上角——那是三章 `'R'` 的样子。`'LR'` 帧因为对称，物件没错，只是左右两盏的名字对调。

**纠正（原生按这个建，不照帧）**：

| 关卡 `lamp` | 上页（右页，抬起） | 下页（左页，平放） | 灯笼 |
|---|---|---|---|
| `'R'`（三章起默认） | 石头的影子落到下页第 3→0 列 | 承影 | 上页外角右上（三章位置），下页左下**没有挂钩** |
| `'L'`（8-1、8-2、8-4） | **承影**：下页石头的影子从折痕那一行（第 4 列）起、合得越多越往上（第 7 列） | 石头在这里 | **亮灯挂下页外角左下**；上页右上只剩**空挂钩** |
| `'LR'`（8-3、8-6、8-7） | 两样都有 | 两样都有 | 两盏都亮，两个角 |

光晕原点跟灯走：`'L'` 的光晕从下页左下角起，正好解释「影子从折痕往上滑」。翻页后（8-7）第三页承左页石头的影子，**不加第二个光晕原点**（ch8 §7 第 4 条）。

### 1.2 其余规则点——对

- **门的三态**：`(a)` 趴下 = 摊平或合上 = 不是地面；`(b)` 立起 = 斜起窗口内 = 地面；`(c)` 站上。和 `ride()` 的 `t === 'A' ? (lit(a) ? from : null)` 一致。帧未标角度，§3.2 补上：窗口 = `lit(a)` = 折角 91°–154° = **物理 26°–89°**，和影子同一窗口（「灯亮着，门就开着」）。
- **灯笼形**：杆 + 臂 + 开口的肋，无底横——满足 skins §3 第 1 条（灯笼是开口的，不是闭合框）。空挂钩 = 灯搬走了，`'L'` 关只有左边的灯——对 ch8 §2。
- **影子随页倾斜**：L1 和 B87 上抬起页的影子画在页面里、跟着透视走——对 ch8 §2（和三章「石狮竖直、不随页倾斜」相反，影子是页上的东西）。
- **高对比**：路 = 白底 3 pt 黑框、缺口 = `#EDEDED` 无框、石头 = 45° 斜线 1.8/5 + 3 pt 轮廓、影子 = 交叉线 1.8/6 + 2.5 pt 虚线框、光晕关——全部同 spec §7。
- **45 pt 真尺寸**：`G1` 的 a · b · c 条带在 45 pt 下三态靠形状分得开（虚线 + U / 实框 / 实框 + 人），灰度缩略同样分得开。唯一不过的是 U 线的值（§2.2）。高对比条带也过。

## 2. 三条裁决

### 2.1 影子的角 tick 与高对比角标：**去掉**

Claude Design 给每道影子加了一个指向自己那盏灯的角 tick（1.5 pt，臂 6 pt），正常模式还让交叉线**朝灯羽化**；高对比改成 3 pt 实心 L 形角标 + 8 pt 白衬。三个理由都不要：

1. **信息是冗余的**。两盏灯的影子从不落在同一页（左灯照右页、右灯照左页，ch8 §2）——站在哪一页就知道是哪盏灯的影子。角标回答的是没人会问的问题。
2. **撞基元**。L 形角标 12 × 12 / 线 3 是 spec §7 **焦点环**的四角角标；白衬 L 形更是 `hc.line` 朱线的高对比画法。影子格里再放一个，切换控制 / VoiceOver 用户会把影子读成焦点。
3. **羽化 = 中间灰**。spec §4「影子：一整格方形，边缘柔，叠 ±45° 交叉线。**不用中间灰**」。朝灯羽化把半个格子的交叉线淡掉，45 pt 下「右灯 set」那格只剩一半花纹。

影子**和三章完全一样**：整格、均匀交叉线、边缘柔；只是画在抬起页的平面里。高对比同 spec §7 一行，无角标。

### 2.2 趴下的门的 U 线：**改值**

`design-ch8.md` §2 写的「1.4 pt、墨色 40%」在信笺上是 2.4:1（实算 ink.900 @ 40% 在 `#F6F3EC` ≈ 2.45:1）。趴下的门是规则物件：这个 U 是「缺口上有东西、但不是地面」的**唯一**标记，和 spec §7「关卡名 40% 灰是装饰」不同类，必须过 3:1。

改成 **`tile.edge` `#857868`，1.5 pt**：信笺 3.88:1、新纸 3.92、终章 3.28（全部 ≥ 3:1），而且它已经是路格边线的 token——趴下的门和路格共用一种「纸的边」的颜色，读作「一片趴着的纸」，比再造一个灰合适。不用 `ink.700`（8.4:1，太重，趴下的门会比立着的门还抢）。高对比：U 用黑 2.5 pt，底是 `#EDEDED` 缺口灰，无框（同帧）。`design-ch8.md` §2 的「墨色 40%」按本条改。

### 2.3 B87 / L1 / 笺上的位置只是示意：**是**，建造从引擎算

`B87-board` 的格子和 `levels.js` 第 54 关 `twolamps` 的地图对不上（门、墨、胶、信封的格子都不在 §3 的位置，信封该在第三页），`L1` 两张的影子列也不严格等于 `shadowColumnL` 在 50° 的值。它们是**物件样式参考**，不是布局参考。原生：

- 影子位置只来自 `logic.shadows(s, a)`（右灯 `shadowColumn`、左灯 `shadowColumnL`，先右后左，同格先到先得）；门的开合只来自 `lit(a)`；渲染层不自己算一遍余弦。
- 石头 / 门 / 墨 / 胶 / 终点的格子只来自 `levels.js`；物件笺的布局只来自 `tools/slips.js` 的脚本（§5 的 `x---S-G-` 与 `S.A-----` / `-.AG----`）。
- B87 右侧那个「灯」书签页签**不做**——不在 ch8 设计里；灯在哪岸由页角的灯笼 + 进关读一次的 `lampSide.*` 告诉玩家，不加界面。

## 3. 建造规格（原生 `FoldCore` build 0.1(20) 直接实现）

单位 pt @1x；SVG 按 skins §5：viewBox `0 0 40 40`，格内渲染为 cell 的 64%（cell 80 → 1 单位 ≈ 1.28 pt；cell 63 → 1 单位 ≈ 1 pt），线端圆、角圆，颜色只用 token，每个规则物件两个 `<g>`：`#skin` / `#hc`。

### 3.1 颜色

| token | 值 | 用处 | 对比（信笺 `#F6F3EC`） |
|---|---|---|---|
| `ink.900` | `#1F1B17` | 立起的门的闭合框；高对比一切线条 | 14.9:1 |
| `ink.700` | `#4A433B` | 灯笼与空挂钩的线（规则承载的页边物，不受布景 2.5:1 上限约束，同三章 #18 的例外） | 8.4:1 |
| `tile.edge` | `#857868` | **趴下的门的 U 线**（新用处） | 3.88:1 |
| `paper.letter` | `#F6F3EC` | 立起的门的面色（= 纸色，不是路格面色 `tile.face`） | — |
| `lamp` | `#FFD08A` | 灯笼火苗填色；光晕 | 装饰 |
| `hc.gap` | `#EDEDED` | 高对比缺口底（趴下的门的底） | — |
| 影子 | 同三章 / `design-ch3.md` §4（v2c1 自测 5.5:1） | 抬起页上的影子同色同纹 | ≥ 3:1 |

### 3.2 角度门 `A`（新 tile，`gate-paper.svg`）

**两态 + 过渡**；状态由 `lit(a)` 决定（折角 91°–154° = **物理 26°–89°**）。

| 态 | 何时 | 画法（`#skin`） | 画法（`#hc`） |
|---|---|---|---|
| **趴下 lying** | 摊平（90°–180°）、合上（0°–26°）、合上后的描图纸 | 缺口的画法照旧（虚线框 / 无厚度），格内**一个开口向上的 U**：`tile.edge` 1.5 pt；几何：两竖 x = 14 / 26，从 y = 11 到 y = 24，下接半径 6 的半圆，底在 y = 30；无框、无填色。合上的描图纸里 U 画成 `edge.upper` 虚线 4/3 同一几何（它是上页带过来的东西） | 缺口灰 `#EDEDED` 无框，U 黑 2.5 pt 同几何 |
| **立起 standing** | 斜起 26°–89° | 整格一张纸片：面色 `paper.letter`，**四边 2 pt `ink.900` 闭合框**，内缩 3 单位（34 × 34），角圆 1；无锁孔、无闩（这是它和门 `D` 的区别：门 = 框 + 挡）；面上不画 U。在抬起页上随页倾斜 | 白底 + 3 pt 黑框（同路格）+ 格中**两道短横** 2.2 单位：宽 16（x 12–28），y = 15 与 25——短于门 `D` 的通栏闩（宽 30 居中一道），且 ch8 的关里没有 `D`，不会同屏 |
| **站上** | 纸人在立起的门上 | 同路格上的纸人，`ink.figure`；影子上的 1.5 pt 逆光描边**不用**（门是纸，不是影） | 同 |

**过渡**：

| 事件 | 时长 | 曲线 | 画面 |
|---|---|---|---|
| 进入 lit（穿过 89° 往合、或从合上穿过 26° 往开） | 260 ms | ease-out | 纸片从折痕一侧的格边绕 x 轴立起（0° → 落平），面色淡入；**和影子出现同一拍**；声：纸片翻起「啪」（短白噪 40 ms + 中频敲击）；触觉 `[10]` |
| 离开 lit | 260 ms | 同一动画倒放 | 声低八度 |
| 站在门上离开 lit | 120 ms 趴下 → 掉落 | — | 先趴（120 ms，不是 260），再播「影子没了掉下去」的既有动画（纸人折叠落下 → 淡回起点）；读屏 `gateDown` 后接掉落句 |
| 减少动态 | 120 ms 淡入淡出 | — | 不翻转；笺里用淡「×」代替掉落（ch8 §5.2） |

**不**：门不吸墨、不印字、粘不走（`bleed` / `stamp` / 胶都不认 `A`）——渲染层不要给它洇圈或胶痕。合上时门那一叠按引擎（只在另一面是纸时开），描图纸按 §closed 画，门以 U 出现。读屏：`gate`「活页门」；进入 / 离开 lit 各读一次 `gateOpen` / `gateDown`。

### 3.3 灯笼与空挂钩（页边资产，`margin-lamp.svg` / `margin-hook.svg`）

卷二的灯笼是新资产（三章 #18 是斜杆挂灯，这里换成**杆 + 臂 + 开口灯身**，仍是开口形）；两盏灯共用一个资产，左边那盏水平镜像。viewBox `0 0 40 48`，渲染高 24 pt × 宽 20 pt（同 #18），线 `ink.700` 2.2 单位，线端圆。

- **亮灯 `margin-lamp.svg`**：竖杆 x = 36，y 0 → 48；横臂 y = 2，x 36 → 18；灯身挂在臂端：两条肋是对称弧线，顶 (18, 6) 分到最宽 (10, 18) / (26, 18) 再收到 (13, 30) / (23, 30)，**底不封口**（间隙 ≥ 8 单位）；顶一道短横 x 14 → 22、y = 6；火苗：椭圆 中心 (18, 18) 4 × 7，填 `lamp` 100%，线 1.4 `ink.700`。`data-glow="18,18"`。
- **光晕**：径向，原点 = 火苗，`lamp` `#FFD08A` 中心 62% → 0，半径 1.8 × 灯笼高（≈ 43 pt）；混合在纸层**之下**（格子、朱线、纸人在上，同 review-ch3 §closed 的层序）；两盏时两团独立。
- **空挂钩 `margin-hook.svg`**：同一竖杆 + 横臂，臂端向下一段 6 单位的短钩（x = 18，y 2 → 8），**不画卷曲**（卷曲在 45 pt 下读作环 = 钥匙基元，skins §3 第 1 条）。
- **位置**（§1.1 表）：右灯 = 上页外角右上，杆贴页侧边、臂伸出页外角，和三章同位；左灯 = 下页外角左下，镜像。它们在页的 44 pt 角区内、不占玩法格，随页的 3D 倾斜。
- **高对比 / 降低透明度**：线改 `ink.900` 3 pt，火苗实心黑椭圆，**光晕关**（spec §3）。不降到 `dress.hc`——它承载「灯在哪岸」。
- **读屏**：进关纸状态句读一次 `lampSide.L` / `lampSide.LR`；灯笼本身不是可聚焦元素。

### 3.4 影子（抬起页上的新画法）

- 来源：`logic.shadows(s, a)` 的每一个 `'q,r'`；左灯的值是左页石头的列，渲染层只用来决定「它是哪块石头的影子」（给影锁描边），不用来算位置。
- 画法：**同三章**——整格方形、边缘柔（羽化 2 pt，四边均匀）、±45° 交叉线、同色；**无方向羽化、无角 tick**。落在抬起页上时整格跟随该页的透视变换（含交叉线），纸人站上去同样倾斜，1.5 pt `#FBF6EA` 逆光描边照旧。
- 高对比：交叉线 1.8 / 6 + 2.5 pt 虚线框，**无角标、无白衬**。
- 两盏灯：两套影子同色同纹；同一格两道影子只画一道（引擎已先到先得）。
- 影锁（spec §5 `hinge.drag`）：判定改为「`shadows()` 里落在缺口且与纸人连通的每一道」，不分哪页、哪盏灯——`'L'` / `'LR'` 下也要有咔哒。
- 声音模式：影子低频持续音，左耳 / 右耳按它落在的页（下页 = 左耳 木，上页 = 右耳 纸，spec §7）。

### 3.5 8-7 的终点与第三页

信封封口已拆（`goal-envelope.svg` 的 `#opened` 变体：封舌三角翻开朝上，线 2.2）；只在第三页 (8,0)，翻页后可见。第三页承左页石头的影子用 §3.4 同一画法；无第二光晕。

### 3.6 建造核对清单（对 `design-ch8.md` §6 第 4 条的展开）

1. 上页 = 右页。`'L'` 关：影子在上页、亮灯在下页左下、上页右上是空挂钩。
2. 门：`lit(a)` 两态、260 ms 翻起 / 趴下、站上掉落先 120 ms 趴；U = `tile.edge` 1.5 pt；立起 = 纸面 + 2 pt `ink.900` 框。
3. 影子：三章画法 + 抬起页透视；无 tick、无羽化、无角标。
4. 灯笼：开口形，`ink.700` 2.2 单位，火苗 `lamp`；空挂钩无卷曲；高对比线黑、晕关。
5. 位置全部从 `levels.js` / `logic.js` / `tools/slips.js` 来；B87、L1、两张笺不作布局依据；不做「灯」页签。
6. 对比复核：U 在五种纸 + 信笺 ≥ 3:1（已算：3.28–3.92）；高对比 17.9:1 不变。
