## 1. 机制：胶

**一句话：涂了胶的格子，合上时把对面的石头粘过来。**

| 规则 | `logic.js` | 一句"纸会怎样" |
|---|---|---|
| 胶是纸 | `isFloor` 含 `g` | 能走，能站，能从这里合书 |
| 合上时粘石头 | `stamp()`：`g` 对面是 `x` → 胶格变 `x`，石头原处变 `.`；事件 `glue` | 石头换了页；胶用掉了（被石头盖住） |
| 只粘石头 | 钥匙、墨、纸片、门不粘 | 钥匙对面只能是门，粘不到；墨是印的，不是搬的 |
| 一次性、无顺序 | 所有胶在**第一次**合上时同时发生，和钥匙开门、墨印同一拍 | 之后再合，什么都不变 |
| 站在胶上被压 | `crushed()`：下页胶对面有石头 → 原规则（上页石头落下来）；**上页**胶对面是下页石头 → 新增：石头被粘上来，压住你 | 卷一"上页永远安全"在胶上不成立 |
| 影子跟着走 | 不改代码：`shadows()` 只看上页的 `x` | 石头粘到上页，就开始投影；粘到下页，影子没了 |
| 压痕跟着走 | 不改代码：`crushed()` 只看上页的 `x` | 石头粘到上页，它的镜像格从此合上会压 |
| 叠合不变 | 粘前粘后，同一叠里都是一块石头 | 合上时走不走得通，胶不改；它改的是**打开**时 |

**求解器**：仍是两张网格（粘前 / 粘后，`st ∈ {0,1}`），因为所有胶在第一次合上时一起用掉。`report()` 新增 `needsGlue`（把胶擦掉解不了）和 `glueFires`（确实有石头换了页）；`needs` 里用哪个看关：胶是**工具**用 `needsGlue`，胶是**陷阱**用 `glueFires`。

**死局**：卷一没有死局（印墨开门只加地面），卷二起有：合早了，石头被粘走 / 粘到路上，终点再也到不了。度量 v2 把它记成 `deadEnds`（§3），游戏靠撤销（U）和重来（R）兜底，读屏在合上那一拍报「有的路断了」（`lost`）。规则：**一关最多一种死局，而且进死局的那一下必须看得见**——石头飞过中缝贴到胶上（§4 的 `glue.pull` 动画），不是悄悄变的。

**不做的**：胶粘钥匙（粘过去永远对不上门，没有意义）；胶粘纸人（那是候选 #10 墨人）；重复使用的胶（求解器要带地图状态，而且"用掉"在纸上更真——胶被石头盖住了）。

## 2. 看起来：信笺

卷二换纸（spec §0 第 1 条：换卷才换纸）。**信笺** `paper.letter` #F6F3EC：比宣纸冷一点、白一点，印着淡格线——卷一的浮雕格到这里变成**印好的格**，格线色 `rule.letter` #545C76 @ 16%（实测在纸上约 1.4:1，装饰，不承载信息；高对比模式关掉）。中缝、朱线、纸人、合上的描图纸、影子的交叉线、灯晕全部同卷一。其余 4 个纸参数（spec §3）：透光 0.14 · 墨 100% · 背光 斜起时 0.45（同第四章）。

**胶** `g`：纸板格上一片**琥珀色的湿胶**，`glue` #E8B848 @ 62% 椭圆（约格宽 58% × 48%，中心略偏下），边缘晕开到 22%，下沿一道 inset 阴影读作厚度；中间一滴 `glue.line` #8A5A14 的滴形线稿（不填色）。湿的时候有一点高光；**用掉之后不画**——石头盖住了它，格子就是石头格。高对比：黑点阵（9 pt 栅格、2.5 pt 点）+ 黑线滴形，不靠黄。

**粘的动画** `glue.pull`（合上到 25° 时，和钥匙 / 墨同一拍）：石头从原格**抬起 2 pt、越过中缝、落到胶格**，220 ms，ease-out；落地时胶格闪一下（同 `flash`）；原格留一个淡淡的石头印（`stone.ghost` #000 @ 6%，1 s 淡出），读作"它刚才在这里"。书打开后，影子和压痕就在新位置了——不解释，让第三章的规则自己说话。减少动态：不抬不飞，直接换位 + 闪一下。

**章印**：五「胶」`seal.muted`，同前四枚位置与尺寸；篆体待定随「成」一起换。

## 6. 无障碍

**VoiceOver**：
