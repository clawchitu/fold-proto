## 1. 机制：第二道折痕（三折 v1）

**一句话：第三页接在右页外沿，有它自己的折痕。先把第三页折到右页上，再合书——左页碰到的是第三页；第三页上的洞里露出右页。**

`design-vol3.md` §1.4 把规则留到"灰盒后定"。v1 定成下面这张表（求解器、游戏本体、文字版走同一套 `logic.js`）：

| 规则 | 代码 | 一句"纸会怎样" |
|---|---|---|
| 三折关 `trifold: true`，12 列：左 0–3 \| 右 4–7 \| 第三页 8–11 | `create()` `s.tri`；**不是**第六章的"右页背面"（三折关不能翻，`flipBlock` = `single`） | 第三页摊在右页右边，第 7|8 列之间是第二道折痕 |
| **两道折痕，一次只动一道** | 书（第一道）只在第三页**摊平或合在右页上**时动；第三页（第二道）只在**书摊平**时动 | 先折哪道是玩家的选择；"一起折"不存在 |
| 第三页摊平、合书 | `face 0`，可见 12 列：右页 + 第三页是一整片硬卡纸一起抬 | 第三页的松石也往第一道折痕滚（跨过平着的第二道折痕滚进右页），也投影；合上时第三页伸出左页外沿、扣在桌上——站在上面就掉下去了；压只压左页和右页 |
| 折第三页（书摊平） | `face 2`：右页当平页、第三页当抬起页，可见列 0–7 = 实列 4–11 | 和一本普通的书一模一样：第三页的松石往**第二道折痕**滚、第三页的石头把影子投在右页上、合上时右页和第三页对压（胶 / 墨 / 钥匙 / 鹤，第三页列 c ↔ 右页列 15 − c）、叠合走法在右页和第三页之间换页。左页在一边平放，你在左页上就走不动（够不着） |
| 第三页合在右页上、合书 | `face 3`：抬起的那页是**两层**——第三页盖在上面，右页在下面 | 每一格看第三页；**第三页是缺口的格看穿到右页**；任一层是石头那格就是石头（纸片盖在石头上也是石头）。滚、影、压、鹤都对这张合成页做：第三页的松石往**第一道折痕**滚——在第三页自己的坐标里是**背着第二道折痕滚**（地图上向右） |
| **两次镜像回到自己那列** | 左页列 q ↔ 合成页 7 − q ↔ 第三页列 q + 8 | 她在第三页第 c 列，你在左页第 c − 8 列那一叠就够得着她：卷一的「合上 = 镜像」做两次 = 不镜像 |
| 打开第三页时你在哪层 | `face 3 → 2`：合成页上你站的那层（第三页那格是纸就在第三页上，是洞就在右页上） | 你站在最上面那层上 |
| 第三页合不上的一种情况 | 站在第三页的纸上、正下方右页是石头时合第三页（石背）：v1 判挤压（求解器 = 死，游戏 = 摔回起点） | 规避：关卡不画这种格；原生同步时再定要不要换成"站石背" |

**没进 v1 的**（`design-vol3.md` §1.4 原计划）：**Z 折**（先合书、再把第三页折到合着的书顶上：层序 L, R, T）和"折序决定地面"（反转 ②）。原因：① 合着的书的"顶面"是右页的背面——本作没有页背面上的格子（第六章的"第三页 = 右页背面"和三折是两种装订，同一关里不能都是）；② 每格三层、哪层是地面要由折序决定，一眼纸画不出来（`design-vol3.md` §1.4 的风险项）；③ v1 里折序已经决定结果——**先折第三页再合书**，左页碰到第三页；**先合书**，左页碰到右页（第三页在外面）——同一次「合上」两种答案，反转 ② 的意思留住了，只是层不是三层。Z 折去卷四开卷或暗信，要主人拍。

**规则纠正一条**（像第十章那条）：`design-vol3.md` §1.4 反转 ③「第三页的松石往第 8 列滚、九章练出的往第 4 列滚在第三页反了」在地图上不成立——第三页的折痕在它**左**沿，往第 8 列滚和往第 4 列滚在地图上都是向左。真正反过来的是**第三页合在右页上、书抬起来**的时候：那时它向第一道折痕滚，在第三页上是向右（第 9 列 → 第 10 列）。

## 2. 计划的反转（每关一个）

| 玩家被训练成的预期 | 实际（v1） | 用在 |
|---|---|---|
| 卷一：合上 = 镜像，她在 c 就去 7 − c 那叠 | 两次镜像 = 自己那列：第三页 q + 8 ↔ 左页 q | 教学关 |
| 第三页折上来就把右页盖住了 | 第三页的洞里露出右页：左页的胶、鹤、墨隔着洞碰到右页 | easy / mid |
| 第九章起松石往折痕滚（地图上永远向左） | 第三页合在右页上、书立起来：第三页的松石**向右**滚（背着它自己的折痕） | hard |
| 第十章：鹤飞到对页的镜像格 | 第三页合上之后鹤飞到第三页（右页被盖住了）；两次压 = 两次镜像，回到自己那列 | hard |
| 第十一章：开一点再合 = 悬 | 第三页也能悬、也能来回；两道折痕各算各的过立 | final |
| 合上只有一种结果 | 先折第三页还是先合书，左页碰到的是两张不同的页 | final |

谓词：每关的反转在 `tools/hunt.js` 里写成结构谓词，或者由 `check.js` 的 `needsTrifold`（不许动第二道折痕就无解）+ 关卡声明保证；显眼的路一律用 `tools/play.js` 实走验死，不推。
