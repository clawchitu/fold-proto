## 1. 《冰》四章

| 章 | 名 | 新东西 | 一句规则 | 回来的旧机制 | 关数 / 章 par |
|---|---|---|---|---|---|
| 十三 | 冰 Ice | `~` 冰（运行态 `u` 水） | 摊平 / 合上时冰是纸；页**停**在灯窗里时，**受光页**上没被影子罩住的冰化成水（不能走；站着化 = 落水 `melt`）；回到摊平全部冻回来；合上时石头正对的冰**压碎**成永久缺口 | 影 / 乘影（三、四）、灯位 L / LR（八）、活页门 `A`（八）、胶（五） | 6 / ≤ 22 |
| 十四 | 滑 Slide | 无 tile | 松石滚到冰上**不停**：顺着连续的冰一直滑到第一格不是冰的地方——纸就停、缺口就填、**水就沉**（那格从此是纸）；挡住它的是石头 / 门 / 你 / 页边，它就在最后一格冰上**破冰沉下去**（也成纸）。松石从不停在冰上 | 滚 / 身体挡石（九）、来回 / 悬（十一）、灯位 L（八） | 6 / ≤ 24 |
| 十五 | 镜 Mirror | `m` 镜 | 石头的一种（挡、遮光、压、胶能粘走）；影子落到它那格，就**折 90°** 沿它所在的列（朝向 ╲ 向下 / ╱ 向上）一直投到第一块石头或页边——那一列的冰全在荫里 | 影（三）、胶（五）、鹤（十） | 5 / ≤ 24 |
| 十六 | 融 Thaw | 关卡旗 `thaw` | 春天：化了的水**不再冻**；碎的碎、沉的沉照旧。每一次停在灯窗里都是花掉一截河 | 全卷 + 翻（六）：翻过去第三页是另一截河 | 5 / ≤ 24（final 6） |

**三拍**（全卷的尺子，接卷三 §0）：**过**（跨 90°）→ 滚、滑、沉；**停**（铰链停下 ≥ 300 ms，`restTarget` 吸附后的那一拍）→ 化；**压**（合到底）→ 碎 → 洇 → 印 / 钥匙 / 粘 → 飞（碎在粘之前：石头先把冰压碎，胶才把它带走——一次压两样不可逆，7-4 式）。**动的时候不化**：乘影一路改角不会把脚下化掉，停下那一刻脚下必须在荫里或不是冰。受光页：灯 R → 平放的左页；灯 L → 抬起的页；LR → 两页。背光页的冰在灯窗里不化（右页在 R 灯下只会滑、不会化——十三章全在左页做化，十四章用 L 灯让同一页又滑又化）。

### 1.1 十三「冰」——影子是伞

- **故事**：河结冰了，一眼望过去全是路。可你只要把书一立、灯一亮，没有影子罩着的冰就化。石头的影子，卷一你乘着它过河；现在你躲在它底下。
- **反转链**（六关）：冰是纸 → 灯窗里化、摊平又冻（错了不要紧）→ **影子罩着的不化**：挡你的石头是你的伞 → 影子随角滑，伞也滑：停错一个角，脚下就没了 → 胶把石头粘走 = 把伞收走 → 合上压碎的是**滚之后**那格下面的冰。
- **13-3 `shade` 伞（mid）**：她在左页河对面，中间两格冰，一道活页门 `A` 在冰当中（只有灯窗里是地面）。显眼的路：踩上冰、斜起开门——停下那拍脚下的冰没在影子里，落水。正解：先斜起到右页那颗石头的影子正好落在门前那格冰上的角度，停住，再走上去、过门。为什么死：卷一练出的「影子是要去踩的路」，这里影子是**唯一还在的地面**；一眼纸印得出每个角的影子，印不出的是你得在**哪个角**停住然后才动脚。
- **13-5 `crack` 碎（hard）**：左页冰河三格，右页一颗松石 `r` 在第 6 列。要合一次书（胶把左岸一颗死石粘到右页去开路）。显眼的路：直接合——跨 90° 松石先滚到第 5 列，压下来的是第 5 列正对的那格冰：河中间碎了一个永久的洞，回头路没了。正解：先来回一次让松石滚进缺口（它成了纸，压不碎冰），再合。为什么死：九章「滚进缺口是桥」训练成了"滚了就好"，这里**滚之后石头正对的格**才是被压碎的；卷二三的"合上才有事"第一次是坏事发生在你的地面上。

### 1.2 十四「滑」——太阳是刹车

- **故事**：石头在冰上停不下来。想让它停，就在前面化一滩水：它沉下去的地方，从此是纸。
- **反转链**：冰上一滑到底 → 水是刹车：**先停（化）再过（滚）**，石头沉在第一滩水里 → 影子留下的那格冰是石头滑过去的"桥"：用角度选沉点 → 你的身体是刹车，沉在你脚前 → 悬：开一点再合，压两次石头一格不滑 → 沉下去的石头是纸，纸压不碎。
- **14-2 `aim` 瞄（mid，灯 L）**：右页：松石 (7,1)，纸 (6,1)，冰 (5,1)(4,1)；左页石头 x 的影子在灯窗里落到右页第 5 或第 4 列（看角度）。她在右页上方，要在灯窗里穿一道 `A`，门前的落脚格必须不是冰。显眼的路（九章手感）：摊平 → 斜起：跨 90° 石头滚到 (6,1) 纸上停了，再斜一次它上冰——滑过 (5,1)(4,1) 到折痕边破冰沉在 (4,1)，门前 (5,1) 还是冰，站上去就化。正解：一次**来回**，但停在影子罩着 (4,1) 的角度：第一次过石头上纸，停下 (5,1) 化成水、(4,1) 在荫里还是冰；放平时第二次过，石头滑上 (5,1) 的水沉了——门前从此是纸；摊平 (4,1) 冻回来。为什么死：九章数的是"过几次"，这里要数的是**停在哪**；一眼纸印得出每个角的化图，印不出"第二次过的时候哪格已经是水"。
- **14-5 `brake` 刹（hard，灯 R）**：右页冰在 R 灯下不化（背光），只会滑。要合书过河，可左页那颗死石正对右页冰路上的 (5,2)——合上就碎，路断。显眼的路：先让松石滑过去（滑到折痕边沉在 (4,2)），再合：(5,2) 碎，死局。正解：站在 (4,2) 当刹车，松石沉在 (5,2)：沉下去的石头是纸，石头压不碎纸；再合。为什么死：十三章刚教完"石头下面的冰会碎"，玩家学会躲，这里要**主动把那格填成纸**——9-4 的身体挡石在冰上多了一层：你站的那格是终点，不是障碍。

### 1.3 十五「镜」——一道影子罩一列

- **故事**：影子只有一格宽，河有三格长。我在河里放了一面镜子：影子折过去，顺着河流下去。
- **反转链**：影子折 90° 成一列 → 镜在**哪一列**由影子落不落到它决定（只有一个角度对）→ 镜是石头：胶能把它粘到对页，到了对页它只是一块会投影的石头，折影没了、多了一道普通影子 → 鹤落在镜的折影里过河。
- **15-2 `bend` 折光（mid）**：左页一条竖的冰路 3 格，中段一道 `A`；右页一颗石头，一面镜 `m`（╲）在冰路顶上那列。显眼的路（卷一）：找石头影子罩住门前那格的角度——罩得住一格，走下一步脚下就化。正解：停在影子**打到镜子**的那个角，整列冰都在荫里，一路走过门。为什么死：三章起"影子 = 一格"，这里影子 = 一列；一眼纸的 VIEW 2 印得出折影，但截图上镜子看着就是一块石头。
- **15-4 `take` 取镜（hard）**：同样的竖冰路，但过门之后要合一次书（叠合换页），而左页有一格胶正对着镜。显眼的路：靠折影过门、合——胶把镜粘走了，打开再斜起，折影没了，回程那列冰化在你脚下。正解：先合（镜被粘到右页，它的**普通影子**现在落在左页的另一列）、再用这道新影子护住回程唯一要停的那格、最后才走竖路。为什么死：7-4 式——胶在卷二是帮手，十四章是坑，这里先是坑后是钥匙：取走镜子的那次合给了你一个新的投影体。

### 1.4 十六「融」——不能悔棋的河（终章）

- **故事**：春天。化了的，不再冻。你护了一卷的河，最后要亲手让它化完。
- **反转链**：十三章"摊平就冻回来，错了重来"→ 这里每次停在灯窗里都是花钱：第一次停就得替第二次留影子 → 翻页：第三页是另一截没化的河，但翻 = 合 = 压碎 → **终关**：没有任何影子可护，正解是把河全化了，用来回把松石沉成唯一一块永久的纸，最后一合什么也碎不了。
- **16-2 `spring` 春（hard）**：要两次停在灯窗里（一次乘影、一次开门），两次需要的落脚格不同。显眼的路：十三章的习惯——先随便斜起看一眼。看的那一下把第二次要用的冰化没了。正解：第一次停的角度同时要罩住第二次的格。为什么死：全卷第一次"看一眼"有代价；一眼纸印得出每个角，印不出你**停过几个角的并集**。
- **16-5 `river` 河（final）**：LR 两盏灯 + 镜 + 松石 + 冰 + `thaw`。显眼的路：找影子护路——两盏灯下影子互相抵消不了水，护不住任何一条路。正解：**全化掉**（把灯窗停遍，河成水）、来回让松石沉成河中唯一一格纸、站上去合书——河里没有冰了，什么都碎不了，叠合直接到她。啊哈一句：「你护了一卷的东西，最后一关要放手。」卷四的信尾：「冰化了，河又是河。」（roadmap §1 早就写好的那句）。

## 3. 美术 / 调子

- **纸**：**皮纸 + 冰纹**（roadmap §1）。卷三硬卡纸透光 0.08 是给这卷留的对比：皮纸透光 0.35，冰格是半透的浅色 + 一道裂纹（高对比：格内一道斜裂线），水是三道横波（高对比同），碎冰 = 缺口里留几片白角。化：停住 0.3 s 后裂纹蔓延、格子沉一档、横波浮上来（和 `restTarget` 吸附同拍，减少动态 = 交叉淡化）；冻：摊平那一帧白一下。荫里的冰**不画任何提示**——荫是三章的影子，玩家认识它。
- **章题 + 章印**（`sealGlyph`，一动作一字的字族：达 通 影 成 落 载 …）：十三「冰」印 **荫**（影子作伞）· 十四「滑」印 **沉**（石头沉成纸）· 十五「镜」印 **映** · 十六「融」印 **春**。印字不和关名撞（ch10 评审的规矩）；章首空镜：十三「一页立起，冰面起雾、一格化开」，十六「整条河化开，纸白了」。卷名《冰》/ Ice / 氷 / 얼음（`letter.12.end` 已用这几个字）。
- **声音**：化 = 一声低的碎裂 + 水声尾音；沉 = 卷三松石闷响 + 一声"咚"；全卷唯一的高音留给冻（摊平那一帧的一声"叮"）。**Duo**：十三章 13-2 一次性的一句「把手机半开着搁一会儿。」（`duo.iceHint`，同 `duo.hint` 的规矩：一装机一次、6 s 淡出、VoiceOver 改公告）。

## 7. 开放问题（要主人拍板）

- **「停住才化」**：是本卷最重要的一条规则也是最难讲的一条。备选是"进灯窗就化（按所到角的并集）"——更物理，但乘影会把脚下化掉、护冰几乎不可能，一眼纸也印不出。我选停住；章首空镜 + 13-1 两拍笺要把"停"演出来。
- **碎在粘之前还是之后**：之前（本文）= 一次压两样不可逆，更狠；之后 = 胶能救冰，更温和。一行代码的事，13-6 试玩后定。
