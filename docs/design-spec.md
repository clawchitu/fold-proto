# 《折信》Letterfold 设计规范 v1（2026-10-16）

来源：Claude Design 项目「Letterfold Paper States」（https://claude.ai/design/p/a1875a33-7e04-4c9f-b574-57bcc2d1392d ），已按 `design-review-1.md` 修订。规则冲突时以 `design-review-1.md` 和 `plan.md` §9 / §11 为准。所有数值单位为 pt（@1x）。效果图在 `~/.tomo/workspace/tmp/fold/design/final-*.jpg`。

## 0. 不可破的规则

1. **一张纸，三种状态**：每章只改 4 个参数（纸色、透光、墨饱和、背光），框架、格子、角色、UI 都不变（§3）。
2. **线只有两种**：中缝（会动的折痕）和朱线（走过的路）。不画装饰折痕，也不画辅助线。
3. **朱线 = 已经走过的路**：跟在纸人身后，像缝线。不画解法。书打开时两页不相通，朱线不跨中缝，只有合上时才"穿"到对页。到终点打一个结。
4. **只画 `levels.js` 里有的元素**：路、缺口、起点、终点、石头、钥匙、门、墨、纸片、影子。剪刀、胶水、镇纸、压力格、纸门、折痕裂缝、墨渍、印章道具都是「候选 · 未入选」，只出现在精灵图的探索区。
5. **默认界面没有控件**：没有滑块、角度读数和按钮行。输入只有拖页和点格；Duo 上铰链是并行的第三个输入，写同一个页角度，游戏从不要求用它（`plan.md` §12）。按钮行只在无障碍模式下出现（§7）。
6. **只用系统字体**：Songti SC、PingFang SC、SF Pro / New York、Hiragino、Apple SD Gothic Neo。不打包字体文件，也不用思源宋体。
7. **只有一种强调色**：朱红系。满饱和的 cinnabar 全游戏只出现一次（终章「成」）。

## 4. 布局与间距

- 基础网格 4pt；常用 4 / 8 / 12 / 16 / 20 / 24 / 32 / 44。屏幕边距：iPhone 20，设置页分组卡片 16，标题区 24。
- **手机竖屏用横折痕**：上页向下合到下页。上页 = 右页（第 7→4 列，从上往下），下页 = 左页（第 3→0 列，从折痕往下）。地图里的「行」对应屏幕上从左到右的「列」。合上时第 c 列落到第 7−c 列。Duo 和 iPad 横屏保留竖折痕，Duo 上就是铰链。
- 书：两页各 352 × 352（4 行地图）或 352 × 285（5 行地图）。书宽 352，中缝在 y = 464 / 440。
- 格子：4 行地图 80，5 行地图 63（≥ 44），间隙 4；Duo 76；超大格子 ≥ 64（4 行地图 92，棋盘可滚动）。
- 路格：比纸深一档的面色 + 底边 1pt 投影。缺口没有厚度。背光页上的路格用"透光更亮 + 1pt 描边"表示。
- 影子：一整格方形，边缘柔，叠 ±45° 交叉线。不用中间灰。
- 中缝：亮线 1.1pt（白 95%）+ 暗线 0.8pt（墨 30%），间距 1.2。终章只有中缝发白。
- 朱线：3pt 缝线（虚线 8 / 5），投影 (0.7, 1.3) 22%。
- 圆角：格子 3 · 卡片 6 · 分组 14 · 胶囊 22 · 主按钮 28。
- 顶栏只放两个图标：左「书」（回到章节）、右「?」（提示，第一次卡住时才出现）。热区 44 × 44。
- Duo：每块屏一页，页 290 × 512（1.6×）。

## 5. 动效

| 名称 | 时长 | 曲线 / 说明 |
|---|---|---|
| hinge.drag | 0 ms | 1:1 跟手。整张上页都能拖。松手吸附到 0° / 90° / 130° / 180°；第三章在 91°–154° 之间不吸附，130° 处有软阻尼 |
| hinge.release | 160 ms | cubic-bezier(.2,.7,.2,1) |
| hinge.device | 160 ms 追上，之后 0 ms | Duo 铰链：300 ms 内转动 ≥ 8° 才接管，虚拟页 160 ms 追上物理角再 1:1 跟随；手指按着页时手指优先；铰链停 300 ms 后交回手指，虚拟角与物理角允许不同。物理 90°–180° 原样映射，物理 30°–90°（熄屏角 + 10°，M2 标定）压到虚拟 0°–90°。停下后吸附规则同 hinge.drag |
| close.snap | 220 ms | spring，response 0.32，damping 0.72 |
| page.press | 120 ms | ease-in-out，纸面下压 2pt（两页相触） |
| crease.glow | 140 ms | ease-out，峰值亮度 +18%，之后 260 ms 衰减 |
| unfold.auto | 300 ms | ease-out（"啊哈"之后自动展开到 180°） |
| thread.draw | 420 ms | cubic-bezier(.65,0,.35,1) |
| seal.drop | 180 + 90 ms | ease-out 落下，再 cubic-bezier(.3,1.5,.6,1) 从 102% 回到 100% |
| ink.bleed | 600 ms | ease-out，洇开半径 0 → 6pt（每合一次往外洇一格） |
| backlight.on | 350 ms | ease-in-out，透光 0 → 0.60 |
| closed.caption | 1000 ms | 合上（0°）后「信，送到了。」淡入 |
| angle.hint.fade | 600 ms | 松手后角度小字淡出 |
| reduce.motion | 200 ms | 线性交叉淡化，没有位移和回弹；不自动播放幽灵手教学 |

"啊哈"三步共 1470 ms，任何一步都能被手指打断：① 合上前一刻（−220 → 0）② 相触·啪（0 → 480）③ 打开·路已接通（480 → 1470）。

## 6. 触觉与声音

| 事件 | API | 强度 | 声音 |
|---|---|---|---|
| 姿态档位 / 每 15° | UISelectionFeedback | — | 纸页轻擦 |
| 吸附到姿态 | Impact .medium | 0.6 | — |
| 两页相触 | Impact .rigid | 0.9 | 「啪」，干纸相拍 80 ms |
| 印章落下 | Impact .soft | 0.6 | 「笃」，木印 |
| 路接通 | Notification .success | — | 本章音色单音 / 上行琶音 |
| 撤销 | UISelectionFeedback | — | 反向纸擦 |
| 撞墙 / 走不到 | Impact .light | 0.4 | 空心短音 |
| 影子滑动 | CHHaptic continuous，强度跟着影子速度 | — | 低频持续音，随移动滑音 |

铰链驱动页时不播「吸附到姿态」的 Impact（铰链本身就是触觉），每 15° 的 Selection tick 和「两页相触」的「啪」保留。设置里「触觉强度」分 关 / 弱 / 强，对应 0 / 0.6× / 1.0×。（精灵图卡片里还写了压力格、墨渍、折痕撕开的触觉，这些都属于未入选的候选，不实现。）

## 7. 无障碍

**对比度（实测）**：正文 ink.900 在新纸 15.59:1，在旧纸 13.05:1；次级 ink.700 8.87:1；朱线 4.55:1（新纸）、4.91:1（thread.aged 在背光页）、4.53:1（thread.aged 在旧纸）；高对比模式黑字灰底 17.94:1，朱线在白底 8.69:1；字幕（纸色字、墨底）15.59:1；关卡名 40% 灰只有 2.41:1，属于装饰，所以 AX 字号和高对比模式下恢复成 100% 墨色。

**触控尺寸**：所有控件 ≥ 44 × 44（书、?、页脚按钮、转子项）。格子 80 / 63，Duo 76。超大格子 ≥ 64（4 行地图 92）。页脚按钮 ≥ 64 × 52，间距 4。「走」书签可见区 30 × 150，热区 44 × 150。拖页的热区是整张上页，不只是边缘，对手部震颤更友好。

**高对比花纹**（意义靠形状和花纹表达，不靠颜色）：

| 元素 | 高对比画法 |
|---|---|
| 路 | 白底 + 3pt 黑框 |
| 缺口 | 灰底 #EDEDED，无框 |
| 石头 | 45° 斜线 1.8 / 5 + 3pt 轮廓 |
| 影子 | ±45° 交叉线 1.8 / 6 + 2.5pt 虚线框 |
| 纸片 | 横条纹 2 / 6 + 3pt 框 |
| 终点 | 双框 2pt，内框内缩 8 |
| 墨 | 实心笔触块；已经印走的位置画 2.5pt 虚线框 |
| 钥匙 / 门 | 实心钥匙轮廓 / 3pt 门框 + 锁孔 |
| 朱线 | 4pt 虚线 9 / 4，#8E2419，8pt 白衬，终点打结 |
| 两个纸人 | 靠轮廓区分：寄信人拄拐杖，收信人有发髻、提灯 |

**焦点环**：外框 2.5pt ink.900，外偏移 7、圆角 7；外框内外各衬一圈 1.5pt 白线，在任何底色上都看得见；内框 1.5pt，内缩 3；四角 L 形角标 12 × 12，线宽 3，外偏移 13。折页控件的焦点环画在页面上，跟着 3D 倾斜。切换控制用 2.5pt 虚线框 + 序号圆标，扫描顺序：① 折叠动作 → ② 「走」→ ③ 棋盘。

**按钮控制模式**：只在三种情况下出现：设置里打开「按钮控制」；系统正在运行 VoiceOver / 切换控制 / 语音控制；或者 AssistiveTouch 开启。出现时是一条像"书的页脚"的按钮行，5 个按钮：折一点 · 展开一点 · 合上 · 打开 · 撤销（每次 15°，没有精度和计时要求）。「走」是夹在书里的书签，点开是四向一步、听一行、我在哪。这些动作同时注册为 `accessibilityCustomActions`。

**读屏文案格式**：
- 格子：`第{行}行第{列}列，{类型}；{状态}；{合上后会发生什么}`，例如「第3行第2列，缺口；合上后对面的纸板会落在这里」。
- 折页控件：`{姿态} {角度}°，可调整，上下轻扫每次 15°`。
- 事件（announcement）：「书已合上，路接通了」「影子带着你滑到了第3行第2列」。
- 转子：路 · 缺口 · 物件 · 影子。
- 页：下页（左岸）、上页（右岸）。行列号始终按地图算，和屏幕朝向无关。
- 纸的状态也要读出来，例如「这页纸举到了灯前」。
- 棋盘的 `accessibilityValue` 给进度，例如「第 3 步，离终点 2 格，书已合上」。朱线不能是进度的唯一表达。

**声音模式**（明眼帮手看到的画面）：一张立体声场图，左耳 = 下页 / 左页（木），右耳 = 上页 / 右页（纸）；音高 = 行，按五声音阶 宫 商 角 徵 羽 宫′（C4 D4 E4 G4 A4 C5）；下面是播报字幕和最近 4 个声音事件。缺口是空心短音，影子是低频持续音，墨是湿润滑音（印到对页时出双声），接通是上行琶音。

**色盲**：三种纸状态分别做了原色、红色盲（protanopia）、绿色盲（deuteranopia）三列模拟（Viénot 1999，近似值）。意义由形状承担：朱线的虚线针脚和结、终点双框、印章上的字、影子的交叉线。正式结论要在真机上用 Xcode Accessibility Inspector 和 Color Oracle 复核。

**设置项**：按钮控制、语音朗读、声音模式、触觉强度（关 / 弱 / 强）、高对比度、超大格子（≥64pt）、减少动态效果、语言（中 / EN / 日 / 한，默认跟随系统）、铰链折页（开 / 关，默认开，只在有铰链的设备上出现）。

**折数（par）**：每关最优解 ≤ 3 次姿态变化、完全合上 ≤ 2 次（`plan.md` §12.3）。棋盘上不显示；只在「书」菜单的关卡列表里以「折 2 / 标准 2」出现，numeric 字号，不惩罚超标。

## 8. 角色与图标

- **皮影纸人**：侧身，关节有铆钉，有镂空纹样和细操纵杆。寄信人拄拐杖、穿长衫；收信人梳发髻、提灯。每个人画站立、行走（2 帧，240 ms）、背光三种状态。纸人的墨色是 ink.figure；背光时是剪影加一圈逆光描边。
- **App 图标**：推荐方案 A，一张对折的纸 + 中缝 + 一根朱线，在中缝上打一个结，图标上没有字。40px 下仍然能认出来，浅色、深色、着色三种主屏模式都检查过。备选方案 B 是「折」字压在一道斜向山折上，但 60px 以下字形会糊成一团。

## 9. 还没定 / 待验证

- 设计稿里 hinge 的吸附点写的是 60 / 90 / 120 / 180，这里按评审改成 0 / 90 / 130 / 180。
- 终章「两人」在 `levels.js` 里还没有地图，设计稿里的布局是临时的。
- 背光、半透明、软影能不能在 120 fps 下做出来，取决于 RealityKit 风险 5 的结果。
- 超大格子模式：单指拖页，双指滚动棋盘。这个分法要在测试里确认。
- Duo 铰链（M2 标定）：熄屏角与「合上」阈值（暂按物理 30°）；8° / 300 ms 接管门槛在沙发换手时是否误触；物理角与原型 `fold` 值（= 180 − 物理角）的换算，确认第三章 91°–154° 对应的真实倾斜。
- 幽灵手在 Duo 上只在四处演示铰链（3-1、3-4、每章末关、4-8），其余演示拇指；需要出一版铰链幽灵手。
