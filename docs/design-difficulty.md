# 《折信》难度重调（2026-10-18）

起因：主人玩完 0.1 (8) 的 17 关：「每个关卡难度都不大，完成起来比较快」。本文给出：① 一个写进 `tools/check.js` 的难度度量，CI 断言每关落在设计者声明的档位；② 对现有关卡的重调（教学关 1-1、2-1、3-1 不动）；③ 每个档位的目标解题时间。第四章的关卡见 `design-ch4.md`，长期难度曲线见 `roadmap.md`。角度写**物理角**（180° 摊平、90° 立起、0° 合上），括注 `levels.js` 的折角。

---

## 1. 诊断：为什么快

把 17 关全部跑过求解器（§2 的度量）之后，原因不是"关卡小"，而是三件事：

1. **一关一个机制，而且只有一条路。** 17 关里 `combo`（解法缺不了的机制数）≥ 3 的只有 2-5、2-6、3-6 三关。其余每关只问一个问题，问题的答案就是章名。
2. **没有任何陷阱。** 第一、二章的印墨和开门只会**增加**可走的格子，影子来回都能走，所以**没有一个可到达的状态是死局**（`dead = 0`，全部 17 关）。玩家做什么都不会错，只会"还没对"。第三章有摔落（`kills`），但摔落全部发生在影子上，是意料之中的；没有一关有"站在纸上、合上就被压"的陷阱可以踩到（`trap = false`，除 3-2）。
3. **走得太少。** 最优解平均走 6 格，第三章 3–4 格。看一眼、折一下、点两格，就过了。

所以不是加地图、加折数（par ≤ 3 是铰链疲劳规则，`plan.md` §12.3，不动），而是：**让机制互相作用、让显而易见的那一步出错、让合上之前站在哪一格成为问题。**

## 2. 度量：`tools/check.js` 的 `analyse()`

对每关枚举全部可达状态（格、角度、是否已盖印），得到：

| 量 | 含义 |
|---|---|
| `par` | 最少姿态变化（原有） |
| `walk` | 最优解走过的格数 |
| `forks` | 能过关的**最短姿态序列**有几种（合并"再合一点 / 再开一点"的同义写法）。1 = 只有一个想法成立 |
| `trap` | 最优路线上的某一格**站在纸上**合书会被压（影子上摔落不算，那是预期） |
| `window` | 最优解用到的斜起角度，在采样的 7 个斜起角里有几个能顶替（≤ 2 = 需要精度；0 = 需要乘影） |
| `combo` | 去掉哪个机制就解不了（合 / 立 / 影 / 乘影 / 钥匙 / 墨），计数 |
| `explore`、`dead`、`kills` | 可达的格×姿态数、死局数、摔落/被压的（状态, 动作）对。**只报告不计分**：`dead` 在现行规则下恒为 0（见 §1），留着是为了将来某条规则打破它时能被看见 |

**score = par + [forks = 1] + [walk ≥ 8] + [trap] + [window ≤ 2] + [combo ≥ 3]**，0–8。

| 档位 `tier` | score | 目标解题时间（首次、不看提示） | 定义 |
|---|---|---|---|
| teach | 0–2 | 20–45 s | 一个新事实，一条路，没有坑 |
| easy | 3–4 | 45 s–1.5 min | 用一次学过的东西；或一点精度 |
| mid | 5–6 | 1.5–3 min | 两个机制相互作用，或一个陷阱 + 一条长路 |
| hard | 7–8 | 3–6 min | 三个以上机制、唯一解、陷阱、需要乘影或精度 |
| final | 8 | 5–10 min | 章末：hard 的满分，再加故事的那一合 |

每关在 `levels.js` 里声明 `tier` 和 `needs`（必须保持为真的求解器标志）。`node tools/check.js` 对 25 关断言：可解、只用 15° 一档可解、par ≤ 3 且完全合上 ≤ 2、**score 落在声明档位内**、`needs` 全真。改一格地图把陷阱改没了，CI 会红。

**度量看不见的**：假线索的"像不像"（对面缺口处的纸板诱你合上，度量只在它造成陷阱时计分）、视觉上的发现成本、斜起窗口在真机上的手感。这些靠 §5 的原则和试玩计时；每章试玩后把实测时间填回这张表，必要时调档位边界，不调公式。

## 5. 把关做难的原则（给后面的章用）

1. **机制相互作用，不是机制并列。** 「影子过不了锁着的门」比「先开门、再走影子」难一倍，因为玩家要在脑子里把两条规则放到同一格上。`combo ≥ 3` 是硬指标，但要的是作用，不是出场。
2. **终点在合上时到不了。** 合上是玩家的第一反应，所以终点那一叠的四邻在合上时必须被下页的石头或双面缺口堵死（第四章六关都这样建）。显而易见的那一步要**做点什么**（印墨、开门、压死你），只是到不了。
3. **par 不涨，精度和顺序涨。** 3 次姿态变化是上限，所以难度来自：第几次合、合到多少度、合之前站在哪。乘影占 2 次，所以乘影关只剩一次合可以用——这正好逼出"先合还是后合"的问题。
4. **假线索要有物理。** 对面缺口处的纸板（3-2）、通向孤岛的第二道影子（4-5）、三块挂在路上的石头只有一格安全（4-4）——每个假线索都是真规则的真后果，不是贴上去的装饰。
5. **陷阱要教东西。** 被压回到起点的那一下必须让玩家知道为什么（合上帧的虚线框 + 压痕，`design-review-3.md` §closed）。一关最多一种陷阱。
6. **走路是节奏，不是难度。** `walk ≥ 8` 只占一分；它让一关有呼吸，让朱线有长度。不要用迷宫凑数。
7. **15° 一档必须全解。** 窄窗口靠影锁（`design-review-ch3.md` §3）成立，不靠手稳。
