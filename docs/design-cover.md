# 《折信》书封动效规格：柳絮过纸（2026-10-18）

对象：书封（`design-review-1.md` §1.5 骨架：满屏「折」、一道斜向山折横穿字面、朱线从顶端垂到「开始」纸签；`design-review-2.md` §4.4 定的 7-1「拉线」CTA：纸签 48 × 72 pt，拉 ≥ 64 pt 或轻点，进入封面 1.5 s 后轻晃一次）。主人要求：更美、更唯美，像落花那样的轻动画。本文定主题、运动、与纸签和开场转场的关系、减少动态、性能预算。不写 App 代码。

---

## 1. 主题：**柳絮的影子**，不是花瓣

候选：花瓣、柳絮、剪纸碎片、墨点。判断：

- 花瓣：江南题材的默认答案，每个水墨游戏的封面都在飘；而且花瓣是彩色的，我们的世界只有纸、墨、朱红（spec §0 第 7 条）。否。
- 剪纸碎片：形状太硬，像 UI 粒子；也不属于《两岸》的叙事。否。
- 墨点：墨在这个游戏里是**规则**（印、洇），封面上飘墨会让玩家以为墨会动。否。
- **柳絮**：两岸有柳，柳絮过河，是《两岸》自己的意象；白、轻、慢、随风。但白柳絮在白纸上看不见。

所以不画柳絮，画**柳絮的影子**：第三章已经定了灯在纸的后面（`design-review-ch3.md` §5 第 1 条），把封面也举到那盏灯前——柳絮在灯和纸之间飘过，纸上落下的是柔边的小灰影，像从一扇糊着纸的窗里看外面的春天。这一张画只有我们能画：影子是本作的签名，灯是第三封信里的那盏灯，而且它对所有人解释了「为什么纸是半透明的」。

颜色：影子用 `shade` #6E604E，三层不透明度 **贴 55% / 近 45% / 远 28%**（评审 `design-review-ch4.md` §1：第一稿 30 / 18% 加模糊后实测只有 1.2 : 1，手机实尺寸上读作白纸），叠在纸色上（不改纸色、不加新色）。纸之上、影子之下有一层 `lamp` #FFD08A 的径向暖晕：中心 (0.55 W, 0.35 H)、半径 0.7 W、中心 6% 到边缘 0——纸是举在灯前的。没有柳絮本体。

## 2. 运动

坐标：屏幕 pt，竖屏 iPhone 393 × 852 为基准；其他尺寸按面积等比缩放数量，尺寸和速度不缩。

| 参数 | 值 |
|---|---|
| 数量 | iPhone **22** 片同屏（上限 24）；iPad 30–34；Duo 两屏 26–28。按屏幕面积 ÷ **15,200** pt² 取整；层比固定 贴 3 : 近 7 : 远 12 |
| 三层 | **贴层**（贴着纸，3 片）：直径 20–26 pt，模糊 0.5 pt，不透明 55%，迎风面（左上）带 3–5 根 1–3 pt 的短绒毛（形体，不是轨迹线）；**近层**（7 片）：直径 14–18 pt，模糊 1.5 pt，不透明 45%；**远层**（12 片）：直径 7–10 pt，模糊 3 pt，不透明 28%。离纸越近越小、越实、越深。模糊是预渲染的 4 张纹理（锐 / 小 / 中 / 大），不实时模糊 |
| 形状 | 不是圆：三个略不规则的"绒球"轮廓（手绘，边缘有 2–3 个小凸起），随机旋转初值，**不自转** |
| 下落 | 贴层 32–40 pt/s，近层 22–28 pt/s，远层 14–18 pt/s，每片恒速（风不是雨，不加速） |
| 漂移 | 水平 x += A·sin(2πt / T)：A 贴层 12–16 pt、近层 8–12 pt、远层 4–6 pt；T 3.5–5.5 s；每片独立相位。整体一个 **−12°** 的风向（向右下，顺着斜向山折 = 河的方向），即每秒再加 下落速度 × tan 12° 的右移 |
| 生成 | 从上边与左边外侧 20 pt 处生成，速率约 1 片 / 0.8 s（按数量上限节流）；出下边或右边 20 pt 后回收。寿命 12–20 s |
| 呼吸 | 不透明度在生命中段缓慢起伏（周期 6–9 s）：贴 / 近层 ±20%，远层 ±12%；灯晕同相位 ±1.5%。灯忽明忽暗的感觉，不是闪 |
| 山折两侧 | 斜向山折上下两侧明暗不同（review-1 §1.5）：暗侧的影子不透明度 ×1.25（封顶 60%），过折线时 120 ms 线性过渡 |
| 与「折」字、朱线 | 影子画在**纸层之上、字和线之下**：纸 → 灯晕 → 影子 → 折面明暗 → 「折」→ 朱线 → 纸签。影子穿过字的笔画时被字遮住，不改字的对比度。静帧 / 商店截图的构图：至少 1 片贴层、2 片近层被「折」的笔画局部遮住，1 片近层被《折信》遮住；贴层不压纸签 |
| 陀螺仪视差 | 可选，默认开（跟「体感」设置无关，这是装饰）：取设备姿态的低通（截止 2 Hz）俯仰 / 横滚，近层平移 ±6 pt、远层 ±2 pt，最大倾角 ±25° 处饱和。减少动态效果或低电量模式下关 |
| 帧率 | 封面锁 **60 Hz**（ProMotion 不上 120：装饰层不值）；进入关卡才回到系统帧率 |

一句话给建造：一个 `TimelineView(.animation)` + `Canvas`，每帧画 ≤ 24 张预模糊纹理，位置用 t 的闭式函数算（无物理模拟、无状态积分），回收用环形数组。

## 3. 与纸签、与开场转场

拉线 CTA 的规则不变（review-2 §4.4：拉 ≥ 64 pt 或轻点触发；拉的过程中封面像上页一样跟手向下折；松手过阈值完成折叠进地图 / 首次进 1-1；不过阈值弹回，不给触觉；完成时 Impact .medium）。影子在折叠过程中要**服从第三章的物理**，不然这张画就是在说谎：

1. **影子在纸上，所以跟着纸折。** 拖拽时封面页绕**封面自己的横折痕**（标题与副标之间那道，y ≈ 568；评审 §1 偏差 ①）翻下来——朱线从页顶垂到纸签，拉纸签就是把页顶拉过折痕（review-3 §2 的朝观者折）。折痕之上露出的内页在灯亮期间保持 40% 不透明，灯灭起 350 ms 升到 100%，影子作为纸面的一层随纸一起转，不浮在屏幕上。
2. **页越合，影子越往下滑。** 第三章的规则是影子位置 = `d·cos θ`。封面上做同一件事的简化版：每片影子在纸面上额外下移 `h · (1 − cos θ)`，h = 贴层 56 pt、近层 40 pt、远层 16 pt，θ 为折角。拉到一半（90°），近层的影子比原位低 40 pt——和 3-1 里影子滑过缺口是同一种运动，第一次拉纸签的人就已经在看第三章了。
3. **合过 60°（折角 120）灯灭。** 透光从 0.45 退到 0（`backlight.on` 的反向，350 ms），灯晕和影子沿同一条曲线淡出到 0；描图纸状态（review-3 §closed）接管，封面背面透出章节地图或 1-1 的轮廓。松手过阈值的最后一段里屏幕上已经没有柳絮。
4. **弹回时全部反向**：不过阈值松手，页 `close.snap` 弹回 180°，灯 350 ms 亮回来，影子从当前位置滑回原位（不重新生成，不闪）。
5. **轻点触发**（不拉）：播同一段折叠 320 ms，影子同样滑、同样灭。
6. **1.5 s 的纸签轻晃**不变；晃的时候朱线下端 ±4°，影子不响应（风吹的是柳絮，不是线）。
7. **Duo 铰链**：合手机 = 拉纸签（plan §12.1「谁最后动谁说话」）；影子按物理角滑；熄屏前 10° 处算合上，和游戏里一致。

进入地图后封面层销毁；返回封面（「书」→ 书封）时影子从随机进度**已在场**，不从空屏开始飘（避免"开机动画"感）。

## 4. 减少动态效果

系统「减少动态效果」开启时（spec §5 `reduce.motion`）：

- 影子**静止**：6 片固定位置（设计稿给坐标），贴 2 近 2 远 2，不透明度按 §2（55 / 45 / 28%）不呼吸；灯晕静止 6%；无视差。
- 拉纸签：页仍跟手（这是输入反馈，不是装饰），但影子不滑；过 60° 时 200 ms 线性淡出，不弹回动画（直接到位）。
- 纸签 1.5 s 轻晃取消，保留静态下拉箭头（review-2 §4.4 第 3 条）。
- 「降低透明度」开启：影子用实色 #6E604E 按 55 / 45 / 28% 预混到纸色（按 paper.new #F7F4EE 算：贴 #ACA396、近 #B9B1A6、远 #D1CBC1，出稿时按实际纸色核），不用 alpha；不画灯晕。
- 低电量模式：按减少动态处理，但保留纸签轻晃。

VoiceOver：影子层 `accessibilityHidden`；封面只有「折 · 折信」标题、「开始」纸签、右上「设置」三个元素，顺序不变。

## 5. 性能与电量预算

| 项 | 预算 | 怎么测 |
|---|---|---|
| CPU | ≤ 1.5 ms / 帧（A15 及以上），封面 60 Hz | Instruments Time Profiler，封面停留 60 s |
| GPU | ≤ 24 次纹理绘制 / 帧 + 1 次灯晕渐变，无实时模糊、无阴影、无 `blur()` 修饰符 | Metal System Trace：无 offscreen pass |
| 内存 | 4 张纹理（24 / 32 / 48 / 64 px @3x），< 260 KB | — |
| 电量 | 封面停留 10 min ≤ 1%（iPhone 15，50% 亮度） | `xcrun xctrace` Energy Log，对比关掉影子层的基线，差 ≤ 0.3% |
| 空闲 | 封面无触摸 90 s 后影子 2 s 内减速到停（不消失），再有触摸 1 s 内恢复；App 进后台立即停 | — |
| 热 | 不允许触发 `thermalState ≥ .serious` 下的任何掉帧；`.serious` 时按减少动态处理 | — |

不做：粒子系统框架、每片独立 `View`、物理引擎、Core Image 实时模糊、120 Hz。

## 6. 给设计稿

出两帧 + 一条带（导出 `~/.tomo/workspace/tmp/fold/design/cover-*.jpg`）：
1. `cover-still` 摊平封面：22 片影子的一个"好看的瞬间"（坐标表随稿给，减少动态用其中 6 片：贴 2 近 2 远 2）。
2. `cover-pull` 拉到 90°：封面页翻下来一半，影子整体下滑贴层 56 pt、近层 40 pt、远层 16 pt，灯还亮着。
3. `cover-strip` 五帧条带：180° → 120° → 90° → 60°（灯灭、影子淡出中）→ 合上（描图纸、地图透出）。

标注里不要出现角度数字和轨迹线（spec §0 第 5 条）；影子不要画成圆点，要有绒球的轮廓。每帧另交一张 180 px 缩略图和一张手机实尺寸图：缩略图上要看得见「有东西在飘」，实尺寸上能数出 ≥ 10 片（`design-review-ch4.md` §1）。

**出稿记录（2026-10-18）**：Claude Design 第十行（`ch4-preview.html?s=8–12`，条带单帧 120–124）。导出 `cover-still`（18 片 + 坐标表，◆ = 减少动态的 6 片）`cover-pull` `cover-lampoff` `cover-reduce`（含降低透明度预混色 #C9BFAD / #DDD5C4）`cover-strip`（摊平 → 抬起 → 半折 → 灯灭 → 合上）。逐张看过：影子是绒球轮廓、不是圆点；在「折」字之下；屏内无角度数字和轨迹线；纸签、朱线、宋体同旧封面。
- **偏差**：① 铰链在封面自己的横折痕（y 568）上，不在屏幕上边：上边做铰链时页会翻出屏幕，合上时也透不出地图。② 拉到一半时内页（地图）已露出，灯亮着时地图压得很淡。③ `cover-pull` 里折下来的那一段纸上影子很少、很淡（背面朝向你）；静帧与下拉位置的对照放在屏外的面板里。④ 减少动态的 6 片，近层两片不透明度是 30%（坐标表），表里另有几片近层 37.5% / 远层 22.5% 是山折暗侧 ×1.25 后的值。
- **评审（`design-review-ch4.md` §1，2026-10-18）**：影子实测对比 1.14–1.28 : 1，手机实尺寸上读作白纸 → 主题留、强度改为本文现行数字（三层 22 片、55 / 45 / 28%、贴层绒毛、灯晕 6%）；偏差 ① ② ③ 接受并写进 §3，④ 按 §4 重算。**待重画**：`cover-still`（新坐标表）、`cover-pull`、`cover-reduce`、`cover-strip` 10-5a / b / c；`cover-lampoff` 不用。

**重画记录（2026-10-18，第二稿）**：Claude Design 第十行，仍由 `tools/gen-ch4.js` 脚本生成（`ch4-preview.html?s=8 / 9 / 11 / 12`，条带单帧 120–122）。导出覆盖 `cover-still`（22 片坐标表，◆ 6 片）`cover-pull` `cover-reduce`（预混色 #ACA396 / #B9B1A6 / #D1CBC1）`cover-strip`，另出单帧 `cover-strip-a / b / c`；另交 `cover-still-180.jpg`（180 px 宽缩略图）和 `cover-still-phone.jpg`（393 pt 实尺寸）。`cover-lampoff`、条带 d / e 没动。
- **验收（看过 180 px 缩略图）**：还看得出东西，不是白纸了。still / reduce / strip a 上能数出 10–14 个灰色绒球形，贴层 3 片一眼就是「纸上有东西」；实尺寸上 22 片都数得出（≥ 10）。分层（大而深 / 小而淡）在缩略图上分得开。保留意见：静帧里远层读起来更像散落的斑点，不太像在飘，「飘」主要还是靠动起来。没到要用 §1 后备方案（贴层 30 pt × 4）的程度。
