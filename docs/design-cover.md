# 《折信》书封动效规格：落樱（2026-10-18，第三稿）

对象：书封（`design-review-1.md` §1.5 骨架：满屏「折」、一道斜向山折横穿字面、朱线从顶端垂到「开始」纸签；`design-review-2.md` §4.4 定的 7-1「拉线」CTA：纸签 48 × 72 pt，拉 ≥ 64 pt 或轻点，进入封面 1.5 s 后轻晃一次）。主人要求：唯美、像落花。本文定主题、花瓣形、颜色、运动、落定、与纸签和开场转场的关系、减少动态、性能预算、验收。不写 App 代码。

**为什么换掉柳絮影（第二稿）。** 第二稿把影子加强到 2.2 : 1 之后缩略图上确实"有东西"了，但静帧（`cover-still-phone.jpg`，393 pt 实尺寸）上看得很清楚：模糊的灰色圆斑没有轮廓、没有方向、没有色相，眼睛给它的解释是**纸脏了 / 霉点**，不是"在飘"。动起来能救一半，但商店截图和缩略图是静的。主人定：**试落樱**。柳絮影的三条理由（两岸意象、只用已有色、影子是本作签名）留给第三章，封面不背这个包袱。

## 1. 主题：**落樱过纸**

一张纸举在灯前，樱花瓣从纸前飘过，几片落在纸上，一片落在「开始」纸签上。花瓣在**纸的前面**（不是柳絮那样的影子）：有清楚的轮廓、有缺口、有正反面、落定时有一道硬边小影——它是一片真的、薄的、剪出来的纸。

**怎么过 spec §0 第 7 条（只有一种强调色：朱红系）。** 不引入粉色。花瓣的颜色就是**朱线 `thread` #C0473A 用水调淡**——按不透明度叠在纸色上，层越远越淡。所以封面上从头到尾只有一种色相：朱线、纸签、花瓣是同一碗颜料，花瓣是蘸水以后的那一笔。两三片没蘸水的（60–65%）是"刚落下来的"，它们和纸签是同一个红。

**为什么它不会像第二稿那样读成斑点。** 三件事柳絮影没有、花瓣有：① **轮廓**——缺口是樱花瓣的签名，4 px 也认得出；② **色相**——粉对纸的差别是色度不是明度（`#E2B2AA` 对 `#F7F4EE` 亮度对比只有 1.71 : 1，但 ΔE 26.6，和第二稿贴层 ΔE 29 一个量级，而且是"颜色不同"不是"脏"）；③ **硬边**——不模糊，远近靠大小和深浅，不靠糊。

## 2. 花瓣

**形。** 单片樱花瓣（五瓣花的一瓣，不画整朵花、不画枝）：水滴形，尖端一个 **V 形缺口**。长 : 宽 = 1.25 : 1；缺口深 18% 长、张角约 70°；基部略尖。手绘 **3 个变体**（A 正、B 左肩略鼓、C 右缘略直），每个变体都不是对称的——剪纸的手感来自不对称和硬边，不来自纹理。**不画渐变、不画高光、不画叶脉**；前层和落定的花瓣画一道 **0.5 pt 的中折线**（从基部到缺口，比花瓣本色深 25% 不透明度），这是剪纸对折留下的痕，也是花瓣"有正反面"的依据。

**正反面。** 翻面靠把花瓣沿长轴压扁（短轴方向缩放 cos φ，§3）。背面比正面淡：不透明度 × 0.55，无中折线。|cos φ| 最小钳到 0.08，花瓣不会变成一根线（180 px 上一根线就是闪）。

**三层**（按离眼睛的距离，不是离纸的距离：越近眼睛越大、越快、视差越多；最靠纸的一层最小最慢，也只有它会落在纸上）：

| 层 | 片数（iPhone） | 长度 | 不透明度（`thread` #C0473A 叠 `paper.new` #F7F4EE） | 实色 | 对纸 | 落定 |
|---|---|---|---|---|---|---|
| **前** | 4 | 20–26 pt | **38%** | #E2B2AA | 1.71 : 1，ΔE 26.6 | 否（在空中就出屏） |
| **中** | 6 | 13–17 pt | **28%** | ≈ #E8C4BB | 1.47 : 1，ΔE ≈ 19 | **是**（§4） |
| **后** | 8 | 8–11 pt | **18%** | #EDD5CE | 1.28 : 1，ΔE 12.2 | 否 |
| 落定 | 3（初始）～4 | 12–15 pt | **34%** + 影 | #E4B9B1 | 1.61 : 1 | — |
| **点睛** | ≤ 2（算在前 / 中层里） | 同层 | **65%** | ≈ #D3847A | 2.6 : 1 | 否 |

- 总数 **18**：按屏幕面积 ÷ **18,600** pt² 取整，钳在 14–20；iPad 26–30（÷ 36,000）；Duo 两屏 22–24。层比固定 4 : 6 : 8。比柳絮少（22）：**少而清楚**，第二稿的教训是数量换不来可见。
- 点睛片：同一时刻最多 2 片，离朱线和纸签 ≥ 60 pt，永不落定；它们是"刚从枝上掉下来、还没褪色"的，颜色和纸签呼应。不能多，多了封面就红了。
- **影子只给落定的花瓣**：`shade` #6E604E **22%**，偏移 (1, 1.5) pt，**不模糊**（剪纸贴上去的影，硬边）。飘着的没有影。
- 不模糊、不预渲染纹理：三个变体是三条路径，正面 / 背面 / 中折线都是路径填充。
- 山折两侧（review-1 §1.5）：暗侧的花瓣不透明度 × 1.12（封顶 45%），过折线 120 ms 线性过渡。灯晕 `lamp` #FFD08A 径向，中心 (0.55 W, 0.35 H)、半径 0.7 W、中心 **10%** 到边缘 0（第二稿偏差 ① 的建议，采纳：6% 在 #F7F4EE 上看不见）。

**层序**：纸 → 灯晕 → 折面明暗 → 「折」《折信》副标 → 后层 → 中层 → 落定影 → 落定花瓣（页上） → 前层 → 朱线 → 纸签 → 纸签上的花瓣。花瓣在纸前，所以会**从「折」的笔画上飘过**：粉色压在墨上是这张封面最好看的一瞬，一片 ≤ 26 pt 的花瓣挡不住 300 pt 的字。静帧构图：至少 1 片前层正在压过「折」的笔画，1 片中层压在《折信》附近但不压字，落定的三片按 §4 的位置。

## 3. 运动

坐标：屏幕 pt，竖屏 iPhone 393 × 852 为基准；其他尺寸按面积等比缩数量，尺寸和速度不缩。每片一个种子，所有量都是 t 的闭式函数（无物理模拟、无状态积分），回收用环形数组。

| 参数 | 值 |
|---|---|
| 下落 | 前 30–38 pt/s，中 20–26，后 12–16。每片的基速恒定，但带**迟疑**：y = y₀ + v·(t − k·sin(ωt)/ω)，k = 0.25——花瓣侧过来时掉得快、摊平时慢。一片前层花瓣过完屏约 25 s；慢是对的，樱花不是雨 |
| 翻面 | φ(t) = ωt + 0.6·sin(1.7t + φ₁)；ω = 前 0.5–0.8 rev/s、中 0.4–0.6、后 0.3–0.5。短轴缩放 cos φ，cos φ < 0 画背面。0.6 那一项让翻面忽快忽慢，匀速翻就是风车 |
| 侧滑 | 花瓣朝哪边脸就往哪边滑：x += S·sin φ，S = 前 6 pt、中 4、后 2。翻面和横移耦合，这是"翩"的来源 |
| 漂移 | x += A·sin(2πt / T + φ₀)：A 前 14–18 pt、中 9–12、后 4–6；T 3.0–5.0 s；每片独立相位 |
| 平面转动 | ρ(t) = ρ₀ + R·sin(2πt / T + φ₀ + π/2)：R 前 ±30°、中 ±25°、后 ±15°。相位比漂移领先 1/4 周期——花瓣先倾向要去的那边，再滑过去（跷跷板）。ρ₀ 随机 |
| 风向 | 整体 **−12°**（向右下，顺着斜向山折 = 河的方向）：每秒再加 下落速度 × tan 12° 的右移 |
| 阵风 | 全局函数 g(t)：每 9–14 s 一次（种子定），持续 2.2 s，smoothstep 进出；期间所有片 +18 pt/s 右移、−4 pt/s 上抬（风把花瓣托一下）、ρ 偏 +12°（迎风倾）；前 / 中层全量，后层 60%。阵风也负责把落定太久的花瓣吹走（§4） |
| 生成 | 上边外 20 pt（x 任意）和左边外 20 pt（y 0–40% H）生成，约 1 片 / 1.2 s（按数量上限节流）；出下边或右边 20 pt 后回收。初次进入封面和从地图返回时都从随机进度**已在场**，不从空屏开始飘 |
| 陀螺仪视差 | 默认开（装饰，跟「体感」设置无关）：取设备姿态低通（截止 2 Hz）俯仰 / 横滚，前层平移 ±8 pt、中层 ±4、后层和落定 0（它们在纸上）。±25° 处饱和。减少动态、低电量下关 |
| 帧率 | 封面锁 **60 Hz**；进关卡回系统帧率 |

一句话给建造：`TimelineView(.animation)` + `Canvas`，每帧 ≤ 20 片 × (1 路径 + 可选中折线) + ≤ 4 道落定影 + 1 个径向渐变；位置、角度、翻面全部由 t 和种子算出来。

## 4. 落定：三片在纸上，一片在纸签上

**初始三片**（进封面就在，也是静帧和减少动态用的）：

| 片 | 位置（pt） | 转角 | 变体 | 说明 |
|---|---|---|---|---|
| S1 | (138, 392) | −20° | A | 卡在「折」扌旁竖钩的弯里，半压墨半在纸上 |
| S2 | (300, 640) | 35° | B | 副标「一本合上才能读懂的书」右下的空纸 |
| S3 | (178, 688) | 22° | C | **纸签左上肩**，探出签边 2 pt，影落在签上 |

**落点表**（最多 4 片同时落定）：L1 = S1 位、L2 = S2 位、L3 (330, 528)「Letterfold」右侧、L4 (58, 760) 左下空纸、L5 = 纸签肩（S3 位）。

**活的落定**：中层花瓣经过某个空落点的 y 时，若 |x − 落点 x| ≤ 14 pt，以 1/3 的概率落下（不是每片路过都落，落得太勤就假）：400 ms 内下落减速到 0（ease-out）、ρ 转到落点转角、φ 转到正面朝上、尺寸缩 10%（贴到纸上了）、影从 0 淡入到 22%。落定满 4 片时不再落。落定 ≥ 25 s 的花瓣在下一次阵风被吹起：先抬 6 pt、影淡出，然后按前层速度 × 1.2 翻滚出屏。L5（纸签）上的那片不被阵风吹走，只在拉纸签时走（§5）。

**纸签轻晃**（进封面 1.5 s，±4°、600 ms，review-2 §4.4 第 3 条）：签上的花瓣随签一起转，并沿签面下滑 1.5 pt 后停住（摩擦）——是花瓣在签上，不是画在签上。

## 5. 与纸签、与开场转场

拉线 CTA 规则不变（review-2 §4.4：拉 ≥ 64 pt 或轻点触发；拉的过程中封面像上页一样跟手向下折；松手过阈值完成折叠进地图 / 首次进 1-1；不过阈值弹回，不给触觉；完成时 Impact .medium）。铰链在封面自己的横折痕（标题与副标之间，y ≈ 568），页顶朝观者翻下来；折痕之上露出的内页灯亮期间 40% 不透明，灯灭起 350 ms 升到 100%（第二稿偏差 ① ② 已接受）。花瓣分三种身份，各听各的物理：

1. **纸上的花瓣（落定 S1 / S2 / L3 / L4）随页翻。** 它们是纸面的一层，跟着页转。页倾过 30° 开始沿页面下滑：滑距 = 48 · (1 − cos θ)，影子同步拉长到偏移 (1, 3)。θ ≥ 110° 时从页边**掉下来**：变成前层速度 × 1.5 的空中花瓣，R ±60°、ω × 2（被抖落的翻滚）。这是和第三章"影子随页滑落"同一个动作换了主角：第一次拉纸签的人已经在学"纸上的东西会跟着纸走"。
2. **空中的花瓣（前 / 中 / 后）不折，但被页扇起的风推。** 附加速度 = 0.35 × 页边线速度（朝右下，沿页的运动方向），封顶 60 pt/s，手指停下后按 500 ms 时间常数衰减；同时 ρ 迎着气流偏最多 15°。拉得快花瓣就被赶开，拉得慢只是轻轻让路。
3. **纸签上的花瓣（S3）骑在签上。** 签是把手，整个拖拽过程它都在签肩上，随签转。**完成那一下（Impact .medium）它滑落**：400 ms 以前层速度 × 1.5 落下，边落边淡——是屏幕上最后一点粉色。
4. **合过 60°（折角 120）灯灭**：透光 0.45 → 0（`backlight.on` 反向，350 ms），灯晕和所有空中、纸上的花瓣沿同一条曲线淡到 0；描图纸状态（review-3 §closed）接管，封面背面透出章节地图或 1-1 轮廓。纸签和签上那片**不灭**（签是挂在线上的 UI，在纸前），它们留到第 3 条。
5. **弹回**（不过阈值松手）：页 `close.snap` 弹回 180°；纸上花瓣滑回原位（θ 没到 110° 的）；已经掉下来的不回去，落点空着等下一片路过；空中花瓣得到一股 300 ms、−20 pt/s 的上扬（页甩回来带的风）；灯若已灭则 350 ms 亮回，花瓣同曲线淡回。不重新生成，不闪。
6. **轻点触发**（不拉）：同一段折叠 320 ms；纸上花瓣只滑不掉（太快了），和灯一起淡出；S3 仍在完成时滑落。
7. **Duo 铰链**：合手机 = 拉纸签（plan §12.1「谁最后动谁说话」）；纸上花瓣按物理角滑；熄屏前 10° 处算合上。
8. **可选（建造可删）**：S3 落到地图页第一章卡片左上角，整个地图会话里静静待着，不再动；它不进关卡（spec §0 第 4 条）。

进入地图后封面层销毁；返回封面时花瓣从随机进度已在场，三个初始落点有花瓣。

## 6. 减少动态效果

系统「减少动态效果」开启时（spec §5 `reduce.motion`）：

- **7 片静止**，坐标固定：落定 S1 / S2 / S3（§4，含影）；中层 N1 (62, 150) 50°、cos φ 0.8，**点睛色 65%**（朱红的回声留着）；中层 N2 (330, 470) −15°、cos φ 0.55；后层 F1 (240, 90)、F2 (40, 560)。不翻、不漂、不落、无阵风、无视差；灯晕静止 10%。
- 拉纸签：页仍跟手（输入反馈，不是装饰），纸上花瓣随页转但**不滑不掉**；空中花瓣不被风推；过 60° 时 200 ms 线性淡出，不弹回动画（直接到位）。S3 在完成时不滑落，和签一起直接消失。
- 纸签 1.5 s 轻晃取消，保留静态下拉箭头（review-2 §4.4 第 3 条）。
- **「降低透明度」**开启：花瓣用实色预混到纸色（按 `paper.new` #F7F4EE 算：前 #E2B2AA、中 #E8C4BB、后 #EDD5CE、落定 #E4B9B1、点睛 #D3847A、落定影 #D9D3CB），背面用 #F2E3DC；不画灯晕。出稿时按实际纸色核。
- 低电量模式 / `thermalState ≥ .serious`：按减少动态处理，但保留纸签轻晃。

VoiceOver：花瓣层 `accessibilityHidden`；封面只有「折 · 折信」标题、「开始」纸签、右上「设置」三个元素，顺序不变。


**出稿记录（2026-10-18，第三稿 · 落樱）**：Claude Design「Letterfold 视觉方向设计」第十行，柳絮帧全部替换，由新脚本 `tools/gen-cover.js`（`tools/gen-ch4.js` 调用）按种子生成。`ch4-preview.html?s=` 8 still · 13 petal · 9 pull · 10 drop · 12 strip（单帧 120–124 = a–e）· 11 reduce（`&phone=2` 降低透明度版）· 14 wiggle；`&phone=1` 只出 393 × 852 手机屏。导出覆盖 `cover-*.jpg`，另交 `cover-still-phone.jpg`（393 pt）和 `cover-still-180.jpg`。
- **迭代一次**：首版按本文数字（前 20–26 pt / 38%、中 28%、后 18%，18 片）在实尺寸上已是花瓣，但 180 px 上偏淡偏小、像粉点。第二版：前 28–34 pt / 55%（点睛 75%）、中 18–22 pt / 42%、后 11–14 pt / 28%、落定 16–19 pt / 48% + 影 28%；长宽比 1.35、缺口 22%（防心形）；22 片（5 / 8 / 9），2 片前层压过「折」。**建议把 §2 表改成这组数字。**
- **验收（看过 180 px 和实尺寸）**：180 px 上前层和落定的花瓣是带缺口的粉色水滴、方向和翻面各不相同，一眼是落花；中层读作有形状的粉，后层是粉点。「折」完整、仍是主角；「开始」字清楚，S3 只在签肩。无 Letterfold 字标、屏内无角度和轨迹线。
- **偏差**（Claude Design 自报）：① 花瓣用预混实色，不用透明朱红（透明的压在墨上发黑、在纸签上消失），所以降低透明度版和常规版几乎一样。② S2 在横折痕（y 568）之下，那半页不翻，所以只有 S1 滑落。③ 滑距按 48·(1 − cos(θ − 30°))，使 90° 时 = 24 pt（对上 §9）。④ 过半折的页显示背面，S1 透过纸可见（同第三章）。⑤ drop / strip d / e 的纸签上移 12 pt 避开 home indicator。

## 7. 性能与电量预算

**选型：SwiftUI `Canvas` + `TimelineView`。** 不用 CAEmitterLayer：它给不了逐片控制（落定、随页滑、被页扇风、签上那片），翻面只能靠缩放纹理不能换背面；不用 SpriteKit：为一个封面多拉一个框架，和 SwiftUI 的页折叠（已经是 SwiftUI 3D 变换）混层麻烦。Canvas 下 ≤ 20 片路径填充是毫不费力的量，而且和柳絮稿的实现路线一致，建造不用改架构。

| 项 | 预算 | 怎么测 |
|---|---|---|
| CPU | ≤ 1.2 ms / 帧（A15 及以上），封面 60 Hz | Instruments Time Profiler，封面停留 60 s |
| GPU | ≤ 20 片 × ≤ 2 次路径填充 + ≤ 4 道落定影 + 1 次径向渐变；无纹理、无实时模糊、无 `blur()`、无 `shadow()` 修饰符 | Metal System Trace：无 offscreen pass |
| 内存 | 3 个变体路径 + 落点表，≈ 0；无图片资源 | — |
| 电量 | 封面停留 10 min ≤ 1%（iPhone 15，50% 亮度） | `xcrun xctrace` Energy Log，对比关掉花瓣层的基线，差 ≤ 0.3% |

## 8. 验收

出稿后先看 **180 px 缩略图**，再看实尺寸，再看 1×：

1. **缩略图一眼读出"落樱"**：找 3 个没参与项目的人，看 180 px 缩略图 2 s，问"封面上是什么"，≥ 2 人不提示说出 樱花 / 花瓣 / 落花（说"粉色的点"不算过）。
2. **缩略图上数得出 ≥ 5 片**带缺口的花瓣（前层 4 片在 180 px 上是 9–12 px 长，缺口必须还在；中层 6–8 px 读成"有形状的粉"；后层可以是粉点）。
3. **实尺寸（393 pt）上 18 片都数得出**，三片落定的影子看得见，S3 在签肩上探出的 2 pt 看得见。
4. **量过的颜色**：前层最深点对纸 ≥ 1.6 : 1 且 ΔE ≥ 24；中层 ΔE ≥ 17；点睛 ≥ 2.4 : 1。任何一片都**不是灰的**（a* > 8）。
5. **不脏**：静帧上没有任何一片糊成圆斑；没有两片以上互相压住；点睛片 ≤ 2 且不挨着纸签；封面整体不读成"红"。
6. **「折」还是主角**：前层花瓣压过笔画时字形完整可认；一眼先看到「折」，再看到花。
7. 屏内无角度数字、无轨迹线（spec §0 第 5 条）；朱线、纸签、宋体同旧封面；zh 屏无 "Letterfold"（review-2 §4.4 第 4 条——第二稿还带着，这稿去掉）。
8. **好不好看**由主人定：不过 1、5、6 就回到 §2 改数字，不换主题。

## 9. 给设计稿

导出到 `~/.tomo/workspace/tmp/fold/design/cover-*.jpg`，每帧另交 180 px 缩略图和 393 pt 实尺寸图：

1. `cover-still` 摊平封面：18 片的一个"好看的瞬间"（坐标 / 转角 / cos φ / 变体表随稿给；◆ 标出减少动态的 7 片），三片落定含影，1 片前层正压过「折」，≤ 2 片点睛。
2. `cover-petal` 花瓣图鉴一张：三个变体的正面、背面、带中折线；一片落定含影；同一片在 cos φ = 1 / 0.55 / 0.08 / −0.6 的四个翻面相；三层的实际尺寸和颜色并排；S3 在签肩上的放大。
3. `cover-pull` 拉到 90°：页翻下一半，纸上花瓣沿页滑 24 pt、影拉长；空中花瓣被扇向右下；S3 骑在签上；灯还亮。
4. `cover-drop` 拉到 120°：灯刚灭、花瓣淡出中；一片纸上花瓣正从页边掉下来翻滚；S3 仍在签上、未淡。
5. `cover-strip` 五帧条带：摊平 → 抬起（30°，花瓣刚开始滑） → 半折（90°） → 灯灭（120°，掉落） → 合上（描图纸、地图透出、S3 正滑落）。另出单帧 a–e。
6. `cover-reduce` 减少动态 7 片静帧，含降低透明度预混色版本。
7. `cover-wiggle` 两帧：纸签轻晃到 +4° 和回正，S3 随签转、下滑 1.5 pt。

标注里不要出现角度数字和轨迹线；花瓣不要画成椭圆或心形，缺口要在；不要加枝、花蕊、整朵花、渐变、高光。缩略图上要一眼是樱花，实尺寸上要数得出 18。
