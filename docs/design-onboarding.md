# 《折信》物件笺与章页：上线前最后两件事（2026-10-26）

主人（10/25，原话）：①「每个物件第一次出现最好有个说明指引 或者有个指引动画」——他没认出胶，说它「像一滴油」；②「关卡内…」——现在重玩一关只能靠章节卡片上藏着的长按菜单，点章节应该看到它的关卡。

本文是两件事的设计稿，**先于任何 UI 代码**。依据：`design-spec.md`（纸、墨、朱红；§0 第 5 条「默认界面没有控件」；§4 顶栏只放两个图标；§5 动效；§7 无障碍与「折 2 / 标准 2」的关卡列表）、`objects.md`（物件与它所在的章）、`design-skins.md`（章皮：同一物件在每章长什么样）、`roadmap.md` §5（提示阶梯）、`design-v2c1.md` §2（胶的画法）、`design-ch6.md` §1（翻）。现状：0.1 (17)，42 关 = 卷一 ch1–4 + 卷二 ch5–6 + 3 暗信；1.0 免费，提交目标 11/5。

写给**没有上下文的视觉设计师**：§2 和 §3 各自能独立执行；§6 是出图单；§7 是给建造的触发 / 存档逻辑。角度一律**物理角**（180° 摊平、90° 立起、0° 合上），括注 `logic.js` 的折角 `fold = 180 − 物理角`。格子（列, 行）从 0 数，同 `levels.js`：左页 0–3、右页 4–7、第三页 8–11；合上时第 c 列落在第 7−c 列。手机竖屏上「左页 = 下页」「右页 = 上页」，中缝横着（spec §4）。

## 0. 两条原则

1. **笺，不是弹窗。** 说明是一张夹在书里的纸条（笺），从中缝抽出来，盖在上页上；读完塞回去，留一个书签角。没有半透明黑底、没有圆角卡片、没有「知道了」按钮。碰一下棋盘它就自己退回去，而且**那一下不白费**（拖页照拖、点格照走）。它的字是信的字（宋体），它的图是寄信人用墨线画的小书——「我画给你看」，不是「系统提示」。
2. **一个物件一张笺，一辈子只自动出现一次。** 记在存档里，按物件记，不按关记。重看永远有地方：这一关的「?」第一档，和书末的「物件」页。

## 2. 物件笺

### 2.1 长什么样

一张**本章纸色**的竖长纸条（笺），从中缝抽出，盖在**上页**（竖屏：屏幕上半的那页）上。上页是拖页的热区——玩家本能先去拖它，拖的那一下让笺退回去，手势继续。下页（点格走路的那页）始终露着。

```
 ┌──────────────────────────────┐   ← 上页（右页）区域
 │  ┌────────────────────────┐  │
 │  │ [胶]  胶          1 / 1 │  │   标题行：物件图标 22 pt + 笺名（宋体 Semibold 17）
 │  │                        │  │
 │  │  ┌──────┐              │  │   小书：两页上下叠（竖屏），每页 4 列 × 2 行，
 │  │  │ ·  · │  合上时，    │  │   格 30 pt、缝 3、页边 8 → 每页 69 × 141，
 │  │  │ ·  x │  它把对面    │  │   两页加中缝 69 × 290；笺左栏放小书，右栏放字
 │  │  │ S  · │  那格的石头  │  │
 │  │  │ G  · │  粘过来——   │  │   正文：宋体 Regular 15 / 22，ink.900
 │  │  ├══════┤  石头换了页， │  │   （design-spec §2 letter.body 的小一号）
 │  │  │ ·  · │  路也换了。  │  │
 │  │  │ g  · │              │  │
 │  │  │ ·  · │              │  │
 │  │  │ ·  · │              │  │
 │  │  └──────┘              │  │
 │  │                   收起 ›│  │   右下：「收起」宋体 13 ink.600，热区 44 × 44
 │  └────────────────────────┘  │
 ╞══════════════════════════════╡   ← 中缝（笺从这里抽出来）
 │         下页（左页），照常可见   │
```

- **尺寸**（iPhone 393 pt 宽，书宽 352）：笺宽 = 书宽 − 24 = **328**，高随内容，正常字号约 **300**，最高到上页高度 − 16；再高就正文内部滚动（AX 字号）。圆角 **2**（它是纸条，不是卡片）；1 pt 边 `tile.edge` #857868 @ 60%；投影 (0, 4) 12% 模糊 10——这是它和棋盘分层的唯一手段，**不加暗底**。
- **纸**：本章的 `paper` 色（spec §3），卷二是信笺 `paper.letter` 带 16% 印格线（design-v2c1 §2），笺上格线和小书的格对齐与否不要求。笺的左上角有一道 6 pt 的斜折角（像夹过书），不画撕边。
- **字**：标题 = 物件图标（和棋盘上同一张皮的 tile 图，64% 格大小 → 22 pt；纸片 = 跨缝成对的 V 折。三张没有 tile 的规则笺：**压** = 石墩 + 下方一道短横线 + 向下短箭头，**乘影** = 交叉线方格上一个墨点纸人，**第三页** = 两张错开叠着的页——评审 `design-review-onboarding.md` F2）+ 笺名；正文 1–2 行，宋体，信的口吻；右上角 `1 / 2` 只在一关同时抽出两张笺时出现（§7.4）。英文用 New York（spec §2 `en.letter`），日文 Hiragino Mincho，韩文 Apple SD Gothic Neo。
- **小书**（§2.3）：寄信人用墨线画的一本小书——不是棋盘的缩略图。格子是 1 pt `tile.edge` 的方框，缺口是纸纹点，纸人是 ink.figure 的圆点，朱线照画，物件画本章皮的 **线稿**（石：实心暖灰块；门：框 + 闩；钥：环 + 柄；墨：黑块 + 溅点；纸片：V 折；影：整格方 + 交叉线；胶：琥珀椭圆 + 滴形线；第三页：竖格线暖纸）。上页合下来时是描图纸（62% 透明 + 实线 / 虚线边，design-review-3 §closed）。**方向跟真书**：竖屏横缝、上页在上；横屏 / iPad 竖缝、右页在右（小书横过来，字在小书下面）。
- **书签角**：笺退回中缝后，在中缝**右端**（靠「?」的那头）留一个 **30 × 44** 的墨色小角，露出物件图标（白描，14 pt），热区 44 × 44，在页边外、不压任何格、不在拖页热区。它只在**这一关**存在（离开关卡即消失）。
- **两种模式**：高对比（spec §7）——笺白底 + 2 pt 黑边，小书的格 2 pt 黑框，物件用各自的高对比花纹，影子交叉线 + 虚线框，朱线 4 pt `hc.line` + 白衬；降低透明度——描图纸改实底 + 1.5 pt 描边（同 spec §3）。

### 2.2 在流程里的位置

```
地图 → [章首页 2.6 s（本章第一关）] → 关卡：棋盘就位，关名淡入 1.5 s
                                        └─ t = 1.2 s：笺从中缝抽出（320 ms）
                                             ├─ 碰棋盘 / 点「收起」/ 点笺外任何处 → 退回（220 ms），留书签角
                                             ├─ VoiceOver：等关卡 intro 播完再抽出；Z 手势 = 收起
                                             └─ 书签角 ∙ 「?」第 0 档 → 再抽出（同一张）
```

- **何时**：棋盘可交互后 **1.2 s**（让人先看一眼棋盘，再看笺）。章首页（ChapterOpener）在前的关，从章首页消失起算。关名淡化（1.5 s）照常进行，和笺无关。
- **只在首次**：按物件记（§7）。已见过的物件，什么都不出现，也不出书签角。
- **计时器让路**：笺抽出期间，1-1 幽灵手、2-1 / 3-1 的 8 s 教学、45 s 的「?」出现，全部**从笺退回那一刻**起算（读笺的时间不算卡住）。
- **退回方式**（任一）：
  1. 碰棋盘：**第一个触摸** 既让笺退回，也照常落到棋盘（拖页 / 点格）。笺不吞手势。
  2. 点笺本身任意处或「收起」。
  3. 点笺外（顶栏、页脚）。
  4. 书合上也让它退回（有人直接用铰链）。
- **重看**：① 书签角；② 「?」——在**引入该物件的关**（§1 表的「首次出现」列，或任何本关首次抽出过笺的关）第 0 档先再抽出这张笺，之后才是 `hint1` → `hint` → 幽灵手（roadmap §5 的阶梯向后挪一档，只在这些关）；③ 「物件」页（§2.6）。
- **不出现的时候**：合上的书上不抽（等打开）；超大格子模式下笺一样出，但盖在棋盘上时上页可能被完全盖住——允许（它 1 秒后就会被第一下触摸退回）。

### 2.3 小书的动效（通用）

| 名称 | 时长 | 说明 |
|---|---|---|
| `slip.rise` | 320 ms | spring response 0.36 / damping 0.78；从中缝线处 0 高度「抽出」：y 位移 + 顶端先露（clip 从中缝向上页方向展开）。纸擦声（现有 rustle，低增益 120 ms）。触觉 Selection |
| `slip.tuck` | 220 ms | ease-in；反向塞回中缝；最后 80 ms 书签角淡入。触觉 Selection |
| `slip.loop` | 3.6–4.4 s / 圈 | 每张笺一段故事（§2.4 分镜），结尾停 700 ms，再 200 ms 交叉淡化回第 0 帧（不倒带）。无声——「啪」留给真书 |
| 小书·合上 | 420 ms | ease-in-out；上页绕中缝合到下页，到 25° 起描图纸化（同 `applyAngle` 的 veil），落下时无回弹 |
| 小书·打开 | 300 ms | ease-out（= `unfold.auto`） |
| 小书·斜起 | 500 ms | ease-in-out；灯晕 `lamp` 从页角亮起 200 ms；影子跟角度滑（同游戏公式，§2.4 给角度） |
| 小书·走一步 | 180 ms / 格 | ease-in-out + 「hop」；朱线跟在身后 |
| 小书·撞 | 120 ms | 纸人向障碍挪 2 pt 再弹回（同 `nope`），障碍物闪一下 1 pt 边变 ink.900 |
| 小书·印 / 开门 / 粘 | 220 ms | 和游戏同一拍：胶 `glue.pull`（石头抬 2 pt 越缝落下，原处留 6% 石头印 1 s）；门 → 虚线框；墨在对面渗出（`ink.bleed` 的 300 ms 版） |
| 小书·压 | 260 ms | 石头落在纸人上：纸人压扁（scaleY 0.3）→ 消失 → 400 ms 后在起点淡入 |
| 小书·翻 | 350 ms | 合上的小书绕中缝的垂线转 180°（卡片翻面），转到一半两页都是纸背，落下时闪 |
| `reduce.motion` | — | 不循环。小书只画**一帧合成图**：§2.4 每张笺标了「静帧」；不出来回弹，`slip.rise` / `tuck` 改 200 ms 线性淡入淡出；书签角直接出现 |

循环里纸人每一步都是 `logic.js` 允许的走法，分镜的地图和步骤在 `tools/slips.js`（`node tools/slips.js` 全绿），建造时直接用这份数据驱动小书——**小书是一关真的 2 行小关，被脚本玩**，不是手画的动画。

### 2.5 读屏、减少动态、字号、两种皮

- **VoiceOver**：笺抽出时 `UIAccessibility.post(.layoutChanged, argument: 笺)`——焦点落到笺上；笺是一个元素：label = `物件笺，{笺名}`，value = 正文 + 「图：…」那句，hint = 「双击收起」，traits = `.isStaticText` + `.allowsDirectInteraction` 关。小书 `accessibilityHidden`（它的内容就是正文）。Z 手势（`accessibilityPerformEscape`）= 收起。书签角是按钮：label `{笺名}，物件笺`，hint「双击再读一遍」；`accessibilitySortPriority` 排在「走」书签之后、棋盘之前。笺在 VoiceOver 下**等关卡 intro 播完**（`announcementDidFinish`）再抽出，避免两句话打架。
- **按钮控制模式 / 切换控制**：笺也出现；扫描顺序：笺 → 折叠动作 → 走 → 棋盘。页脚按钮的任一下也让笺退回（动作照做）。
- **减少动态**：不循环，用各笺标注的「静帧」；抽出 / 塞回 200 ms 线性淡化；灯晕不呼吸。静帧要能单独讲完规则——所以每张静帧都选「结果」那一刻，前因靠正文。
- **Dynamic Type**：标题 / 正文跟随，小书不缩放（和棋盘一样）；AX3 以上笺高到上限后正文内部滚动，正文区底部 12 pt 线性渐隐到笺纸色，「收起」固定在渐隐之下。
- **笺上没有灯晕**：灯只在小书里——三章的三张（影子、压、乘影）小书上页斜起时从上页外端亮起；其余六张没有灯（评审 F4）。
- **高对比 / 降低透明度**：§2.1 末；另外书签角在高对比下是白底黑边 2 pt。
- **两种皮**：笺的纸、小书里的物件和格子都按**当前关所在章**的 `PaperState` + `Skin` 画（卷一宣纸四色、卷二信笺）；「物件」页里按**首次出现那一章**画（§1 表末列）。高对比下皮不变花纹（design-skins §3）。
- **语言**：四语键 `slip.<id>.title` / `.body`（+ `.body.h` 横屏变体，只有 shadow / press / turn 三张需要）、`slip.tuck`「收起」/ "Tuck in" / 「しまう」/ 「넣기」、`slip.aria`「物件笺」/ "object slip"、`slip.pic.<id>` 读屏图注。ja / ko 全部标 TODO 送审。英文正文比中文长 2.5×：正文区 190 pt 宽、15 pt 下中文 2 行 / 英文 4–5 行，笺高随之，上限见 §2.1。

### 2.6 「物件」页

书末的一页：所有抽出过的笺按书的顺序排着，像夹在封底的纸条。

- **入口**：① 地图每卷页面最底、「下一页」卡之下一行：`物件笺 · 已集 6 / 9 ›`（宋体 15，ink.700，虚线下划，热区 44 高）；② 设置页末新加一组「书」：一行「物件笺 ›」。两处进同一页。
- **页面**：标题「物件」（宋体 Bold 34），副标 `已集 n / 9`（numeric 15 ink.700）。列表每行一张**缩小的笺**（宽 = 屏宽 − 32，高 ≈ 96）：左边物件图标 28，中间笺名 + 正文首句（截断 1 行），右边小书静帧 56 × 56；按首现章的纸色。点一行 → 整张笺以 §2.1 的样子抽出（这里是从页面底边抽出，`slip.rise` 同），循环播放，点笺外塞回。
- **没见过的**：灰纸条，没有图标和名字，只有 `还没遇到`（ink.600）；不可点（traits 无 button，value「还没遇到」）。不剧透它是什么。
- **9 / 9 时**：副标旁一枚 `seal.muted` 小印「集」（14 pt）。不记成就、不弹任何东西。
- **VoiceOver**：标题 isHeader；每行按钮 label `{笺名}`，value 正文；未见过的 label「物件笺，还没遇到」。
- **高对比 / 减少动态**：同 §2.5。

### 2.7 声音与触觉

抽出：纸擦 120 ms（现有 rustle 低增益）+ Selection；塞回：Selection；循环：无声；书签角点击：Selection。笺和「物件」页都不播本章音色单音——那是接通的声音。

## 3. 章页（章节的关卡列表）

### 3.1 现在与改法

现在：点章节卡片 = 直接跳进下一封未送的关；重玩只能长按卡片（`contextMenu`，没人发现）。改为：**点章节卡片 → 翻到这一章的「章页」**——一页目录，列出本章每一封信；「继续」胶囊仍在地图底部，是直达的快路。长按菜单删掉（一件事一个入口；它的无障碍 `accessibilityActions` 由章页的行替代）。

### 3.2 长什么样


- **页面**：和地图同一张桌面 `TableBackground`；章页本体是**本章纸色**的一张纸（圆角 6、投影同章节卡），从地图上该卡片的位置**展开**（`matchedGeometryEffect`，280 ms ease-in-out；减少动态：200 ms 淡化）。返回时折回卡片。
- **行**：最小高 56；行首 24 pt 的状态位（针脚 / 墨点 / 虚线），编号 `1-3` numeric 15 ink.700（tabular），关名宋体 Semibold 17，右侧状态区。分隔线 1 pt 白 90%（同卡片的折线）。
- **折数**（进 1.0，评审 §4 ②）：「折 n · 标准 n」（spec §7 的 par 展示，numeric 13 ink.600）只在存档里有这一关的最少折数时出现；没有就只画 ✓（老玩家已送达的关重玩一次就有了，不回填）。标准 = `levels.json` `expect.changes`；折 = 本次进关起的姿态变化数（含翻，`check.js` par 口径；压回起点不清零，重来清零），过关取历史最小。等于标准时结旁多一枚 3 pt 的点（roadmap §5「一折」印的最小版；不做印）。
- **卷二**：章名「一 胶」「二 翻」按卷内序号（`volumeNumeral`），返回写「‹ 翻页」。
- **高对比**：纸白底 2 pt 黑边；✓ 和结换成 `hc.line` 的 ✓ 字形 + 白衬；未到的行不降透明度，改为 ink.900 + 行末「未到」两字 + 锁图标。

### 3.3 行为

| 动作 | 结果 |
|---|---|
| 点已送达的行 | 进关（重玩）。过关后存档不变（已在 done 里）；「下一关」结照常指向下一封（或本章末的信）。 |
| 点「下一封」的行 | 进关。 |
| 点未到的行 | 轻触觉 `Impact .light 0.4` + toast `先送出上一封。`（`lv.lockedToast`，en "Deliver the letter before it first."）。行不是按钮，但可点（为了给原因）。 |
| 点暗信行 | 同现在：章没送完 → `dark.lockedToast`。 |
| 「书」图标（关内左上） | 回到**来处**：从章页进的回章页；从「继续」或封面进的回地图。`Router` 记一个 `from`。 |
| 返回「‹ 卷一《两岸》」/「‹ 卷二《翻页》」 | 折回地图，滚动位置保持。 |
| 锁着的章（卡片系着线） | 点卡片仍只 toast（`ch.lockedToast`），**不**进章页。未写的虚线章同现在。 |

**解锁规则一字不改**：`SavedProgress.chapterOpen`（上一章全部送达才开下一章）和 `levelOpen`（已送达可重玩；第一封未送达的是下一封；其后全锁）。章页只是把这两条**画出来**。

### 3.4 读屏

- 进章页 `screenChanged`，焦点到标题；标题 label `第 1 章 对页，3 / 5`（`ch.label` + `ch.count`），isHeader。
- 行：label `1-3 背`（现有 `lvAria`），value `已送达` / `下一封` / `未到，先送出上一封`；已送达和下一封有 `.isButton`；未到的没有 button trait 但保留 `accessibilityAction`「为什么锁着」= toast 那句。折数读「折 2，标准 2」。
- 暗信标题 isHeader；行同上，锁着时 value `章送完后开`（现有 `dark.note`）。
- 转子：标题。

| **老玩家**（存档里有 `fold.doneIDs`，没有 `fold.slipsSeen`）——主人和 TestFlight 的人 | 第一次启动时**播种**：§1 表里「首次出现」的关已送达的物件，直接记为已见（不会在 6-3 这种关突然冒出四张笺）。它们全在「物件」页里，第一次回到地图时**一次性**在地图顶栏下出一行 `书里夹了几张物件笺 ›`（toast 样式但可点，10 s 或点掉），点进「物件」页。以后的新章（墨晕、灯位…）对他们和新玩家一样自动抽出。 |
| **一关引入两个新物件** | 现在没有这样的关（1-4 的门和钥匙是同一张笺；5-1 的石头早在 1-2 见过）。规则备着：同一关最多抽出**一张**笺，但它可以有两页——右上角 `1 / 2`，「收起」变成「下一张 ›」，第二张读完才是「收起」；顺序按离起点近的先。两个物件都记已见。 |
| **老玩家在暗信或重玩里遇到没播种的物件** | 不会发生：播种按「首现关已送达」，而暗信在章送完后才开。但以防万一（例如 `renamed` 迁移），规则是**懒触发**：任何关进入时，只要本关满足某张未见笺的触发条件，就抽出它。 |
| **重置进度** | `SavedProgress.reset` 同时清 `fold.slipsSeen` 和 `fold.slipsIntroduced`。 |
| **笺抽出时玩家已经在拖页** | 不抽；等手指松开 300 ms 后再抽（仍记已见）。 |
| **笺抽出时书是合着的**（铰链设备一开始就合着） | 等打开再抽。 |
| **第一次合上就赢了**（5-1 不会，但以后可能） | 赢了就不抽；下一次遇到再抽（没记已见）。记已见的时刻 = 笺真的抽出了。 |
| **章页里重玩已送达的关，中途退出** | 不改存档；回章页。 |
| **0.1 (8) 的位置存档** | 现有迁移照常；播种在迁移之后跑。 |
| **「继续」指向的关正是引入新物件的关** | 正常：进关 1.2 s 后抽出。 |
| **iPad 横屏 / Duo 两屏** | 笺盖右页（折页）；Duo 上两块屏各一页，笺在右屏。章页宽 ≤ 560 居中。 |

## 7. 触发与存档（给建造）

### 7.1 存档

- `fold.slipsSeen: [String]`（UserDefaults，`SavedProgress` 新增 `slipsKey`）：已自动抽出过的笺 id（§1 表的 id）。按物件，不按关。
- `fold.slipsIntroduced: Bool`：老玩家播种后那条「书里夹了几张物件笺」提示是否已出过。
- `reset()` 清两者。`load()` 末尾跑一次播种（§7.3）。
- 折数（§3.2，进 1.0）：`fold.bestFolds: [String: Int]`（关 id → 最少姿态变化数），`SavedProgress` 新增 key，`reset()` 一起清，`migrate` 不碰；`levelOpen` / `chapterOpen` 不读它。

### 7.2 触发条件（纯函数，`FoldCore` 新增 `Slips.swift`，和 `tools/slips.js` 同一份表）

```
slipsDue(level, seen) -> [SlipID]      // 按 §1 表顺序，过滤掉 seen；调用方只取前两张
  stone   : level.map 含 'x'
  door    : 含 'D'
  ink     : 含 'i'
  tab     : 含 'p'
  shadow  : level.needs 含 needsShade
  press   : crushable(level)  — 存在右页石头 (c,r)，c ≥ 4，使 mirror(c) 处是 floor（'.SGkiopg'）
  ride    : level.needs 含 needsRide
  glue    : 含 'g'
  turn    : level.pages == 3
```

`needs` 已在 `levels.json` 里（export.js 导出）；`crushable` 在 `check.js` 里加一列并断言 3-2 是第一个为真的主线关。**哪一关引入哪张笺不写死**：改关卡后 `tools/slips.js` 重算「首现关」并打印，和 §1 表对照。

### 7.3 老玩家播种（只跑一次）

```
if slipsSeen == nil && !doneIDs.isEmpty:
    seen = { slip | firstLevel(slip) ∈ doneIDs }      // firstLevel 按 §1 表（Chapter.all 顺序扫 levels）
    save(seen); slipsIntroduced = false                // 下次进地图出一次提示
if slipsSeen == nil && doneIDs.isEmpty: save([])       // 新玩家
```

### 7.4 关内流程

```
go(i):
  due = slipsDue(level, seen).prefix(2)
  if due.isEmpty: 照旧
  else: 棋盘就位后 1.2 s（章首页之后），且 !dragging && posture != .closed && !won
        → slip.rise；seen ∪= due；暂停 ghost / teach / stuck 计时，slip.tuck 时恢复
hint(): 若本关 due 非空（本次进入抽出过）且 hintRung == 0 → slip.rise（不加 rung）；否则现有阶梯
```

两张时（`due.count == 2`）笺内翻页，§4 第二行。
