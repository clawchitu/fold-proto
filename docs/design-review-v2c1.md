## 0. 结论：**go-with-changes**

帧整体过关：胶（琥珀湿斑 + 褐滴线）和墨 / 石 / 影一眼分得开，斜起帧上页朝观者、合上帧是描图纸、标注全在屏外。**两帧重画**（`v2c1-bridge`、`v2c1-a11y`），**一处文字改**（`v2c1-paper` 的卷一纸 token），其余偏差照收。七关的「要想到的」每一关都成立、都绕不过去；**一处收紧**：5-4 的一句话「别急着合上」把本关唯一的洞察直接说出来了，改掉（§2）。

## 2. 七关复核（主人的标准：卷一「还是有点简单」）

逐关手推，确认"要想到的"是唯一通路：

| 关 | 要想到的 | 绕得过去吗 | 裁决 |
|---|---|---|---|
| 5-1 `glue` | 合上 → 石头被粘走 | 不合上路就不通；叠走不通（下页第 6 列全空）。合几次都安全 | 过。teach 就该这样 |
| 5-2 `lend` | 影子是借来的：先送石头过去 | 缺口 (1,2) 只能靠影子；上页没石头就没影子；叠走 (1,2) 两页皆空。窗口 30°–50° 含 30° / 45° 两档 | 过 |
| 5-3 `bridgeGlue` | 桥立着 + 借来的影子同时在 | 不粘：桥头 (3,1) 永远空；叠走：第 1 行的叠全是空或石头。只有 75° 让影子落 (3,1) 且桥立着 | 过 |
| 5-4 `shadowFirst` | **别先合上** | 先合：石头到下页，影子永不再有，(1,2) 永空 → 死局，看得见（石头飞过中缝）。先斜 40° 踩影到 (1,3) 再合 → 叠走到 (6,4) | 过，但**一句话泄题**，见下 |
| 5-5 `oneClose` | 只合一次，在哪合 | 四个位置：(1,0)/(1,1) 石头落身前堵死；(1,2) 被压；只有 (1,3) 对。无影子捷径（上页石头的影子落在胶格上，没用）。可以靠撤销两次试出来，但每一次错都**看见后果**——这就是本关要教的 | 过；按 §7 试玩 < 1.5 min 则加假影子 |
| 5-6 `rideFirst` | 先乘影再合，而且那一合要同时开门 | 先合：石头到下页，纸人困在 (3,0)。影子在 60° 落 (2,0)、45° / 30° 落 (1,0)、15° 落胶格，从 (3,0) 只有 60° 踩得上，再乘到 45° 才到 (1,0)。门锁着不挡、开着挡：第一次把门放在下页 | 过 |
| 5-7 `stuckPage` | 5-5 的在哪合 + 5-2 的造影子 + 60° + 门 + 合上相遇 | 不先合：(2,3) 永空、门锁着；在 (1,1)/(1,2) 合 = 堵 / 压；合后只有 60° 让 (7,3) 的影子落 (2,3)（45° 落 (1,3)，75° 落门格）；第二次合在 (3,3) 叠上 (4,2) | 过 |

**收紧（必做）**：5-4 的一句话不能是「别急着合上」——它把 `before` + `misdirect` 两分全给了。改为 **「影子只借一次。」**（zh）/ *The shadow is lent once.*（en）；「别急着合上」降为「?」第一次按出的 `line`。其余三句不动。

**不收紧的理由**：5-5 的试错成本是两次可见的后果，不是暗算；把它做成不可试错反而违反"进死局的那一下必须看得见"。5-2 作为第二关是 mid，照 §7 试玩阈值处理。

## 3. 建造清单（给 App；灰盒 `logic.js` / `levels.js` / `i18n.js` 已有的不重复）

**机制**
- `g` 是地面；第一次合到 25° 那一拍，所有胶同时执行：`g` 的镜像格是 `x` → 胶格变 `x`，原格变 `.`；与钥匙开门、墨印同拍。之后再合不变。只粘石头。
- 压：上页胶对面是下页石头 → 站在上页胶上合 = 被压（新增）；下页胶对面是上页石头 → 原规则。
- 影子、压痕不改代码：石头到了上页就投影、就压。
- 死局：合上**和打开**两拍都跑一次 `checkReach()`；可达格变少 → `lost`（读屏「有的路断了」+ 下行二音）。撤销 / 重来照旧，撤销一步要把胶和石头一起还原。
- 影锁：5-3 停 75°，5-7 停 60°（条件同 ch4：影子接上可走的路）。

**视觉**
- 纸 `paper.letter` #F6F3EC；印格线 `rule.letter` #545C76 @ 16%，空格也画；高对比关掉。卷一纸 token 以 spec §3 为准。
- 胶：`glue` #E8B848 @ 62% 椭圆 58% × 48%，中心略偏下，边缘晕到 22%，下沿 inset 阴影，1 点高光；滴形线稿 `glue.line` #8A5A14 不填色。用掉后不画。
- `glue.pull`：抬 2 pt（0 ms）→ 越中缝（110 ms，原处留 `stone.ghost` #000 @ 6%，1 s 淡出）→ 落胶（220 ms ease-out）→ 胶格 `flash`（220–520 ms）。多块按下页列号从小到大错开 60 ms。减少动态：直接换位 + 闪，无抬起、无残影、不错开。
- 朱线在石头层之下。章印五「胶」`seal.muted` 24 pt 锚终点格右上角，不盖邻格物件。
- 章首：卷名「翻页」小字 → 「五」 → 「胶」，擦入 600 ms（减少动态 200 ms 交叉淡化），`ch.5.line` 随后淡入；小书摊平、右下一滴胶。
- 信：三折 2 / 2 / 署名 + 「岸」印，右上角朱线卷到页角；标题组件同卷一（无「已送达」）；`letter.5.end` 在「回到章节」之上。

**触觉 / 声音**
- 踩上胶格：纸声 + 低频短 tick（和纸片 flick 区分）；触觉 `.soft`。
- 粘走那一拍：石头音从原页那一耳滑到对页那一耳（220 ms 声像平移），触觉 `.rigid` ×1（两块石头时 ×2，间隔 60 ms）；和钥匙开门音叠放，开门音靠后 80 ms。
- 被压：沿用；死局：`lost` 下行二音 + `.warning` 触觉；减少动态不改声音。

**无障碍 / 音频模式**
- VoiceOver：进章 `paper.ch5`；格 `kind.g`「胶」；胶对面有石头追加 `glueTakes`；石头对面是胶追加 `stoneGlued`（n = 对页列号）；合上拍 `book.closed` + `glued`（+ `doorOpened`）；打开拍若路断读 `lost`。转子「物件」含胶，用掉后移除。
- 高对比：胶 = 整格 9 pt 点阵（2.5 pt 点，内缩 3 pt）+ 黑线滴形；石头 45° 斜线 + 3 pt 轮廓；终点双框；格线关。
- 色盲：胶靠滴形线稿而非琥珀色承载信息，不另出变体。
- 运动：15° 一档全部可解（check.js 断言）；75° / 60° 有影锁；乘影不限速。

**存档**
- 关 id 不变：`glue` `lend` `bridgeGlue` `shadowFirst` `oneClose` `rideFirst` `stuckPage`（levels 26–32，显示号 5-1…5-7）。完成记录同卷一按 id 存；章键 `ch5`，`letter.5.read` 标信已读；卷二解锁不单独存——由 `letter.4.read`（卷一末信）推出。

**地图**
- 两岸地图第二页「翻页」：卷一末信「回到章节」落到这一页；左上「‹ 卷一《两岸》25 / 25」返回第一页；卡片「一 胶 0/7 · 进行中」，朱线从中缝顶端走到卡边打结；「二 翻页」虚线卡不可点，VoiceOver「尚未写」。从第一页向下滑也能到第二页（卷一全过之后才出现）。
- 「继续 5-1」主按钮同卷一。
