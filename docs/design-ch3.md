## 1. 机制：把纸举到灯前

**一句话：上页斜起时，灯在它背后；上页的石头在下页投下影子，影子能走，而且会跟着页角滑。**

- **斜起窗口**：物理 89°–26°（折角 91–154）。这是第三章新加的姿态，在立起（90°）和合上（≤25°）之间，**连续、不吸附**；50° 处只有软阻尼（spec §5 hinge.drag）。
- **影子位置**：上页离折痕 d 格的石头，影子落在下页离折痕 `round(d·cos 物理角)` 格处（`logic.js shadowColumn`）。页越合，影子越往外滑，合到底时正好落在石头的镜像位——石头本身压下来。**远的石头影子走得快**：同样合 10°，d = 4 的影子比 d = 2 的多走一倍。
- **能走**：影子盖住缺口时，缺口变成路（`openNeighbours` 的 `sh`）。影子不越过石头、门。
- **乘影**：站在只有影子的格子上改变页角，影子带着纸人走（`ride`）；影子离开下页（d·cos 物理角 < 0.5，d = 4 时页抬过 82°、d = 3 时过 80°）或书合上（≤ 25°），纸人掉下去，回到起点。合上时的那一下读作「石头压下来了」。
- **没有新 tile。** 第三章只加一个姿态，不加一种格子：石头在第一、二章是「合上会挡路」，第三章同一块石头多了第二重身份——斜起时它的影子是桥。这就是 plan §2「压」那条的核心。

**被否决的方向**：① 立起的纸片投影（纸片在 90° 立着，影子落在折痕根部一格，和纸片桥重复，且 90° 吸附会吃掉连续角度）；② 背光透出隐藏的路（需要新 tile「暗路」，引入一条要解释的规则；而且背光页是上页，路透出来也走不到）。两者都留在候选。

**压的规则（评审定，`design-review-ch3.md` §2）**：**合上时（折角 ≥ 155）纸人站在下页、而上页石头的镜像位正是这一格 → 被压，回到起点**（`logic.js crushed`，与乘影合到底是同一个结局：影子滑到底就是镜像位）。只有上页的石头会落下来；下页的石头不动，站在上页石头对面的格子只是走不了，不会被压（和读屏现有的 `crushedHere` / `fallsHere` 分工一致）。`check.js` 17 关重跑全过，par 不变；Swift `FoldCore` 同步加这一条。所以 3-2「压」有两层陷阱：合上时石头落在缺口后面的路上（堵路），而如果你已经站在那格上再合——被压。

**难度曲线**：1 → 1 → 1 → 2 → 2 → 3 次姿态变化；窗口宽度 23° → 26° → **5°** → 16° → 8° → 5°。3-3 的窄窗口是故意的「咔哒」时刻，但只出现在 3-3 和 3-6，而且两处都落在 15° 档（30°）上，按钮玩家不需要精度。

**每关的「啊哈」与陷阱**：
- 3-1：第一反应是合上——合上时石头落在（1,3），缺口还是缺口。合的途中影子从折痕滑过整页，玩家第一次合书时就会撞见它扫过缺口（被动提示，和 2-1 纸片扫过 120° 翻起是同一种设计）。
- 3-2：纸板正好在缺口的镜像位，一合就盖上——可石头同时落在缺口后面那格，路被压断。答案是「不合到底」。第二层：走过影子站到（2,2）之后再合上 = 站在镜像位被压，回到起点（这是全章唯一一处能在纸上被压的格子，`check.js` 已核）。
- 3-3：先看到一道影子到位，另一道还差一格；再合一点，两道才排齐。教「影子速度 = 离折痕的距离」。
- 3-4：缺口两格宽、影子一格。站上去继续合；合过头（≤ 25°）就摔下去。
- 3-5：影子只在快合上时才伸到脚边，可终点在折痕那一侧——站上去之后要**打开**。打开到底也安全：纸人会先落到（4,2）的纸上。
- 3-6：两条路线都成立：从（4,3）站上第二块石头 52°–67° 的影子，或从（3,2）站上第一块的影子；都要在 29°–33° 下到（2,4），然后合上。在影子上合到底 = 掉下去，这是全章唯一一次「先下来再合」的考题，也是章末的送信一合（plan §12.2）。

**铰链（plan §12）**：每关最优 ≤ 3 次姿态变化，完全合上 ≤ 2 次（本章最多 1 次）；第三章一次连续斜起算 1 次。**影锁**（评审 §3，spec §5 / §6；判定在 `design-review-ch4.md` §2 改写为「落在缺口上的影子每一道都接上纸人走得到的路、至少一道，纸上的不计」——原写法在 3-3 每个角度都成立、在 3-6 永远不成立）：影子接上路时为「锁定」——Selection 触觉 + 缺口描边亮 400 ms + 缺口的空心音变实（两道同时锁定加双音和弦），**所有玩家都有**；松手落在锁定窗口内时页停在窗口中点，不往外漂。3-3 / 3-6 的 5° 窗口靠它成立，91°–154° 其余位置照旧不吸附。Duo 的铰链签名时刻：3-1 第一次斜起（阻尼手感）、3-4 乘影（广告镜头）、3-6 最后一合（送信）。其余幽灵手演示拇指。

**教学（3-1，零文字）**：触发同 review-2 §2.4——一次失败的合上之后 1.5 s，或进关 8 s 没折。幽灵手从摊平拖到 50° 停住**松手**，不吸附回 90°；影子滑进缺口时缺口描边亮 400 ms。减少动态：静止剪影，只在「?」出现。VoiceOver：不播幽灵手，播 announcement `teach.lean`「书可以停在立起和合上之间的任何地方」。

## 5. 无障碍

**对比度（WCAG 2.x，已算）**——玩法相关的都 ≥ 3:1：

| 元素 | 前景 / 背景 | 比值 |
|---|---|---|
| 影子面色 `shade` #6E604E | 背光纸 #F1E9D8 | 5.05:1 |
| 影子 | 背光页上的亮路格 #FBF6EA | 5.65:1 |
| 路格描边 `edge.lower` #7D7163 | 背光纸 | 3.94:1 |
| 朱线 `thread.aged` | 背光纸 | 4.91:1 |
| 正文 ink.900 | 背光纸 | 14.17:1 |
| 纸人 ink.figure | 影子 #6E604E | **2.76:1 —— 不够** |
| 纸人 ink.figure | 逆光描边 #FBF6EA | 15.62:1 |

所以纸人站在影子上时**必须**带 1.5 pt #FBF6EA 逆光描边（spec §8 已有「背光时剪影加一圈逆光描边」，这里升为规则），描边对影子 5.65:1。亮路格对纸只有 1.12:1，所以背光页上的路靠「1 pt 描边」成立，不靠亮度。网页原型现在的影子是淡灰软块，目测远低于 3:1——这是原型，iOS 按本表出。

**高对比**：影子 = ±45° 交叉线 1.8 / 6 + 2.5 pt 虚线框（spec §7）；石头 45° 单斜线 + 3 pt 轮廓——单斜 vs 交叉，色盲和灰度下都分得开。灯晕去掉。**降低透明度**：上页 #F1E9D8 实底 + 1.5 pt 描边，石头实色剪影加白棱线（spec §3）。

**VoiceOver**：
- 折页控件：`斜起 50°，可调整，上下轻扫每次 15°`；页抬进斜起窗口时读一次 `paper.lit`。
- 格子：缺口上有影子时读 `kindShadow`「影子，可以走」；上页石头读 `stoneShadow`「斜起时投下影子；合上会压住第{col}列」。
- 事件：影子落进缺口 → `shadowGap`；乘影 → `slid`「影子带着你滑到了第{r}行第{c}列」；掉下 → `fell` / `crushed`。
- 转子「影子」项列出当前所有影子格。

**声音模式**：影子 = 低频持续音，音高按行（五声音阶），声像在左耳（下页）；影子每滑一格一个下滑音；影子盖住缺口时缺口的「空心短音」变成实音——闭眼也能听出「对齐了」。3-3 / 3-6 的窄窗口：两道影子都落在缺口上时播一个双音和弦 + Selection 触觉，这就是听得见的「咔哒」。

**运动**：15° 一档全部可解（`check.js` 断言）。乘影不要求速度，任何时候停手影子就停；减少动态下纸人直接跳到目标格，播 `slid`。
