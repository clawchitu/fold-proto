## 2. 八条裁决

### 2.1 飞的几何：**原地一跳，不越折痕**

合上时上页贴到下页，(c, r) 和 (7 − c, r) 面对面——鹤的落点离它只有一张纸的厚度。所以「飞到对页」在屏幕上就是：在那一叠上抬起来、翅膀张开、落回去，落点那格（现在和原格重合）闪一下；书打开，它在对页，带着你。这正是 ch10 §1 写的「合着的时候你还在同一叠，打开才发现在对页」——发现在**打开**那一刻，不在合上那一刻。动画的信息量放在三处：合上时的一跳（「它动了」）、落点的闪（「它到了那一叠」）、打开后原格的淡影 `crane.ghost`（「它刚才在这里」，同 v2c1 `stone.ghost` 的用法）。25° 之前绝不动：拖到 60° 再拉回去，鹤一动不动。

### 2.2 染了 / 粘住：**过渡，不是状态**

ch9 评审 §1.1 (d)：填过的缺口只许一次性的淡环，之后「不留第三种格」。同理：10-5 整关建在「飞不动的鹤是一滴墨，第二次合它会洇」上——玩家必须把它读成**和别的湿墨一样**的湿墨；一个永远留着鹤形的墨团会暗示「它还能飞」。粘住同理：引擎两格都是 `.`，画面 600 ms 后就是两格路，胶「用掉之后不画」（v2c1 §2）。鹤形只在过渡里出现（§3.4），正常模式 600 ms、高对比 200 ms（ch9 §3.8 的高对比一律 200 ms 交叉淡化）。

### 2.3 胶：**用 token，高对比按 v2c1 的定稿**

正常模式（v2c1 §2 / review-v2c1 §3，一字不改，只换底色为卡纸的压痕格）：`glue` **`#E8B848` @ 62%** 椭圆，格面的 58% × 48%，中心下移 4%，外沿 12% 晕到 22%，下沿 1 pt inset 阴影 `#8A5A14` 30%，一点高光（白 45%，14% × 8%，在 (−14%, −12%)）；中间滴形线稿 `glue.line` **`#8A5A14`** 1.4 单位不填色。对比（卡纸 `tile.face.card` `#D6CDBE`）：`glue.line` 在格面 **3.75:1**，在胶面（62% 叠色后 ≈ `#E1C075`）**3.38:1**，都 ≥ 3:1；琥珀面本身是图形不承载信息。C1 (d) 的黄更饱和、高光像釉——改回 token。

**高对比胶**（review-v2c1 ⑦ 的定稿，本文写成可建的数）：白底 + 3 pt 黑框（同路格）；**整格点阵**：间距 9 pt、点 Ø 2.5 pt、黑，从框内沿**内缩 3 pt** 居中铺满；中央一枚**黑线滴形** 2 pt、高 = 格内高的 40%、不填色；无黄。和高对比松石（点 r 1.0、间距 4、裁在 3 pt 圆轮廓里）的区分：**满格稀点 + 滴形 vs 圆内密点**，形不同、密度差两倍多。用掉后整格变白底黑框路格。C1-HC (d) 那一圈椭圆线不要。

### 2.4 站上去不张翅：**一种停姿**

张翅只在你站上去时出现，会暗示「只有载人才飞」——10-2 教的恰恰是它自己也飞。纸人已经是「站在上面」的全部信息，鹤不用再表态。停着永远是 (a)；纸人画在鹤上面（层序 §3.3），鹤的线色（`ink.700`）比纸人（`ink.figure`）浅一档，45 pt 下纸人赢。

### 2.5 轮廓色：**`ink.700`，不是胶的褐**

原型 `main.js:98` `SVG.h` 的 `stroke="#8a5a14"` 就是 `glue.line`——鹤会被读成「胶做的」。鹤是纸：线 `ink.700` `#4A433B`（卡纸 7.7:1、格面 6.2:1），面是纸色。原型本班改为 `#4a433b`；原生按 §3.1 的 token。

### 2.6 笺第二拍：**纸人下鹤**

`S.h..... / --x--G--` 里 (2,0) 正对 (5,0)。「不飞」要在落点放石头，石头就正对着站在鹤上的人——合上是 `crushed`，不是 `craneStuck`。第二拍用 `.Sh..x.. / --x--G--`：纸人在 (1,0)（正对 (6,0) 的路，安全），石头 (5,0) 占着落点，合上、打开，鹤还在 (2,0)。顺便演示了「不站上去它也要飞——飞不动」。

### 2.7 章印：**「载」，确认**

四条理由：① **「渡」在册子里是两个关名**（5-5 `ferry`、10-3 `cross`）——卡上的印和关卡表用同一个字，印会被读成一关的标记；② 载是鹤的动词：规则「载人」、读屏 `carried`、信里「站在它上面」——印回答的是「这一章你被什么带过去」；③ 字族：达 · 通 · 影 · 成 · 落 · **载**，都是一个动作一个字；载 10 画、戈 + 车结构开，17 pt 印和 150 pt 章首都干净，比渡（氵+ 度，12 画）在小印上透气；④ 渡是水的字，是卷一的字族（达 / 通 / 岸）；卷三是立起来的书，不是河。「载 zǎi」的另一读（记载）在信册里不冲突，反而顺。`sealGlyph[10] = 载`。**第九章的「落」仍是候选**（vol3 评审 §4，待主人定）；C5 画的「落」只是占位。

### 2.8 地图（C5）：**族里的卡，改两处**

卡的结构、「十 鹤 · 0 / 6 · 进行中 ◇」、「6 / 6 · 已达 + 印」、「‹ 卷二《翻页》 26 / 26」、左右交错、朱线到进行中的卡打结再变灰——全对（vol3 评审 §2.7 / §3.9 的修正都落实了）。改：① **未写的卡只有数字 + `ch.unwritten`**，不带「来回」「三折」——章名在章入库时才定、才上屏；② 「继续 10-1」胶囊不在 `ChapterMapView` 的族里（卡本身是点击目标），除非原生已有同款，不加；③ 已达而无进行中的卡时（C5-sealed），朱线红到**最后一张已达卡的底边**打结，之后灰到页底——帧的位置对。

| 染了（`inked`） | 不跳；从 T_c 起 **600 ms** 交叉淡化：湿墨团（`I` 的正常画法）淡入盖住鹤，鹤的轮廓先变成 `paper.card` 色的白线、再随之淡出 | **普通 `I`**，无鹤形 | `craneSoaked` |
| 粘住（`glued`，有 `to`） | 正常一跳落到胶格、落点闪；落地后 **600 ms** 鹤 + 琥珀一起淡出到压痕格面 | **两格都是普通路格**（引擎已写 `.`） | 载人 `carried` 再 `craneGlued`；否则 `craneGlued` |

### 3.5 飞的时序与弧（合上那一拍）

T0 = 合到 25° 提交、`close.snap` 开始（v2c1 的 `glue.pull` 也以此为零点）。25° 之前鹤**不动**，拖回去什么都没发生。

| 时刻 | 发生 |
|---|---|
| 0 – 220 | `close.snap`（松石的滚在这段里走完，ch9 §3.5） |
| 220 – 340 | `page.press`：纸面下压 2 pt |
| 340 | `stamp()` 的其它事件起：洇圈、钥匙 / 门、墨印、`glue.pull`（340–560 越缝，560–860 胶格闪） |
| **T_c** | **鹤起跳**：这一拍没有洇 / 印 / 粘事件时 **T_c = 340**；有则 **T_c = 560**（等墨到、石头落胶——先洇先粘后飞，和引擎顺序一致） |
| T_c → T_c + 140 | 抬：在那一叠的位置（合上后原格和落点在屏幕上**重合**，review-3 §closed）向屏幕上方抬 **0.10 cell**、缩放 1 → **1.08**，ease-out；翅膀 t 0 → 1；接触影 ry × 0.6、18% → 8%；画在描图纸层**之上**（同越缝的石头） |
| T_c + 140 → T_c + 280 | 落：回到 0 / 1.0，ease-in；t 1 → 0；落地时落点那一叠 `flash`（300 ms，同 `stamp` 的闪）；鹤落回描图纸层之下 |
| T_c + 280 | 引擎状态已是飞后（`fly()` 在 `stamp()` 里早就写好了）；`placeChar` 到 `carried()` 的格——合着时和原叠重合，看不出 |
| 打开（角度 > 25°） | 第一帧鹤已在 `to`、纸人已在 `to`；原格画压痕格 + `crane.ghost`（鹤形剪影 `#000` 6%，1 s 线性淡出） |

- **多只鹤同一拍**：同一个 T_c 一起跳（引擎已经按压后的图一起判）；触觉一次。
- **一跳的方向不分上页下页**：鹤在右页飞到左页（10-2）和左页飞到右页（10-1）是同一段动画——都是在重合的那一叠上抬一下。
- **翻（10-6）**：翻的 350 ms 卡片转（ch6）落地 = 这里的 340；之后同表（T_c = 350 或 570）。右页的鹤不参与。
- **打开得早**：T_c + 280 之前就开始拖开 → 直接切到落后态（不做半跳）；打开后的 ghost 照放。
- 触觉：起跳 Impact **.light 0.5**，落地 **.soft 0.6**；耸一下 .light 0.4；染 / 粘不加（跟各自原有的）。声：落地借 `sound.stamp` 升 2 个半音；两下纸的扑声 `sound.crane`（≤ 280 ms）和 ch9 的厚纸闷响一起录。

### 3.6 减少动态效果

不抬、不张翅、不缩放：T_c 时鹤从原格消失、在 `to` 出现（合着时重合，等于只看到落点闪 300 ms）；打开后无 ghost；染了 / 粘住 = 200 ms 交叉淡化到 `I` / 路格；不飞 = 不耸，只读屏 + 触觉。时序表的 T_c 不变（顺序仍是先洇先粘后飞）。
