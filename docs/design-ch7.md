## 1. 机制：墨还没干

**一句话：墨还没干——每合一次，它往四周洇一格，再印到对面；印过去的也是湿的。**

### 1.1 规则（`logic.js`）

| 规则 | 代码 | 一句"纸会怎样" |
|---|---|---|
| 湿墨是地面 | `isFloor` 含 `I` | 和墨 `i` 一样能走 |
| 每一次**压**先洇一圈 | `stamp()` 第一步 `bleed(s)`：取当前所有 `I` 的快照，每格向本页四邻的 **缺口 `-` 和胶 `g`** 各扩一格 | 纸、石头、门、页边、中缝挡住它；洇到胶上，胶被盖住、**不再粘**。一次压只洇一圈——新洇出的格子这次不再往外洇 |
| 然后才印 | 原有配对循环：`(i 或 I) 对着 -` → 印同一种墨 | 洇完的整片湿墨印到对面的缺口上；印出来的是 `I`，下次压它也洇 |
| 压 = 合，也 = 翻 | `flip()` 调 `stamp()` | 翻过去那一拍 L–T 之间也洇、也印；翻回来再洇一圈 |
| 墨不干、不收 | 没有反向规则 | 洇满为止（`stamp` 到饱和后幂等） |
| 事件 | `{ type: 'bleed', cells: [{c, r, was}] }` 在门 / 墨 / 胶事件之前；湿墨的印是 `{ type: 'ink', wet: true }` | 读屏 `inkBled`「墨往外洇了一圈」；文字版 / 一眼纸把洇到的格子逐格报出 |

**顺序是规则的一部分**：先洇、后粘 / 开门 / 印。所以**胶挨着湿墨，就在同一次合里失效**（洇到胶上在粘之前）；而钥匙、门、石头不受洇影响（墨不洇到纸和石头上）。

**不做的**：墨干（时间 / 次数上限）——"合的次数是资源"要的是**越合越多**，不是倒计时；斜起时洇（压才洇；斜起是看，不是做）；洇过中缝（页边挡）；洇到纸上（纸本来能走，洇了没意义，也让"看洇到哪"成为一眼能算的事）。

### 1.2 和每一条已有规则的相互作用

| 和什么 | 作用 | 哪关用 |
|---|---|---|
| **合的次数**（一） | 合一次 = 一圈。卷一至今"合"是开关（第二次合不改图），现在每次都改图：`phases` 天然 ≥ 2。本章主线 `CLOSES_MAX.wet = 3` | 全章 |
| **叠合行走**（一、P5） | 洇出的格子是地面，叠合图随之开；但在**哪一圈**之后走哪一叠，一眼纸印不出来（它印的是"合 k 次之后"的图，不是"合 1 次 → 走 → 合 2 次"的历史） | 7-2 起 |
| **墨 `i`**（一） | 干墨只印不洇；湿墨印出来的也洇。同一关里两种墨并存时，干墨的印是"一次性的纸"，湿墨的印是"会长的纸" | 7-3 |
| **压**（三） | 不变——墨不是石头。但**洇满的缺口不再是缺口**：原来"合上安全"的格（对面是缺口）还是安全的；原来要乘影子过的缺口，可能已经是纸 | 7-4 起 |
| **影**（三） | 墨不挡光（`isOpaque` 只认石头）。影子落在湿墨上 = 落在纸上 | — |
| **乘影**（三 / 四） | **墨沉渡船**：乘影要先站上"缺口上的影子"；那格一旦洇成墨，影子就是纸上的影子，**不载人**（P5-4）。所以乘影必须在某一次合**之前**做完——先乘后印 vs 先印后乘，只有一个顺序成立（P2 + P3） | 7-3、7-5、7-7 |
| **钥匙 / 门**（一） | 不受洇影响；门挡洇 | 7-5（门挡住一边的洇） |
| **胶**（五） | **洇到胶上，胶失效**（同一次合里先洇后粘）：胶离墨 k 格，第 k 次压它就死；要胶粘，得在那之前合——或者让纸 / 石头挡住洇的路 | 7-4、7-6 |
| **翻**（六） | 翻 = 压：洇一圈 + L–T 互印。合 1 次再翻 = 两圈；合 2 次再翻 = 三圈。一眼纸只印"合 → 翻"和"合 → 翻 → 翻回"，**不印"合 → 开 → 合 → 翻"**：第三页上有什么，取决于翻之前合了几次 | 7-6、7-7 |
| **渡口**（P3） | 对面是缺口的左页空格 = 渡口；洇满之后两边都是纸 = 普通叠 | 7-5 |

### 1.3 为什么它是 v3 的料（对照 `difficulty-v3.md` §2）

- **P1 行动才揭示**：一眼纸能印"合 1 / 2 / 3 次之后"的三张图（`glance.js` 现在就印），但**在哪两次合之间走哪段路、乘哪道影**才是题——图上没有。
- **P2 不可逆**：墨不收回。多合一次，渡船沉了，而且你还能在叠里走、还能斜起看到别的影子——三步之后才知道。
- **P3 顺序**：先乘后印；先粘后洇。两条规则在一格相遇，顺序决定结果。
- **P6 资源**：合几次，第一次要数。

## 2. 看起来：墨迹未干的信笺

纸仍是**信笺**（`design-v2c1.md` §2；第三页规则同 `design-ch6.md` §2）。本章 4 个纸参数不动，换的是**墨**：

- **湿墨 `I`**（新 tile，轮廓基元 = 墨的基元：不规则湿黑块 + 溅点，`objects.md` A.1）：比干墨大一号（格的 96%）、边缘软（灰盒 `filter: blur(.7px)`；原生用 1.5 pt 高斯边 + 中心 100% / 边缘 70% 的径向墨色）、**有一圈淡晕**（墨色 12% 的外环，不出格）。干墨 `i` 保持原样——两种墨同屏时一眼分得开：一个边硬，一个边软。卷二皮「墨池」（objects.md A.2）用在湿墨上正合适：从砚里溢出来的一片。
- **洇的动画**（建造）：合到位那一拍（`stamp` 的闪同一拍），新洇到的格子从相邻的湿墨格**长出来** 260 ms（径向 scale 0 → 1，ease-out），先洇后印：对面的印在洇完之后 120 ms 出现。三页关翻过去同。减少动态：直接出现 + 闪。
- **高对比**：湿墨 = 墨的实心笔触块 + **外圈 2 pt 虚线环**（干墨没有环）；不靠模糊、不靠色。
- **声音**：洇 = 纸吸水的一声短"噗"（低通噪声 90 ms），每圈一声，不按格数叠加；印同前。震动 [15]。
- **章印**：七「晕」`seal.muted`。页边布景：**砚**（右页外下角半只砚台，墨池的来处；2.2:1，不占格）。终点仍是信封。
- **第三页**（7-6、7-7）：同第六章（暖一档、正面字迹透过来 0.14）。

## 6. 物件笺：墨晕 `wet`（7-1；`tools/slips.js` 已验）

```
S--I----      左页：起点 缺 缺 湿墨 | 右页：缺 缺 缺 缺
-G------      左页：缺 终点 缺 缺   | 右页：缺 缺 缺 缺
```

| t | 镜头 |
|---|---|
| 0–400 | 书摊平。纸人在 (0,0) 向右：前面 (1,0) 是缺口，撞（纸纹点抖一下）。湿墨 (3,0) 的软边轻轻呼吸一下。 |
| 400–800 | 停。 |
| 800–1300 | 合上。到位那一拍：墨**长出一圈**——(2,0)、(3,1) 从墨格里长出来（260 ms）；120 ms 后对面 (4,0)(5,0)(4,1) 印出同样软边的墨。 |
| 1300–1600 | 打开。纸人再向右：**还差一格**，(1,0) 仍是缺口，撞。 |
| 1600–2000 | 停（让人看见"一圈不够"）。 |
| 2000–2500 | 再合上。第二圈长出来：(1,0)、(2,1)；对面也多一圈。 |
| 2500–2800 | 打开。 |
| 2800–3400 | 纸人走 (1,0) → (1,1) 终点，打结。 |
| 3400–4100 | 停。→ 淡回第 0 帧。 |
